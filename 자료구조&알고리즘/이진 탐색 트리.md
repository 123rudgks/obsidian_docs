# 이진 탐색 트리

BST(Binary Search Tree)는 이진 트리에 다음 규칙이 추가된 자료구조이다.

- 각 노드는 왼쪽 자식과 오른쪽 자식을 최대 하나씩 가진다.
- 왼쪽 서브트리에는 현재 노드보다 작은 값만 존재한다.
- 오른쪽 서브트리에는 현재 노드보다 큰 값만 존재한다.

여기서는 중복 값은 삽입하지 않는다고 가정한다.

## 연산 시간 복잡도

트리의 높이를 `h`라고 하면 검색, 삽입, 삭제는 기본적으로 `O(h)`이다.

| 상태 | 검색 / 삽입 / 삭제 |
|---|---:|
| 루트에서 바로 찾는 최선의 검색 | `O(1)` |
| 균형에 가까운 트리 | `O(log N)` |
| 한쪽으로 치우친 트리 | `O(N)` |
| 전체 순회 | `O(N)` |

BST는 배열처럼 특정 인덱스에 `O(1)`로 임의 접근하는 자료구조는 아니다.

## 구현

```java
public class BinarySearchTree {
    private static class Node {
        int data;
        Node left;
        Node right;

        Node(int data) {
            this.data = data;
        }
    }

    private Node root;

    public void insert(int data) {
        root = insert(root, data);
    }

    private Node insert(Node node, int data) {
        if (node == null) {
            return new Node(data);
        }

        if (data < node.data) {
            node.left = insert(node.left, data);
        } else if (data > node.data) {
            node.right = insert(node.right, data);
        }

        return node;
    }

    public boolean contains(int data) {
        return contains(root, data);
    }

    private boolean contains(Node node, int data) {
        if (node == null) {
            return false;
        }

        if (data == node.data) {
            return true;
        }

        if (data < node.data) {
            return contains(node.left, data);
        }

        return contains(node.right, data);
    }

    public void remove(int data) {
        root = remove(root, data);
    }

    private Node remove(Node node, int data) {
        if (node == null) {
            return null;
        }

        if (data < node.data) {
            node.left = remove(node.left, data);
        } else if (data > node.data) {
            node.right = remove(node.right, data);
        } else {
            // 자식이 없거나 오른쪽 자식만 있는 경우
            if (node.left == null) {
                return node.right;
            }

            // 왼쪽 자식만 있는 경우
            if (node.right == null) {
                return node.left;
            }

            // 자식이 2개인 경우
            // 오른쪽 서브트리의 최솟값을 후계자로 사용
            Node successor = findMin(node.right);
            node.data = successor.data;
            node.right = remove(node.right, successor.data);
        }

        return node;
    }

    private Node findMin(Node node) {
        while (node.left != null) {
            node = node.left;
        }

        return node;
    }

    public void inorder() {
        inorder(root);
        System.out.println();
    }

    private void inorder(Node node) {
        if (node == null) {
            return;
        }

        inorder(node.left);
        System.out.print(node.data + " ");
        inorder(node.right);
    }

    public static void main(String[] args) {
        BinarySearchTree tree = new BinarySearchTree();

        tree.insert(50);
        tree.insert(30);
        tree.insert(70);
        tree.insert(20);
        tree.insert(40);
        tree.insert(60);
        tree.insert(80);

        System.out.print("중위 순회: ");
        tree.inorder();

        System.out.println("40 존재 여부: " + tree.contains(40));
        System.out.println("100 존재 여부: " + tree.contains(100));

        tree.remove(70);

        System.out.print("70 삭제 후: ");
        tree.inorder();
    }
}
```

## 중위 순회

BST를

```text
Left → Root → Right
```

순서로 중위 순회하면 값이 오름차순으로 출력된다.

## 균형과 성능

정렬된 데이터를 순서대로 삽입하면

```text
1 → 2 → 3 → 4 → 5
```

처럼 한쪽으로 치우친 트리가 만들어질 수 있고, 이 경우 검색이 `O(N)`까지 느려질 수 있다.

무작위 삽입 순서는 정렬된 순서보다 비교적 균형 잡힌 트리가 만들어질 가능성이 높지만 **균형을 보장하지는 않는다.**

균형을 보장하려면 AVL Tree, Red-Black Tree 같은 별도의 균형 이진 탐색 트리가 필요하다.
