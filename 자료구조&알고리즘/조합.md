조합은 N개 중 R개를 뽑되, **순서**를 고려하지 않는 것 
[[순열]]이랑 연결해서 보면 이해가 쉽다.

예를 들어 `1,2,3` 중 2개를 뽑으면
```
[1, 2]
[1, 3]
[2, 3]
```
이렇게 3개만 나온다.
순열에선 `[1,2]`와 `[2,1]`을 다른 경우로 보았지만, 조합에선 같은 경우로 본다.


1. start부터 원소를 하나 선택한다.
2. 선택한 값을 `selected[depth]`에 저장한다.
3. 다음 탐색은 현재 선택한 위치의 다음 인덱스(`i+1`)부터 시작한다.
4. `depth + 1`로 재귀 호출한다.
5. `R`개를 모두 선택하면 하나의 조합이 완성된다.
6. 재귀에서 돌아온 뒤, for문을 계속 돌며 다른 원소를 선택

>핵심은 하나 선택 → 다음 인덱스부터 탐색 → R개가 되면 완료

```java
static int[] arr = {1,2,3};
static int[] selected = new int[2];

static void combination(int start, int depth){
	if(depth==2){
		System.out.println(Arrays.toString(selected));
		return;
	}
	
	for(int i = 0; i<arr.length; i++){
		selected[depth] = arr[i];
		combination(i+1,depth+1);
	}
}
```
