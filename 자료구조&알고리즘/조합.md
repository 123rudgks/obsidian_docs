# 조합

조합은 N개 중 R개를 뽑되, **순서를 고려하지 않는 것**이다.

예를 들어 `1, 2, 3` 중 2개를 뽑으면

```text
[1, 2]
[1, 3]
[2, 3]
```

순열에서는 `[1, 2]`와 `[2, 1]`을 다르게 보지만 조합에서는 같은 선택으로 본다.

```text
nCr = n! / (r! × (n-r)!)
```

## 재귀를 이용한 조합

핵심은 **현재 원소를 선택한 뒤 다음 인덱스부터만 탐색하는 것**이다.

1. `start`부터 원소 하나 선택
2. `selected[depth]`에 저장
3. 다음 탐색은 `i + 1`부터 시작
4. `depth + 1`로 재귀 호출
5. R개를 선택하면 조합 완성

```java
import java.util.Arrays;

public class Main {
    static int[] arr = {1, 2, 3};
    static int R = 2;
    static int[] selected = new int[R];

    static void combination(int start, int depth) {
        if (depth == R) {
            System.out.println(Arrays.toString(selected));
            return;
        }

        for (int i = start; i < arr.length; i++) {
            selected[depth] = arr[i];
            combination(i + 1, depth + 1);
        }
    }

    public static void main(String[] args) {
        combination(0, 0);
    }
}
```

## 순열과 조합 구현 차이

```text
순열
→ 같은 원소를 다시 사용하면 안 됨
→ visited 필요
→ 매 depth에서 전체 원소 후보를 확인

조합
→ 이전에 선택한 인덱스보다 뒤만 확인
→ start 필요
→ i + 1부터 다음 탐색
```

## 비트 마스킹으로 조합 구현

[[비트 마스킹]]으로 모든 부분집합을 표현하고, 그중 선택된 원소가 정확히 R개인 상태만 사용할 수 있다.

```java
public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};
        int n = arr.length;
        int r = 3;

        for (int mask = 0; mask < (1 << n); mask++) {
            if (Integer.bitCount(mask) != r) {
                continue;
            }

            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    System.out.print(arr[i] + " ");
                }
            }

            System.out.println();
        }
    }
}
```

이 방식은 `2^N`개의 상태를 확인하고 그중 R개가 선택된 상태만 사용한다.

## Next Permutation으로 조합 구현

N개 중 R개를 선택한다면

```text
0 = 선택하지 않음
1 = 선택함
```

으로 보고 0이 `N-R`개, 1이 R개인 배열에서 Next Permutation을 수행할 수 있다.

예를 들어 5개 중 3개를 선택하면

```text
0 0 1 1 1
0 1 0 1 1
0 1 1 0 1
...
1 1 1 0 0
```

처럼 `NCr`개의 선택 상태를 직접 생성한다.

```java
public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};

        int n = arr.length;
        int r = 3;
        int[] selected = new int[n];

        for (int i = n - r; i < n; i++) {
            selected[i] = 1;
        }

        do {
            for (int i = 0; i < n; i++) {
                if (selected[i] == 1) {
                    System.out.print(arr[i] + " ");
                }
            }
            System.out.println();
        } while (nextPermutation(selected));
    }
}
```

`nextPermutation()` 구현은 [[순열#Next Permutation]] 참고.

## 비트마스크 vs Next Permutation

| 방식 | 확인하는 상태 |
|---|---:|
| 비트마스크 | `2^N` |
| Next Permutation | `NCr` |

비트마스크 방식은 모든 `2^N`개의 선택 상태를 확인한 뒤 R개가 선택된 경우만 골라낸다.

Next Permutation 방식은 R개가 선택된 `NCr`개의 조합 상태를 직접 생성한다.
