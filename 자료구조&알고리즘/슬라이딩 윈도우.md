
# 슬라이딩 윈도우

슬라이딩 윈도우는 배열이나 문자열에서 **연속된 구간을 한 칸씩 이동시키며 필요한 값을 갱신하는 기법**이다.

구간을 이동할 때마다 모든 원소를 다시 계산하지 않고, 새로 들어오는 값은 더하고 구간에서 빠지는 값은 빼서 중복 계산을 줄인다.

## 로직

1. 문제에서 사용할 윈도우의 크기와 시작 위치를 정한다.
2. 첫 번째 윈도우의 값을 계산한다.
3. 윈도우를 한 칸 이동하며 새로 들어온 값을 추가한다.
4. 이전 윈도우에서 빠진 값을 제거한다.
5. 현재 윈도우의 값으로 정답을 갱신하고 배열 끝까지 반복한다.

## 예제 — 연속 근무 수익

문제 
: 
일 수 별로 일당이 다를 경우 받을 수 있는 최대 금액은?
공지된 일수 n, 연속 근무 일수 m 
```java
import java.io.*;
import java.util.*;

public class Main{
	public static void main(String[] args) throws Exception{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		
		StringTokenizer st = new StringTokenizer(br.readLine());
		
		int n = Integer.parseInt(st.nextToken());
		int m = Integer.parseInt(st.nextToken());
		
		int[] arr = new int[n];
		
		st = new StringTokenizer(br.readLine());
		
		for(int i = 0; i < n; i++){
			arr[i] = Integer.parseInt(st.nextToken());
		}
		
		long sum = 0;
		
		// first window
		for(int i = 0; i < m; i++){
			sum += arr[i];
		}
		
		long max = sum;
		
		// move window by one cell
		for(int i = m; i<n; i++){
			// add new value
			sum += arr[i];
			// substract oldest value
			sum -= arr[i-m];
			
			max = Math.max(max,sum);
		}
		System.out.println(max);
	}
}
```
