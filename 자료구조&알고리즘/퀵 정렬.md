[[정렬]]에는 다양한 알고리즘이 있지만 대부분 컴퓨터 언어는 퀵 정렬을 사용한다.

최악의 시나리오 에서는 [[삽입 정렬]]이나 [[선택 정렬]]과 성능이 유사하지만 대부분 일어나는 평균 시나리오에서는 훨씬 빠르다.

퀵 정렬을 구현해보면서 [[재귀]]가 어떻게 알고리즘의 속도를 크게 향상시키는지 배울 수 있고 이를 다른 알고리즘에도 똑같이 적용할 수 있다.

**분할**과 [[재귀]]로 이루어 진다.
#### 분할
1. [[배열]]의 가장 오른쪽 원소를 피벗으로 선택한다. (다른 값을 선택해도 무방)
2. 두 "포인터"를 사용해 하나는 배열 가장 왼쪽에, 나머지 하나는 배열의 가장 오른쪽(피벗 제외)에 할당한다.
3. 왼쪽 포인터를 한 셀씩 계속 오른쪽으로 옮기면서 피벗보다 크거나 같은 값에 도달하면 멈춘다.
4. 오른쪽 포인터를 한 셀씩 계속 왼쪽으로 옮기면서 피벗보다 작거나 같은 값에 도달하면 멈춘다. 또는 배열의 맨 앞에 도달해도 멈춘다.
5. 오른쪽 포인터가 멈춘 후에 왼쪽 포인터가 오른쪽 포인터에 도달했으면 (또는 넘었다면) 왼쪽 포인터가 가리키고 있는 값과 피벗을 교환한다.
6. 왼쪽 포인터가 오른쪽 포인터에 도달(또는 교차)하지 않았다면 두 원소를 교환한 후 위 단계들을 반복한다.

분할이 마치면 피벗 왼쪽은 전부 피벗의 값보다 작고 오른쪽은 전부 피벗의 값보다 크다.

#### 재귀
1. 분할을 마친 피벗은 올바른 위치에 있다.
2. 피벗의 왼쪽 하위 배열과 오른쪽 하위 배열을 각각 또 다른 배열로 보고 분할 과정을 재귀적으로 반복한다.
3. 하위 배열의 원소가 0개 또는 1개 뿐이라면 기저조건임으로 아무것도 하지 않는다.

**코드 구현**
```java
public class QuickSort{
	
	public static void quickSortTwoPointer(int[] arr, int low, int high){
		if(low < high){
		// 피벗의 최종 위치를 반환
		int p = partition(arr,low,high);
		// 피벗은 이미 정렬된 위치이므로 제외
		quickSortTwoPointer(arr, low, p-1);
		quickSortTwoPointer(arr, p+1, high);
		}
	}
	
	private static int partitionTwoPointer(int[] arr, int low, int high){
		// 가장 오른쪽 값을 피벗으로 선택
		int pivot = arr[high];
		// 왼쪽 포인터
		int left = low;
		// 오른쪽 포인터
		// 피벗은 제외하므로 high - 1
		int right = high - 1;
		
		while(true){
			// 피벗보다 크거나 같은 값을 찾음
			while(left <= right && arr[left] < pivot){
				left++;
			}
			// 피벗보다 작거나 같은 값을 찾음
			while(left <= right && arr[right] > pivot){
				right--;
			}
			
			// 두 표인터가 만나거나 교차하면 종료
			if(left >= right){
				 break;
			}
			
			// 두 포인터가 가리키는 값을 교환
			swap(arr, left, right);
			
			// 같은 값을 만났을 때 무한 반복 방지
			left++;
			right--;
		}
		
		// 왼쪽 포인터 위치와 피벗을 교환
		swap(arr, left, high);
		
		// 피벗의 최종 위치 변환
		return left;
	}
	
	private static void swap(int[] arr, int i, int j) { 
		int temp = arr[i]; 
		arr[i] = arr[j]; 
		arr[j] = temp; 
	}

}


// 실행
public static void main(String[] args){
	int[] arr = {5,3,8,4,2,7,1,6};
	
	quickSortTwoPointer(arr,0,arr.length-1);
	System.out.println(Arrays.toString(arr));
}
```



퀵 정렬은 Lomuto 분할을 사용하여 구현 할 수도 있다.
#### 분할

1. [[배열]]의 가장 오른쪽 원소를 피벗으로 선택한다. (다른 값을 선택해도 무방)
2. 두 "포인터"를 사용한다.
    - `j` 포인터는 배열의 가장 왼쪽 원소부터 시작하며, 각 원소를 피벗과 비교한다.
    - `i` 포인터는 피벗보다 작거나 같은 원소들이 모여 있는 영역의 끝을 나타내며, 처음에는 배열 시작 위치의 한 칸 앞에 둔다.
3. `j` 포인터를 왼쪽에서 오른쪽으로 한 칸씩 이동시키면서 각 원소를 피벗과 비교한다.
4. `j`가 가리키는 값이 피벗보다 작거나 같다면 `i`를 한 칸 오른쪽으로 이동시키고, `i`와 `j`가 가리키는 원소를 서로 교환한다
5. `j`가 가리키는 값이 피벗보다 크다면 아무것도 하지 않고 `j`만 다음 원소로 이동시킨다.
6. `j`가 피벗 바로 앞까지 모든 원소를 검사하면, `i`의 바로 다음 위치와 피벗을 교환한다.
7. 피벗이 이동한 위치를 분할 위치로 반환한다.

분할이 마치면 피벗 왼쪽에는 피벗보다 작거나 같은 값들이 있고, 오른쪽에는 피벗보다 큰 값들이 있다. 따라서 피벗은 최종적으로 올바른 위치에 놓인다.
#### 재귀
1. 분할을 마친 피벗은 올바른 위치에 있으므로 이후 정렬 대상에서 제외한다.
2. 피벗의 왼쪽 하위 배열과 오른쪽 하위 배열을 각각 또 다른 배열로 보고 분할 과정을 재귀적으로 반복한다.
3. 하위 배열의 원소가 0개 또는 1개뿐이라면 이미 정렬된 상태이므로 기저 조건으로 보고 아무것도 하지 않는다.

**코드 구현**
```java
public class QuickSort{
	
	public static void quickSortLomuto(int[] arr, int low, int high){
		if(low < high){
		// 피벗의 최종 위치를 반환
		int p = partitionLomuto(arr,low,high);
		// 피벗은 이미 정렬된 위치이므로 제외
		quickSortLomuto(arr, low, p-1);
		quickSortLomuto(arr, p+1, high);
		}
	}
	
	private static int partitionLomuto(int[] arr, int low, int high){
		// 가장 오른쪽 값을 피벗으로 선택
		int pivot = arr[high];
		
		// 피벗 이하 값들의 영역 끝
		int i = low - 1;
		
		// j가 왼쪽에서 오른쪽으로 이동
		for (int j = low, j < high; j++){
			if(arr[j] <= pivot){
				i++;
				swap(arr,i,j);
			}
		}
		
		// 피벗을 최종 위치로 이동
		swap(arr, i + 1, high);
		return i + 1;
	}
	
	private static void swap(int[] arr, int i, int j) { 
		int temp = arr[i]; 
		arr[i] = arr[j]; 
		arr[j] = temp; 
	}

}


// 실행
public static void main(String[] args){
	int[] arr = {5,3,8,4,2,7,1,6};
	
	quickSortLomuto(arr,0,arr.length-1);
	System.out.println(Arrays.toString(arr));
}
```

- **Lomuto**: 구현이 단순하지만 swap이 비교적 많이 발생합니다. 특히 이미 정렬된 배열이나 중복값이 많은 경우, 피벗 선택이 나쁘면 한쪽으로 치우친 분할이 나오기 쉽다.
- **Hoare**: 양쪽에서 포인터가 움직이기 때문에 보통 swap 횟수가 더 적고, 실제 실행 성능이 Lomuto보다 좋은 경우가 많다.
