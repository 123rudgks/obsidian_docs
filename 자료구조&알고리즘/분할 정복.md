# 분할 정복

분할 정복(Divide and Conquer)은 큰 문제를 **작은 문제로 쪼개서 각각 해결한 뒤, 그 결과를 합쳐 원래 문제를 해결하는 알고리즘 설계 방식**이다.

대표적인 예:

- [[병합 정렬]]
- [[퀵 정렬]]
- [[이진 검색]]

분할 정복은 [[재귀]]와 자주 같이 사용된다.

## 기본 구조

### 1. Divide — 분할

현재 문제를 더 작은 하위 문제들로 나눈다.

### 2. Conquer — 해결

나누어진 하위 문제를 각각 해결한다. 하위 문제가 여전히 크다면 다시 분할한다.

### 3. Combine — 결합

하위 문제에서 얻은 결과를 합쳐 원래 문제의 답을 만든다.

문제에 따라 Combine 단계가 거의 없는 경우도 있다. [[이진 검색]]은 답을 찾은 하위 구간만 계속 탐색하므로 별도의 복잡한 결합 과정이 없다.

## 기저 조건

분할을 계속하다가 더 이상 나눌 필요가 없는 가장 작은 문제가 되면 바로 답을 반환해야 한다.

```java
void divide(int size) {
    if (size == 1) {
        return;
    }

    divide(size / 2);
    divide(size / 2);
}
```

따라서 분할 정복을 재귀로 구현할 때는

```text
기저 조건
→ 문제 분할
→ 하위 문제 해결
→ 결과 결합
```

구조를 생각하면 된다.

## 대표 문제 — 쿼드 압축

2차원 영역의 값이 모두 같으면 해당 영역을 하나로 처리하고, 값이 섞여 있다면 영역을 4개로 나누어 같은 작업을 반복한다.

```java
class Solution {
    int[] answer = new int[2];

    public int[] solution(int[][] arr) {
        divide(arr, 0, 0, arr.length);
        return answer;
    }

    void divide(int[][] arr, int row, int col, int size) {
        // 현재 영역이 모두 같은 숫자라면 더 분할할 필요 없음
        if (isSame(arr, row, col, size)) {
            answer[arr[row][col]]++;
            return;
        }

        // 같은 숫자가 아니라면 4등분
        int half = size / 2;

        divide(arr, row, col, half);                       // 왼쪽 위
        divide(arr, row, col + half, half);                // 오른쪽 위
        divide(arr, row + half, col, half);                // 왼쪽 아래
        divide(arr, row + half, col + half, half);         // 오른쪽 아래
    }

    boolean isSame(int[][] arr, int row, int col, int size) {
        int value = arr[row][col];

        for (int i = row; i < row + size; i++) {
            for (int j = col; j < col + size; j++) {
                if (arr[i][j] != value) {
                    return false;
                }
            }
        }

        return true;
    }
}
```

이 문제에서는

```text
Divide  : 현재 영역을 4등분
Conquer : 각 영역에 대해 다시 divide 호출
Combine : 각 영역에서 센 0과 1의 개수가 answer에 누적됨
```

으로 볼 수 있다.

## 핵심

> 큰 문제를 작은 문제로 나눌 수 있고, 작은 문제를 해결한 결과로 전체 문제를 해결할 수 있을 때 분할 정복을 생각한다.
