우선순위 큐는 삭제와 접근은 전형적인 [[큐]]와 흡사하나 삽입은 정렬된 [[배열]]과 비슷한 리스트.
즉, 우선순위 큐 앞에서만 데이터에 접근,삭제를 하고 데이터를 삽입할 때는 데이터를 늘 특정 순서대로 정렬시킨다.

[[배열]]로 우선순위 큐를 구현한다면 삽입시에 O(n)이 걸리고 (shift 때문에), 삭제 시에 O(1)이 걸린다.(맨 끝을 배열의 끝으로 한 경우)
힙은 가장 높은 우선순위의 항목이 가장 루트 노드에 있어서 바로 접근할 수 있기 때문에 [[힙]]으로 구현할 수 있다.

## 구현
```java
public class MyPriorityQueue{
	private int[] heap;
	private int size;
	
	public MyPriorityQueue(int capacity){
		heap = new int[capacity];
		size = 0;
	}
	
	public boolean isEmpty(){
		return size == 0;
	}
	
	public int size(){
		return size;
	}
	
	// 원소 삽입
	public void offer(int value){
		if(size == heap.length){
			resize();
		}
		
		heap[size] = value;
		
		// 새 원소를 위로 올리면서 힙 조건 복구
		siftUp(size);
		
		size++;
	}
	
	// 최솟값 확인
	public int peek(){
		if(isEmpty()){
			throw new IllegalStateException("PriorityQueue가 비어있습니다.");
		}
		return heap[0];
	}
	
	// 최솟값 삭제 및 반환
	public int poll(){
		int(isEmpty()){
			throw new IllegalStateException("PriorityQueue가 비어 있습니다.");
		}
		
		int result = heap[0];
		
		// 마지막 원소를 루트로 이동
		heap[0] = heap[size-1];
		size--;
		
		// 루트부터 아래로 내려가며 힙 조건 복구
		siftDown(0);
		
		return result;
	}
	
	// 아래에서 위로 올라가며 정렬
	private void siftUp(int index){
		while(index > 0){
			int parent = (index - 1) / 2;
			
			// 부모가 더 작거나 같으면 Min Heap 조건 만족
			if(heap[parent] <= heap[index]){
				break;
			}
			
			swap(parent, index);
			
			index = parent;
		}
	}
	
	// 위에서 아래로 내려가며 정렬
	private void siftDown(int index){
		while(true){
			int left = index * 2 + 1;
			int right = index * 2 + 2;
			
			int smallest = index;
			
			if(left < size && heap[left] < heap[smallest]){
				smallest = left;
			}
			
			if(right < size && heap[right] < heap[smallest]){
				smallest = right;
			}
			
			// 현재 위치가 이미 가장 작음
			if(smallest == index){
				break;
			}
			
			swap(index, smallest);
			
			index = smallest;
		}
	}
	
	private void swap(int a, int b){
		int temp = heap[a];
		heap[a] = heap[b];
		heap[b] = temp;
	}
	
	private void resize(){
		int[] newHeap = new int[heap.length * 2];
		
		for(int i = 0; i < heap.length; i++){
			newHeap[i] = heap[i];
		}
		
		heap = newHeap;
	}
}
```
