힙에는 여러가지 종류가 있다. 그 중에서 이 문서에선 이진 힙을 다루겠다.
이진 힙은 특수한 종류의 이진 [[트리]]이다. 

이진 힙에는 최대 힙(max-heap)과 최소 힙(min-heap)이 있다. 둘이 사실상 같은 구조임으로 이 문서에선 최대 힙을 기준으로 설명한다.

힙은 다음 조건을 따르는 이진 트리이다.
- 부모 노드는 자식 노드보다 값이 커야한다. (힙 조건)
- 트리는 완전해야한다.
  노드의 왼쪽에서 부터 오른쪽으로 차곡 차곡 채워져야 한다. (하나 건너 뛰고 채워지는 것은 안됨)

힙은 [[이진 탐색 트리]]에 비해 약한 정렬이다.
	값 3을 검색 할 때 루트 노드가 100이라 하면 이진 탐색 트리에선 당연히 3이 100의 왼쪽 자손임을 알지만 힙은 3이 100의 조상이 아니라 자손이라는 것 까지만 안다. 왼쪽, 오른쪽 어느 자식을 검색해야 하는지는 알 수가 없다.

힙에서는 루트 노드가 항상 최대값이다.

힙의 주요 연산은 삽입,삭제다. 힙에서는 검색을 위해선 모든 노드를 검사해야 하므로 대개 검색 연산을 구현하지 않는다. (단순히 루트 노드의 값만 보는 "읽기" 연산은 선택적으로 존재 함)

힙의 마지막 노드(last node)는 가장 바닥 레벨에서 가장 오른쪽에 있는 노드를 의미한다.

힙의 노드 찾기 공식
- 어떤 노드의 왼쪽 자식 : `(index * 2) + 1`
- 어떤 노드의 오른쪽 자식 : `(index * 2) + 2`
- 어떤 노드의 부모 : `(index - 1) / 2`

힙에 값을 삽입할 시에 마지막에 값을 추가한 뒤 부모와 비교하며 위로 shift-up 한다.
힙에 값을 삭제할 시에 루트를 제거한 뒤 마지막 값을 루트로 옮기고 더 큰 자식과 교환하면 아래로 shift-down 한다.

```java
import java.util.ArrayList;

public class MaxHeap{
	private ArrayList<Integer> heap;
	
	public MaxHeap(){
		heap = new ArrayList<>();
	}
	
	// 원소 삽입
	public void insert(int value){
		heap.add(value);
		
		int index = heap.size() - 1;
		
		// 부모보다 크면 위로 올린다.
		while(index > 0 ){
			int parent = (index - 1) / 2;
			
			if(heap.get(parent) >= heap.get(index)){
				break;
			}
			swap(parent, index);
			index = parent;
		}
	}
	// 최댓값 확인
	public int peak(){
		if(heap.isEmpty()){
			throw new IllegalStateException("힙이 비어 있습니다.");
		}
		return heap.get(0);
	}
	
	// 최댓값 삭제 및 반환
	public int remove(){
		if(heap.isEmpty()){
			throw new IllegalStateException("힙이 비어 있습니다.");
		}
		
		int max = heap.get(0);
		
		// 마지막 원소를 루트로 이동
		int lastValue = heap.remove(heap.size()-1);
		
		// 원소가 남아 있다면 아래로 내려가며 재정렬
		if(!heap.isEmpty()){
			heap.set(0,lastValue);
			
			int index = 0;
			
			while(true){
				int leftChild = index * 2 + 1;
				int rightChild = index * 2 + 2;
				
				int largest = index;
				
				// 왼쪽 자식과 비교
				if(leftChild < heap.size() && heap.get(leftChild) > heap.get(largest)){
					largest = leftChild;
				}
				// 오른쪽 자식과 비교
				if(rightChild < heap.size() && heap.get(rightChild)> heap.get(largest)){
					largest = rightChild;
				}
				// 현재 노드가 가장 크다면 종료
				if(largest == index){
					break;
				}
				swap(index, largest);
				index = largest;
			}
		}
		return max;
	}
	
	// 힙이 비어 있는지 확인
	public boolean isEmpty(){
		return heap.isEmpty();
	}
	// 두 원소 교환
	private void swap(int i, int j){
		int temp = heap.get(i);
		heap.set(i, heap.get(i));
		heap.set(j, temp);
	}
	// 출력
	public void printHeap(){
		System.out.println(heap);
	}
	
	public static void main(String[] args){
		MaxHeap maxHeap = new MaxHeap();
		
		maxHeap.insert(30); 
		maxHeap.insert(10); 
		maxHeap.insert(50); 
		maxHeap.insert(20); 
		maxHeap.insert(40);
		
		maxHeap.printHeap();
	}
}


```


힙은 모든 항목을 완벽히 정렬하는 대신 부모 자식간의 값만 정렬하는 (약한 정렬)이기 때문에 떄로는 더 효율적이다.
