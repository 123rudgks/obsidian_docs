# 힙

힙에는 여러 종류가 있으며, 여기서는 **이진 힙(binary heap)** 을 다룬다.

이진 힙은 특수한 종류의 이진 [[트리]]이다.

## 최대 힙과 최소 힙

- 최대 힙(max-heap): 부모의 값이 자식의 값보다 크거나 같다. 루트가 항상 최댓값이다.
- 최소 힙(min-heap): 부모의 값이 자식의 값보다 작거나 같다. 루트가 항상 최솟값이다.

여기서는 최대 힙을 기준으로 설명한다.

## 힙의 조건

최대 힙은 다음 조건을 만족한다.

1. 부모 노드는 자식 노드보다 값이 크거나 같다. **(힙 조건)**
2. 트리는 **완전 이진 트리**이다.
   - 마지막 레벨은 왼쪽부터 차례대로 채워진다.

힙은 [[이진 탐색 트리]]처럼 왼쪽과 오른쪽의 대소 관계까지 보장하지 않는다.

예를 들어 루트가 100이고 어떤 자손 중 값 3이 있다는 것은 알 수 있지만, 3이 왼쪽 서브트리에 있는지 오른쪽 서브트리에 있는지는 알 수 없다.

따라서 특정 값을 검색하려면 최악의 경우 모든 노드를 확인해야 한다.

## 배열로 표현하는 이유

힙은 완전 이진 트리이므로 노드가 왼쪽부터 빈칸 없이 채워진다. 따라서 별도의 Node 객체 없이 배열에 연속해서 저장하기 좋다.

0번 인덱스를 루트로 사용할 때

- 왼쪽 자식: `(index * 2) + 1`
- 오른쪽 자식: `(index * 2) + 2`
- 부모: `(index - 1) / 2`

## 시간 복잡도

| 연산 | 시간 복잡도 |
|---|---:|
| 루트 확인(peek) | `O(1)` |
| 삽입 | `O(log N)` |
| 루트 삭제 | `O(log N)` |
| 특정 값 검색 | `O(N)` |

## 삽입 — shift-up

새 값은 완전 이진 트리 조건을 유지하기 위해 **배열의 마지막 위치에 먼저 추가**하고, 부모와 비교하며 위로 올린다.

예를 들어 최대 힙이

```text
[50, 30, 40, 10, 20]
```

이고 `60`을 삽입한다고 하자.

```text
1. 마지막에 추가
[50, 30, 40, 10, 20, 60]

2. 부모 40보다 60이 큼 → 교환
[50, 30, 60, 10, 20, 40]

3. 부모 50보다 60이 큼 → 교환
[60, 30, 50, 10, 20, 40]
```

루트까지 올라가거나 부모가 더 클 때 멈춘다.

## 삭제 — shift-down

최대 힙에서는 보통 루트를 삭제한다.

예를 들어

```text
[60, 30, 50, 10, 20, 40]
```

에서 루트 `60`을 삭제한다고 하자.

```text
1. 마지막 값 40을 루트로 이동
[40, 30, 50, 10, 20]

2. 두 자식 30, 50 중 더 큰 자식 50과 비교
40 < 50 이므로 교환

[50, 30, 40, 10, 20]
```

현재 노드가 자식보다 크거나 리프에 도달하면 멈춘다.

## 최대 힙 구현

```java
import java.util.ArrayList;

public class MaxHeap {
    private final ArrayList<Integer> heap = new ArrayList<>();

    public void insert(int value) {
        heap.add(value);

        int index = heap.size() - 1;

        while (index > 0) {
            int parent = (index - 1) / 2;

            if (heap.get(parent) >= heap.get(index)) {
                break;
            }

            swap(parent, index);
            index = parent;
        }
    }

    public int peek() {
        if (heap.isEmpty()) {
            throw new IllegalStateException("힙이 비어 있습니다.");
        }

        return heap.get(0);
    }

    public int remove() {
        if (heap.isEmpty()) {
            throw new IllegalStateException("힙이 비어 있습니다.");
        }

        int max = heap.get(0);
        int lastValue = heap.remove(heap.size() - 1);

        if (!heap.isEmpty()) {
            heap.set(0, lastValue);

            int index = 0;

            while (true) {
                int leftChild = index * 2 + 1;
                int rightChild = index * 2 + 2;
                int largest = index;

                if (leftChild < heap.size()
                        && heap.get(leftChild) > heap.get(largest)) {
                    largest = leftChild;
                }

                if (rightChild < heap.size()
                        && heap.get(rightChild) > heap.get(largest)) {
                    largest = rightChild;
                }

                if (largest == index) {
                    break;
                }

                swap(index, largest);
                index = largest;
            }
        }

        return max;
    }

    public boolean isEmpty() {
        return heap.isEmpty();
    }

    private void swap(int i, int j) {
        int temp = heap.get(i);
        heap.set(i, heap.get(j));
        heap.set(j, temp);
    }
}
```

## 핵심

> 힙은 모든 원소를 완전히 정렬하는 것이 아니라 부모와 자식 사이의 힙 조건만 유지하기 때문에 최댓값 또는 최솟값을 빠르게 관리할 수 있다.
