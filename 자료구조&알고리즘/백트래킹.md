백트래킹은 가능한 경우를 탐색하다가, 더 볼 필요가 없거나 한 선택을 다 확인했다면 이전 상태로 돌아가서 다른 선택을 시도하는 방법
> 즉, 선택 → 탐색 → 선택 취소를 반복하면서 모든 경우를 찾아가는 방식


[[완전 탐색]]과 백트래킹의 차이
```
완전탐색
└─ 가능한 모든 경우를 끝까지 확인

백트래킹
└─ 경우의 수를 탐색하다가
   현재 경로가 답이 될 수 없다고 판단되면
   그 아래 경우는 더 보지 않고 이전 단계로 돌아가
   다른 경우를 확인
```


[[재귀]]는 항상 기저 조건을 만나 호출한 함수로 되돌아가는데 그럼 재귀는 항상 백트래킹이라고 봐도 되는 걸까?
> **재귀의 복귀 ≠ 백트래킹**  
> **백트래킹 = 선택 → 탐색 → 선택 취소 → 다른 선택 탐색**
> 필요하면 탐색 중 답이 될 수 없는 경로는 더 진행하지 않고 바로 돌아간다.



**대표 문제 (N-Queen)**

`N × N` 체스판에 퀸 `N개`를 서로 공격할 수 없도록 배치하는 문제.

퀸은 다음 방향으로 이동할 수 있다.
- 가로
- 세로
- 대각선

따라서 퀸끼리 같은 행, 같은 열, 같은 대각선에 위치하면 안 된다.

각 행마다 퀸을 하나씩 배치한다.

1. 현재 행에서 퀸을 놓을 열을 선택
2. 이전에 놓은 퀸들과 충돌하는지 확인
3. 충돌하지 않으면 다음 행으로 이동
4. 충돌하면 그 경우는 더 탐색하지 않고 다른 열을 선택
5. `N`개의 퀸을 모두 배치하면 하나의 정답

### 핵심

> 각 행에서 가능한 위치를 하나씩 선택하고,  
> 현재 배치가 불가능하다고 판단되면 그 아래 경우는 더 탐색하지 않고 이전 단계로 돌아간다.

```java
public class Main{
	static int N;
	static int count;
	
	// board[row] = col;
	// row행에 있는 퀸이 col열에 있다는 의미
	static int[] board;
	
	public static void main(String[] args){
		N = 4;
		board = new int[N];
		nQueen(0);
		System.out.println(count);
	}
	
	static void nQueen(int row){
		// N개의 퀸을 모두 배치한 경우
		if(row == N){
			count++;
			return;
		}
		
		// 현재 row에 퀸을 놓을 열 선택
		for(int col = 0; col < N; col++){
			board[row] = col;
			
			// 현재 위치에 퀸을 놓을 수 있다면
			if(isPossible(row)){
				nQueen(row+1);
			}
			
			// 놓을 수 없는 위치면 다음 행으로 안넘어가고 다음 열일 때 검사를 함
		}
	}
	
	static boolean isPossible(int row){
		// 이전 행에 놓인 퀸들과 비교
		for(int i = 0; i<row; i++){
			// 같은 열
			if(board[i] == board[row]){
				return false;
			}
			
			// 같은 대각선
			// 체스판의 대각선은 한 칸 아래로 내려갈 때 열도 한 칸 옆으로 이동하는 방향
			if(Math.abs(row-i) == Math.abs(board[row]-board[i])){
				return false;
			}
		}
		
		return true;
	}
}
```
