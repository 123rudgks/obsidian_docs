# 백트래킹

백트래킹은 가능한 경우를 탐색하다가 더 볼 필요가 없거나 현재 선택을 모두 확인했다면 이전 상태로 돌아가 다른 선택을 시도하는 방법이다.

> 선택 → 탐색 → 선택 취소 → 다른 선택 탐색

## 완전탐색과 백트래킹

```text
완전탐색
└─ 가능한 모든 경우를 끝까지 확인

백트래킹
└─ 경우의 수를 탐색하다가
   현재 경로가 답이 될 수 없다고 판단되면
   그 아래 경우는 확인하지 않고 이전 단계로 돌아감
```

재귀 함수가 이전 호출로 복귀한다고 해서 모든 재귀가 백트래킹인 것은 아니다.

```text
재귀의 복귀 ≠ 백트래킹
```

백트래킹에서는 현재 선택 상태를 바꾸고, 탐색하고, 다시 원상복구하여 다른 선택을 시도하는 구조가 자주 사용된다.

## 가지치기(Pruning)

가지치기는 **현재 상태가 정답으로 이어질 수 없다고 판단되면 그 아래의 경우를 더 이상 탐색하지 않는 것**이다.

### 목적

- 불필요한 탐색을 제거
- 탐색해야 하는 상태 수를 줄임
- 실행 시간을 줄임

예:

```java
if (!isPossible(state)) {
    return;
}
```

중요한 점은 **정답이 될 가능성이 있는 경로를 잘못 제거하면 안 된다는 것**이다.

가지치기가 거의 일어나지 않는 최악의 경우에는 완전탐색과 비슷한 수의 상태를 확인할 수도 있다.

## 대표 문제 — N-Queen

`N × N` 체스판에 퀸 N개를 서로 공격할 수 없도록 배치한다.

각 행마다 퀸을 하나씩 배치한다고 하면

1. 현재 행에서 퀸을 놓을 열 선택
2. 이전에 놓은 퀸들과 충돌하는지 확인
3. 가능하면 다음 행으로 이동
4. 불가능하면 다음 열을 확인 → **가지치기**
5. N개의 퀸을 모두 배치하면 정답 하나 완성

```java
public class Main {
    static int N;
    static int count;
    static int[] board;

    public static void main(String[] args) {
        N = 4;
        board = new int[N];

        nQueen(0);
        System.out.println(count);
    }

    static void nQueen(int row) {
        if (row == N) {
            count++;
            return;
        }

        for (int col = 0; col < N; col++) {
            board[row] = col;

            if (isPossible(row)) {
                nQueen(row + 1);
            }
        }
    }

    static boolean isPossible(int row) {
        for (int i = 0; i < row; i++) {
            if (board[i] == board[row]) {
                return false;
            }

            if (Math.abs(row - i) == Math.abs(board[row] - board[i])) {
                return false;
            }
        }

        return true;
    }
}
```

## 핵심

> 백트래킹의 가지치기는 정답이 될 수 없는 경로를 조기에 제거하여 불필요한 탐색을 줄이는 것이 목적이다.
