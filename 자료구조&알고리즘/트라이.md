스마트폰 자동 완성 기능을 구현한다고 할 때 [[배열]]이라면 배열 내의 모든 단어를 검색해야 한다. O(N)
[[해시 테이블]]이라면 단어를 통째로 해싱하지 않으면 값을 찾을 수 없다. (catn을 해싱하지 않으면 catnip이나 catnap을 찾기 어렵다.)
물론, 정렬된 배열을 사용한다면 O(logN)으로 값을 찾을 수 있기에 낫지만 그보다 더 나은 방법이 있다.

트라이는 자동 완성 같은 텍스트 기반 기능에 이상적
> 트라이라는 이름은 retrieval(추출)에서 유래했다. 따라서 발음 따라 트리로 읽어야 하지만 이미 트리라는 자료구조가 있어서 트라이라고 부르기로 했다.

이진 [[트리]]와 다르게 트라이는 노드에 2개 이상의 자식이 있어도 된다.(자식 노드 개수에 제한이 없다.)

트라이는 여러 방식으로 구현이 가능하지만 여기서는 해시 테이블을 사용하여 구현을 한다.


```java
import java.util.HashMap;
import java.util.Map;

public class Trie{
	// Trie의 노드
	private static class Node{
		// 자식 노드들을 문자 -> 노드 형태로 저장
		Map<Character, Node> children = new HashMap<>();
		
		// 이 노드에서 하나의 단어가 끝나는지 여부
		boolean isEndOfWord = false;
	}
	
	// 루트 노드
	private final Node root = new Node();
	
	// 단어 삽입
	public void insert(String word){
		Node current = root;
		
		for (char ch : word.toCharArray()){
			// 해당 문자의 자식 노드가 없다면 새로 생성
			current.children.putIfAbsent(ch, new Node());
			// 다음 노드로 이동
			current = current.children.get(ch);
			
		}
		// 마지막 노드에서 단어가 끝난다는 표시
		current.isEndOfWord = true;
	}
	
	// 단어 검색
	public boolean search(String word){
		Node current = root;
		for (char ch : word.toCharArray()){
			// 해당 문자가 존재하지 않으면 단어가 없음
			if(!current.children.containsKey(ch)){
				return false;
			}
			current = current.children.get(ch);
		}
		// 경로가 존재하더라도 실제 단어로 등록되어 있어야 함
		return current.isEndOfWord;
	}
	
	// 접두사 검색
	public boolean startWith(String prefix){
		Node current = root;
		
		for (char ch : prefix.toCharArray()){
			if(!current.children.containsKey(ch)){
				return false;
			}
			current = current.children.get(ch);
		}
		return true;	
	}
	
	public List<String> getWordsWithPrefix(String prefix){
		List<String> result = new ArrayList<>();
		Node current = root;
		
		// prefix가 끝나는 노드까지 이동
		for(char ch : prefix.toCharArray()){
			if(!current.children.containsKey(ch)){
				return result;
			}
			current = current.children.get(ch);
		}
		// 해당 노드부터 단어 수집
		collectWords(current, prefix, result);
	}
	private void collectWords(Node node, String currentWord, List<String> result){
		if(node.isEndOfWord){
			result.add(currentWord);
		}
		for(Map.Entry<Character, Node> entry : node.children.entrySet()){
			char ch = entry.getKey();
			Node child = entry.getValue();
			
			collectWords(child, currentWord + ch, result);
		}
	}
	
	public static void main(String[] args){
		Trie trie = new Trie();
		trie.insert("apple");
		trie.insert("app");
		
		System.out.println(trie.search("apple"));
		System.out.println(trie.search("app"));
	}
}
```


L : 삽입 또는 검색하려는 단어의 문자 길이 
N : 자료구조 내의 원소 개수

| 연산                    | 평균 시간복잡도 |
| --------------------- | -------: |
| 삽입 `insert()`         |   `O(L)` |
| 단어 검색 `search()`      |   `O(L)` |
| 접두사 검색 `startsWith()` |   `O(L)` |
배열은 O(N)이 소요 된다.


단어 별 인기도 점수를 포함한 트라이 코드
```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Trie {

    // Trie의 노드
    private static class Node {

        // 자식 노드들을 문자 -> 노드 형태로 저장
        Map<Character, Node> children = new HashMap<>();

        // 이 노드에서 하나의 단어가 끝나는지 여부
        boolean isEndOfWord = false;

        // 단어의 인기도 (1 ~ 10)
        // 단어가 끝나는 노드에서만 의미가 있음
        int popularity = 0;
    }


    // 단어와 인기도를 함께 반환하기 위한 클래스
    public static class WordInfo {
        String word;
        int popularity;

        WordInfo(String word, int popularity) {
            this.word = word;
            this.popularity = popularity;
        }

        @Override
        public String toString() {
            return word + " (" + popularity + ")";
        }
    }


    // 루트 노드
    private final Node root = new Node();


    // =========================
    // 단어 삽입
    // =========================
    public void insert(String word, int popularity) {

        // 인기도 범위 검사
        if (popularity < 1 || popularity > 10) {
            throw new IllegalArgumentException(
                    "인기도는 1부터 10 사이여야 합니다."
            );
        }

        Node current = root;

        for (char ch : word.toCharArray()) {

            // 해당 문자의 자식 노드가 없다면 새로 생성
            current.children.putIfAbsent(ch, new Node());

            // 다음 노드로 이동
            current = current.children.get(ch);
        }

        // 마지막 노드에서 단어가 끝난다는 표시
        current.isEndOfWord = true;

        // 단어의 인기도 저장
        current.popularity = popularity;
    }


    // =========================
    // 단어 검색
    // =========================
    public boolean search(String word) {

        Node current = root;

        for (char ch : word.toCharArray()) {

            if (!current.children.containsKey(ch)) {
                return false;
            }

            current = current.children.get(ch);
        }

        return current.isEndOfWord;
    }


    // =========================
    // 단어의 인기도 검색
    // =========================
    public int getPopularity(String word) {

        Node current = root;

        for (char ch : word.toCharArray()) {

            if (!current.children.containsKey(ch)) {
                return -1;
            }

            current = current.children.get(ch);
        }

        // 실제 등록된 단어가 아니라면 -1
        if (!current.isEndOfWord) {
            return -1;
        }

        return current.popularity;
    }


    // =========================
    // 접두사 검색
    // =========================
    public boolean startsWith(String prefix) {

        Node current = root;

        for (char ch : prefix.toCharArray()) {

            if (!current.children.containsKey(ch)) {
                return false;
            }

            current = current.children.get(ch);
        }

        return true;
    }


    // =========================
    // 특정 접두사의 단어 수집
    // =========================
    public List<WordInfo> getWordsWithPrefix(String prefix) {

        List<WordInfo> result = new ArrayList<>();

        Node current = root;

        // prefix가 끝나는 노드까지 이동
        for (char ch : prefix.toCharArray()) {

            if (!current.children.containsKey(ch)) {
                return result;
            }

            current = current.children.get(ch);
        }

        // 해당 노드부터 단어 수집
        collectWords(current, prefix, result);

        return result;
    }


    // =========================
    // DFS로 단어 수집
    // =========================
    private void collectWords(
            Node node,
            String currentWord,
            List<WordInfo> result) {

        // 하나의 완성된 단어라면
        if (node.isEndOfWord) {

            result.add(
                    new WordInfo(
                            currentWord,
                            node.popularity
                    )
            );
        }

        // 모든 자식 탐색
        for (Map.Entry<Character, Node> entry
                : node.children.entrySet()) {

            char ch = entry.getKey();
            Node child = entry.getValue();

            collectWords(
                    child,
                    currentWord + ch,
                    result
            );
        }
    }


    // =========================
    // 실행
    // =========================
    public static void main(String[] args) {

        Trie trie = new Trie();

        trie.insert("apple", 10);
        trie.insert("app", 8);
        trie.insert("apply", 6);
        trie.insert("application", 9);
        trie.insert("banana", 5);

        System.out.println(trie.search("apple"));
        System.out.println(trie.search("app"));

        System.out.println(
                "apple 인기도: "
                        + trie.getPopularity("apple")
        );

        System.out.println(
                "app 인기도: "
                        + trie.getPopularity("app")
        );


        List<WordInfo> words =
                trie.getWordsWithPrefix("app");

        for (WordInfo wordInfo : words) {
            System.out.println(wordInfo);
        }
    }
}
```

result.sort((a,b)->Integer.compare(b.popularity,a.popularity));
