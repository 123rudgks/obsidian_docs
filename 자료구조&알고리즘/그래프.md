# 그래프

[[트리]]는 그래프의 한 종류이다.

트리는 사이클이 없고 모든 노드가 서로 연결되어 있지만, 일반 그래프는 사이클이 존재하거나 일부 정점이 서로 연결되어 있지 않을 수도 있다.

## 그래프 기본 용어

- 정점(vertex): 그래프를 구성하는 점
- 간선(edge): 두 정점을 연결하는 선
- 경로(path): 한 정점에서 다른 정점까지 이어지는 **연속된 정점 또는 간선의 나열**
- 연결 그래프: 모든 정점이 서로 어떤 경로로든 연결된 그래프
- 방향 그래프: 간선에 방향이 있는 그래프
- 무방향 그래프: 간선에 방향이 없는 그래프
- 가중 그래프: 간선에 거리, 비용 등의 값이 있는 그래프

## 차수(Degree)

### 무방향 그래프

정점의 차수(degree)는 해당 정점에 연결된 간선의 개수이다.

```text
A -- B -- C
     |
     D
```

B에는 A, C, D와 연결된 간선 3개가 있으므로

```text
degree(B) = 3
```

무방향 그래프에서는 간선 하나가 양쪽 정점의 차수에 각각 1씩 포함되므로

```text
모든 정점의 차수 합 = 2E
```

이다.

### 방향 그래프

- 진입 차수(in-degree): 현재 정점으로 들어오는 간선 수
- 진출 차수(out-degree): 현재 정점에서 나가는 간선 수

방향 그래프에서는

```text
모든 진입 차수의 합 = E
모든 진출 차수의 합 = E
```

이다.

# 인접 행렬 vs 인접 리스트

## 인접 행렬

정점 간 연결 여부를 `V × V` 배열로 저장한다.

```text
    1 2 3
1 [ 0 1 1 ]
2 [ 1 0 0 ]
3 [ 1 0 0 ]
```

방향 그래프에서는

```text
행(row)의 합 → 해당 정점의 진출 차수
열(col)의 합 → 해당 정점의 진입 차수
```

로 볼 수 있다.

### 특징

- 공간복잡도: `O(V²)`
- 두 정점의 연결 여부 확인: `O(1)`
- 특정 정점의 모든 이웃 확인: `O(V)`

### 사용

- 정점 수가 작을 때
- 간선이 많은 밀집 그래프
- 두 정점의 연결 여부를 자주 확인할 때

---

## 인접 리스트

각 정점마다 실제로 연결된 정점만 저장한다.

```text
1 → [2, 3]
2 → [1]
3 → [1]
```

### 특징

- 공간복잡도: `O(V + E)`
- 연결 여부 확인: 보통 `O(degree)`
- 특정 정점의 이웃 탐색: `O(degree)`

### 사용

- 정점 수가 많을 때
- 간선이 적은 희소 그래프
- [[DFS]], [[BFS]]에서 연결된 정점들을 탐색할 때

---

## 차이

| 구분 | 인접 행렬 | 인접 리스트 |
|---|---|---|
| 저장 | 모든 정점 쌍 | 실제 연결된 정점만 |
| 공간 | `O(V²)` | `O(V + E)` |
| 연결 여부 확인 | `O(1)` | `O(degree)` |
| 한 정점의 이웃 탐색 | `O(V)` | `O(degree)` |
| 적합한 그래프 | 밀집 그래프 | 희소 그래프 |

> 인접 행렬 = 연결 여부 확인에 강함  
> 인접 리스트 = 메모리 효율 + 실제 이웃 탐색에 강함

## DFS / BFS 탐색 시간 복잡도

### 인접 리스트

```text
O(V + E)
```

이유:

- 각 정점을 한 번 방문 → `O(V)`
- 각 정점의 실제 인접 간선들을 확인 → 전체적으로 `O(E)`

따라서

```text
O(V + E)
```

이다.

### 인접 행렬

```text
O(V²)
```

정점 하나를 방문할 때마다 연결된 정점을 찾기 위해 해당 행의 V개 칸을 확인한다.

이 작업을 최대 V개의 정점에 대해 수행하므로

```text
V × V = O(V²)
```

이다.

> 그래프 탐색의 시간복잡도를 무조건 `O(V+E)`라고 외우면 안 된다. **그래프 표현 방식에 따라 달라진다.**

## 간선 리스트(Edge List)

그래프의 모든 간선을 하나씩 나열해서 저장한다.

```text
1 - 2 (비용 5)
1 - 3 (비용 2)
2 - 3 (비용 4)
```

```java
class Edge {
    int from;
    int to;
    int cost;
}

List<Edge> edges = new ArrayList<>();
```

### 특징

- 간선 자체를 순회하거나 정렬하기 편함
- 특정 정점의 인접 정점을 찾는 데는 비효율적
- [[Kruskal]], [[Bellman-Ford]] 등에 자주 사용

---

## 격자 그래프(Grid Graph)

2차원 배열의 각 칸을 하나의 정점으로 보는 방식이다.

```text
1 1 0
0 1 1
1 1 1
```

상하좌우로 이동할 수 있다면 그 이동 관계를 간선으로 본다.

```java
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};
```

### 활용

- 미로 탐색
- 섬 개수
- 연결 영역 개수
- 최단 거리
- 불 / 물 확산
- 게임 맵 이동

## 그래프 탐색의 핵심

그래프에는 사이클이 있을 수 있으므로 방문했던 정점을 기록하지 않으면 같은 정점을 계속 방문할 수 있다.

```java
boolean[] visited = new boolean[V];
```

그래프 탐색에는 [[DFS]]와 [[BFS]]가 널리 사용된다.
