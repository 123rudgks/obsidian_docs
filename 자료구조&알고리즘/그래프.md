[[트리]]는 그래프의 한 종류이다.
트리는 사이클이 없고 모든 노드가 서로 연결되어있는 그래프이다.

그래프 기본 용어
- 정점(vertex), 간선(edge)
- 경로(path)
	한 정점에서 다른 정점으로 가는 간선들의 순열
- 연결 그래프
	모든 정점이 어떻게든 서로 연결 되어있는 그래프
- 방향 그래프
	정점간 연결이 되어있을 때 한쪽만 일방적으로 연결이 되어있고 다른 쪽은 그렇지 않은 경우도 있다. 화살표로 이를 표현할 수 있고 이런 그래프를 방향 그래프라고 부른다.
- 가중 그래프
	간선에 정보를 추가한 그래프 (ex : 거리, 비용 등등)

연결 그래프를 사용한다면 정점 하나에만 접근 할 수 있을 때 모든 정점을 찾을 수 있다.

## 인접 리스트 vs 인접 행렬

### 인접 행렬

정점 간 연결 여부를 `N x N` 배열로 저장한다.
```text
    1 2 3
1 [ 0 1 1 ]
2 [ 1 0 0 ]
3 [ 1 0 0 ]
````

### 특징

- 공간복잡도: `O(V²)`
- 두 정점의 연결 여부 확인: `O(1)`
- 특정 정점의 이웃 전체 탐색: `O(V)`

### 사용

- 정점 수가 작을 때
- 간선이 많은 그래프
- 두 정점의 연결 여부를 자주 확인할 때

---

### 인접 리스트

각 정점마다 실제로 연결된 정점만 저장한다.

```text
1 → [2, 3]
2 → [1]
3 → [1]
```

### 특징
- 공간복잡도: `O(V + E)`
- 연결 여부 확인: 보통 `O(degree)`
- 특정 정점의 이웃 탐색: `O(degree)`

### 사용
- 정점 수가 많을 때
- 간선이 적은 그래프
- DFS / BFS에서 연결된 정점들을 탐색할 때

---

## 차이

|구분|인접 행렬|인접 리스트|
|---|---|---|
|저장|모든 정점 쌍|실제 연결된 정점만|
|공간|`O(V²)`|`O(V + E)`|
|연결 여부 확인|`O(1)`|`O(degree)`|
|이웃 탐색|`O(V)`|`O(degree)`|
|적합한 그래프|간선이 많음|간선이 적음|

## 핵심

> 인접 행렬 = 연결 여부 확인에 강함  
> 인접 리스트 = 메모리 효율 + 이웃 탐색에 강함

코딩테스트에서는 일반적으로 **인접 리스트를 더 자주 사용**한다.


## 그래프에서의 탐색
1. 그래프 어딘가에 있는 특정 정점 찾기
2. 그래프 내 한 정점에 접근할 수 있을 때 그 정점과 어떻게든 연결된 또 다른 특정 정점을 찾기
### 용도
1. 임의의 정점 하나만 접근 할 수 있으면 탐색으로 전체 그래프 내 어떤 정점이든 찾을 수 있다.
2. 두 정점이 서로 연결 되어있는지 알아낼 수 있다.
3. 그래프의 모든 정점에 어떤 연산을 수행할 수 있다.

> 그래프 탐색의 핵심은 지금까지 어떤 정점을 방문했는지 기록 하는 것. 그렇지 않다면 무한 사이클에 빠진다.
> [[해시 테이블]]로 방문했던 정점을 기록할 수 있다.
> `key:정점 - value:boolean(방문 여부)`


그래프 탐색에는 [[DFS]]와 [[BFS]]가 널리 사용된다.

### 그래프 탐색의 효율성
`O(V+E)` 여기서 V는 정점의 개수 E는 간선의 개수를 의미
	 각 정점과 정점의 인접 정점들을 같이 확인해야 하기 때문에
