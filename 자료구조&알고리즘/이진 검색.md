핵심은 `mid`를 기준으로 탐색 범위를 계속 절반으로 줄이는 것. 따라서 시간 복잡도는 **O(log n)**이고, 이진 검색을 사용하려면 배열이 반드시 **정렬되어 있어야 함**.


로직 설명
1. 원소들이 정렬이 되어있을 때를 가정으로 함 (아래 설명에선 오름차순으로 가정)
2. 데이터들 중 중앙값을 찾고 검색하려는 값과 비교
3. 중앙값이 검색하려는 값보다 더 작을 경우 중앙값 기준 왼쪽 원소들만 확인
4. 왼쪽 원소들 중 다시 중앙값 찾아 검색하려는 값과 비교
5. 위 단계 반복
6. 최종적으로 값을 찾게 됨

구현 코드 예시
```java
public class BinarySearchExample {
	public static int binarySearch(int[] arr, int target){
		int left = 0;
		int right = arr.length-1;
		
		while(left<=right){
			int mid = left + (right - left)/2;
			
			if(arr[mid]==target){
				return mid; // 찾은 값의 인덱스 반환
			} else if(arr[mid] < target){
				left = mid + 1;
			}else{
				right = mid - 1;
			}
		}
		
		return -1; // 값을 못 찾은 경우
	}
}

// 사용 예시
public static void main(String[] args){
	int[] numbers = {1, 3, 5, 7, 9, 11, 13, 15};
	int target = 11;
	
	int result = binarySearch(numbers, target);
	
	if(result != -1){
		System.out.println("searched value index : "+ result);
	}else{
		System.out.println("no value searched)
	}
}
```
