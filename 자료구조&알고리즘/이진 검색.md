# 이진 검색

이진 검색(Binary Search)은 `mid`를 기준으로 탐색 범위를 계속 절반으로 줄이는 탐색 방법이다.

시간 복잡도는

```text
O(log N)
```

이다.

## 사용 조건

가장 기본적인 이진 검색에서는

> **탐색 대상이 정렬되어 있어야 한다.**

정렬되어 있기 때문에 `mid`와 target의 크기를 비교하여 한쪽 절반을 버릴 수 있다.

## 로직

오름차순 배열을 기준으로 한다.

1. `left`, `right` 범위의 중앙 `mid`를 계산
2. `arr[mid] == target` → 찾음
3. `arr[mid] < target` → target은 더 큰 값이므로 **오른쪽 탐색**, `left = mid + 1`
4. `arr[mid] > target` → target은 더 작은 값이므로 **왼쪽 탐색**, `right = mid - 1`
5. `left > right`가 되면 값이 없음

## 핵심 패턴

```java
while (left <= right) {
    int mid = left + (right - left) / 2;

    if (arr[mid] == target) {
        return mid;
    } else if (arr[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}
```

## 구현

```java
public class BinarySearchExample {
    public static int binarySearch(int[] arr, int target) {
        int left = 0;
        int right = arr.length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (arr[mid] == target) {
                return mid;
            } else if (arr[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return -1;
    }

    public static void main(String[] args) {
        int[] numbers = {1, 3, 5, 7, 9, 11, 13, 15};
        int target = 11;

        int result = binarySearch(numbers, target);

        if (result != -1) {
            System.out.println("searched value index : " + result);
        } else {
            System.out.println("no value searched");
        }
    }
}
```

## 핵심

```text
arr[mid] < target → 오른쪽 → left = mid + 1
arr[mid] > target → 왼쪽   → right = mid - 1
```

> 이진 검색은 정렬된 상태를 이용하여 한 번 비교할 때마다 탐색 범위를 절반씩 제거한다.
