핵심은:
> **매 순간 현재 상황에서 가장 좋아 보이는 선택을 하는 방식**
> 그러나 매 순간 최선의 선택을 했다고 해서 항상 전체 최적해가 되는 것은 아니다.

그래서 그리디 문제는 보통 **왜 이 선택이 전체 최적해를 보장하는지**가 중요
>현재 단계에서 내가 선택한 그리디 선택을 포함하는 최적해가 반드시 존재한다

즉 단순히
```
지금 제일 좋아 보이니까 선택
```
하면 안 되고,
```
이 선택을 해도 최적해를 놓치지 않는다
```
는 근거가 필요합니다.

**대표 문제1(Knapsack)**
그리디 알고리즘 판단 기준 
	그리디는 단순히 `분할 가능/불가능`으로 판단하는 것이 아니라, > **현재의 최선 선택이 미래의 더 좋은 조합을 방해하지 않는가?** 를 확인해야 한다.

예시
	- Fractional Knapsack → 현재 좋은 선택이 이후 선택을 망치지 않음 → 그리디 가능 
	- 0-1 Knapsack → 현재 선택이 더 좋은 조합을 막을 수 있음 → 그리디 불가

| Note. 0-1 Knapsack은 보통 [[동적 프로그래밍]]으로 푼다.

```java
import java.io.*; 
import java.util.*;

public class Main{
	static class Item{
		int weight;
		int value;
		double ratio;
		
		Item(int weight, int value){
			this.weight = weight;
			this.value = value;
			this.ratio = (double) value / weight;
		}
	}
	
	public static void main(String[] args) throws Exception{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		StringTokenizer st = new StringTokenizer(br.readLine());
		
		int N = Integer.parseInt(st.nextToken());
		int W = Integer.parseInt(st.nextToken());
		
		Item[] items = new Item[N];
		
		for(int i = 0; i < N; i++){
			st = new StringTokenizer(br.readLine());
			
			int weight = Integer.parseInt(st.nextToken());
			int value = Integer.parseInt(st.nextToken());
			
			items[i] = new Item(weight, value);
		}
		
		// 가치 / 무게 비율이 높은 순서
		Arrays.sort(items, (a,b)->Double.compare(b.ratio, a.ratio));
		
		int remain = W;
		double totalValue = 0;
		
		for(Item item : items){
			if(remain == 0){
				break;
			}
			// 물건 전체를 넣을 수 있는 경우
			if(item.weight <= remain){
				remain -= item.weight;
				totalValue += item.value;
			}else{
				// 남은 공간만큼 일부만 넣음
				totalValue += item.ratio * remain;
				remain = 0;
			}
		}
		System.out.println(totalValue);
	}
}
```



**대표 문제2 (동전 자판기)**
핵심
> 문제의 관점을 최대로 사용할 동전의 갯수가 아니라 최소로 뺄 동전의 갯수로 바꾸어 그리디 적용 조건을 맞추는 것(그리디 조건 + 최적 부분 해)

```java
import java.io.*; 
import java.util.*;

public class Main{
	public static void main(String[] args) throws Exception{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		// 음료수 가격
		int W = Integer.parseInt(br.readLine());
		// 동전 단위
		int[] coins = {500,100,50,10,5,1};
		// 보유 동전 개수
		int[] count = new int[6];
		
		StringTokenizer st = new StringTokenizer(br.readLine());
		
		int totalPrice = 0;
		int totalCount = 0;
		
		for(int i = 0; i < 6; i++){
			count[i] = Integer.parseInt(st.nextToken());
			
			totalPrice += coins[i] * count[i];
			totalCount += count[i];
		}
		
		// 사용하지 않아야 하는 금액
		int remain = totalPrice - W;
		// 실제 사용할 동전 개수
		int[] used = count.clone();
		
		// 큰 동전부터 최대한 사용하지 않도록 제거
		for(int i = 0; i<6; i++){
			int removeCount = Math.min(count[i], remain / coins[i]);
			used[i] -= removeCount;
			totalCount -= removeCount;
			
			remain -= removeCount * coins[i];
		}
		// 사용되는 최대 동전 개수
		System.out.println(totalCount);
		
		// 각 동전별 사용 개수
		for(int i = 0; i < 6; i++){
			System.out.print(used[i]);
			
			if(i < 5){
				System.out.print(" ");
			}
		}
	}
}
```
