[[정렬]]
삽입 정렬은 **앞쪽 부분이 이미 정렬되어 있다고 보고, 현재 값을 알맞은 위치에 끼워 넣는 방식**
시간 복잡도는 **최선 Θ(n)**, **평균 Θ(n²)** , **최악 Θ(n²)** 이다. 이미 거의 정렬된 데이터에서는 꽤 효율적이라는 특징이 있다.

1. 인덱스 1의 값을 삭제 하여 공백을 만든 후 이를 임시 변수에 저장한다.
2. 삭제한 인덱스 1 왼쪽의 값을 가져와 임시 변수와 비교한다.
3. 값이 임시 변수보다 클 경우 그 값을 오른쪽으로 shift 한다. (임시로 삭제한 값보다 작은 값을 만나거나 배열의 왼쪽 끝에 도달해야 시프트가 끝난다.)
4. 임시로 제거한 값을 공백에 추가한다.
5. 인덱스를 1 올린다.
6. 배열의 마지막 인덱스에서 패스스루를 시작할 때 까지 패스스루를 반복한다.

코드 예시
```java
public static void insertionSort(int[] arr){
	for(int i=1; i <arr.length; i++){
		int key = arr[i];
		int j = i -1;
		
		// key보다 큰 값을 오른쪽으로 한 칸씩 이동
		while(j>=0&&arr[j] > key){
			arr[j+1] = arr[j];
			j--;
		}
		// key가 들어갈 위치에 삽입
		arr[j+1] = key;
	}
}

public static void main(String[] args){
	int[] numbers = {5,3,8,4,2};
	insertionSort(numbers);
	
	for(int number: numbers){
		System.out.print(number + " ");
	}
}
```
