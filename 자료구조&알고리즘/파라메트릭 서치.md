
> **정답 범위에서 특정 값이 가능한지 판정하며 [[이진 검색]]하는 기법**
> **최적화 문제를 "이 값이 가능한가?"라는 결정 문제로 바꿔 이분 탐색한다.**
## 핵심 조건

- 정답 후보에 **단조성**이 있어야 함
	예: `불가능 → 불가능 → 가능 → 가능`

## 핵심 흐름

```text
mid 선택
→ possible(mid)로 가능 여부 판정
→ 가능/불가능에 따라 범위를 절반으로 줄임
```

# 대표 문제
[입국심사](https://school.programmers.co.kr/learn/courses/30/lessons/43238)


```java
class Solution{
	public long solution(int n, int[] times){
		long left = 1;
		long right = 0;
		
		// 가장 오래 걸리는 심사관이 모든 사람을 심사하는 경우
		for(int time : times){
			right = Math.max(right, time);
		}
		
		right *= n;
		
		long answer = right;
		
		while(left <= right){
			long mid = left + (right - left) / 2;
			long count = 0;
			
			// mid 시간 동안 심사 가능한 사람 수
			for(int time : times){
				count += mid/time;
				if(count >= n){
					break;
				}
			}
			
			if(count >= n){
				// mid 시간 안에 가능
				answer = mid;
				right = mid - 1;
				
			}else{
				// mid 시간 안에 불가능
				left = mid + 1;
			}
		}
		
		return answer;
	}
}
```

> `long mid = left + (right - left) / 2` 는 `long mid = (left + right) / 2` 와 같은데 `left + right`가 `long`의 최대 값을 넘어 오버플로우가 날 것을 막기 위해 변형한 것
