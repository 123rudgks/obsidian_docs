[[배열]]과 마찬가지로 항목의 리스트를 표현하는 자료구조

배열 vs 연결리스트
배열은 연속된 메모리 주소를 가지고 있기 때문에 프로그램은 배열이 어떤 메모리 주소부터 시작하는지 알면  원하는 인덱스에 바로 접근할 수 있다.
연결리스트는 연속된 메모리 블록이 아니라 컴퓨터 메모리 전체에 여러 셀에 퍼져있을 수 있다.

데이터가 컴퓨터 메모리 전체에 흩어져 있다는 것이 연속된 전체 셀 블록을 찾지 않아도 되어서 배열보다 더 유리할 수 있다.

노드
메모리 곳곳에 흩어져 연결된 데이터
노드는 다음 노드의 메모리 주소를 포함한다. 다음 노드의 메모리 주소로의 포인터를 링크라고 한다.

첫번째 노드는 헤드(head), 마지막 노드는 테일(tail)

```java
public class SignlyLinkedList{
	// Node Class
	private static class Node {
		int data;
		Node next;
		
		Node(int data){
			this.data = data;
			this.next = null;
		}
	}
	
	// 연결 리스트의 시작 노드
	private Node head;
	
	// 맨 앞에 삽입
	public void addFirst(int data){
		Node newNode = new Node(data);
		
		newNode.next = head;
		head = newNode;
	}
	
	// 맨 뒤에 삽입
	public void addList(int data){
		Node newNode = Node(data);
		
		if(head==null){
			head = newNode;
			return;
		}
		Node current = head;
		
		while(current.next != null){
			current = current.next;
		}
		current.next = newNode;
	}
	
	// 특정 값 검색
	public boolean contains(int data){
		Node current = head;
		while(current != null){
			if(current.data == data){
				return true;
			}
			current = current.next;
		}
		return false;
	}
	
	// 특정 값 삭제
	public void remove(int data){
		// 리스트가 비어있는 경우
		if(head == null){
			return;
		}
		// head를 삭제해야 하는 경우
		if(head.data == data){
			head = head.next;
			return;
		}
		
		Node current = head;
		
		// 삭제할 노드의 "바로 이전 노드" 찾기
		while(current.next != null){
			if(current.next.data == data){
			current.next = current.next.next;
			return;
			}
			current = current.next;
		}
	}
	// 리스트 출력
	public void printList(){
		Node current = head;
		
		while(current != null){
			System.out.print(current.data + " -> "); 
			current = current.next;
		}
		System.out.println("null");
	}
	
	public static void main(String[] args){
		SinglyLinkedList list = new SinglyLinkedList();
		
		list.addLast(10);
		list.addFirst(5);
		list.remove(20);
		list.printList();
		
	}
}
```

연결리스트의 읽기
리스트의 마지막 노드를 읽으려면 마지막 노드까지 순회해야하기 때문에 O(N)이 걸린다.

연결리스트의 검색
검색하려는 값을 찾을때 까지 순회해야 하기 때문에 O(N)이 걸린다.

연결리스트의 삽입
[[배열]]은 삽입 시 shift가 일어나는 반해, 연결 리스트는 노드간의 재연결만 해주면 된다.
그러나 삽입하려는 위치까지 순회를 해야하기 때문에 O(n)이 소요된다.
단, 맨 앞에 삽입을 할 시에는 O(1)만 소요된다.

연결리스트의 삭제
삽입과 마찬가지로 배열은 shift가 일어나지만 연결 리스트는 노드간의 재연결만 필요하다.
그러나 삽입과 마찬가지로 해당 위치까지 순회해야하므로 O(n)이 소요된다.

| 자료구조   | 연산          |   최선 |   평균 |   최악 |
| ------ | ----------- | ---: | ---: | ---: |
| 배열     | 읽기 (인덱스 접근) | O(1) | O(1) | O(1) |
| 배열     | 검색 (값 찾기)   | O(1) | O(n) | O(n) |
| 배열     | 삽입          | O(1) | O(n) | O(n) |
| 배열     | 삭제          | O(1) | O(n) | O(n) |
| 연결 리스트 | 읽기 (인덱스 접근) | O(1) | O(n) | O(n) |
| 연결 리스트 | 검색 (값 찾기)   | O(1) | O(n) | O(n) |
| 연결 리스트 | 삽입          | O(1) | O(n) | O(n) |
| 연결 리스트 | 삭제          | O(1) | O(n) | O(n) |

배열은 끝에 삽입 또는 삭제할 때, 연결리스트는 앞에 삽입 또는 삭제할 때 유리하다.

연결리스트에서 노드가 삭제되면 노드가 고립되는 데 연결리스트에서는 삭제가 되었을 지언정 메모리 상으론 아직 남아있다. (자바에선 "가비지 컬렉터"가 제거해준다.)

연결리스트는 한 리스트를 검사하여 많은 원소를 삽입 또는 삭제할 때 유리하다.

# 이중 연결리스트

이중 연결 리스트는 첫 번째 노드 외에 마지막 노드도 기록한다.
따라서 리스트 앞과 끝에서 읽기,삽입,삭제시 O(1)이 걸린다.

```java
public class DoublyLinkedList {

    // 노드 클래스
    private static class Node {
        int data;

        Node prev; // 이전 노드
        Node next; // 다음 노드

        Node(int data) {
            this.data = data;
            this.prev = null;
            this.next = null;
        }
    }

    // 리스트의 첫 번째 노드
    private Node head;

    // 리스트의 마지막 노드
    private Node tail;


    // 맨 앞에 삽입
    public void addFirst(int data) {

        Node newNode = new Node(data);

        // 리스트가 비어 있는 경우
        if (head == null) {
            head = newNode;
            tail = newNode;
            return;
        }

        newNode.next = head;
        head.prev = newNode;

        head = newNode;
    }


    // 맨 뒤에 삽입
    public void addLast(int data) {

        Node newNode = new Node(data);

        // 리스트가 비어 있는 경우
        if (tail == null) {
            head = newNode;
            tail = newNode;
            return;
        }

        tail.next = newNode;
        newNode.prev = tail;

        tail = newNode;
    }


    // 특정 값 검색
    public boolean contains(int data) {

        Node current = head;

        while (current != null) {

            if (current.data == data) {
                return true;
            }

            current = current.next;
        }

        return false;
    }


    // 특정 값 삭제
    public void remove(int data) {

        Node current = head;

        // 삭제할 노드 검색
        while (current != null) {

            if (current.data == data) {

                // 이전 노드가 존재하는 경우
                if (current.prev != null) {
                    current.prev.next = current.next;
                }
                // head를 삭제하는 경우
                else {
                    head = current.next;
                }


                // 다음 노드가 존재하는 경우
                if (current.next != null) {
                    current.next.prev = current.prev;
                }
                // tail을 삭제하는 경우
                else {
                    tail = current.prev;
                }

                return;
            }

            current = current.next;
        }
    }


    // 앞에서부터 출력
    public void printForward() {

        Node current = head;

        while (current != null) {
            System.out.print(current.data + " <-> ");
            current = current.next;
        }

        System.out.println("null");
    }


    // 뒤에서부터 출력
    public void printBackward() {

        Node current = tail;

        while (current != null) {
            System.out.print(current.data + " <-> ");
            current = current.prev;
        }

        System.out.println("null");
    }


    public static void main(String[] args) {

        DoublyLinkedList list = new DoublyLinkedList();

        list.addLast(10);
        list.addFirst(5);
        System.out.println("20 존재 여부: " + list.contains(20));
        list.remove(20);

        list.printForward();
        // 뒤에서부터 출력
        list.printBackward();
    }
}
```


이중 연결리스트는 리스트의 앞과 끝 모두에 바로 접근 가능하기 때문에 [[큐]]를 위한 좋은 내부 자료 구조다.
(큐는 FIFO로 끝에 삽입하고 앞에서 삭제한다.)
이중 연결 리스트는 끝에 삽입하고 앞에 삭제하는데 모두 O(1)이다.
