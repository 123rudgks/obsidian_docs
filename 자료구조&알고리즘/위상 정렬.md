# 위상 정렬

## 위상(Topology)

그래프에서 정점들이 어떻게 연결되어 있고 어떤 선후 관계를 가지는지에 대한 구조를 의미한다.

## 위상 정렬

방향 그래프에서 **모든 선후 관계를 만족하도록 정점들을 일렬로 나열하는 알고리즘**이다.

```text
A → B
A → C
B → D
C → D
```

가능한 위상 정렬 결과:

```text
A → B → C → D
A → C → B → D
```

따라서 위상 정렬 결과는 하나로 유일하지 않을 수 있다.

## 전제 조건

위상 정렬은 **DAG(Directed Acyclic Graph)** 에서만 가능하다.

1. Directed → 방향 그래프
2. Acyclic → 사이클이 없음

사이클이 존재하면 서로가 서로보다 먼저 처리되어야 하는 관계가 생길 수 있으므로 위상 정렬이 불가능하다.

## 핵심 개념 — 진입 차수(In-degree)

현재 정점으로 들어오는 간선의 수이다.

```text
진입 차수 0
= 현재 정점보다 먼저 처리해야 할 정점이 없음
= 지금 처리 가능
```

## 기본 흐름 — Kahn 알고리즘

1. 모든 정점의 진입 차수를 계산
2. 진입 차수가 0인 모든 정점을 Queue에 삽입
3. Queue에서 정점 하나를 꺼내 결과에 추가
4. 해당 정점에서 나가는 간선을 제거한 효과로 다음 정점들의 진입 차수를 1 감소
5. 새롭게 진입 차수가 0이 된 정점을 Queue에 삽입
6. Queue가 빌 때까지 반복

## Java 구현

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

public class Main {
    static int V;
    static List<Integer>[] graph;
    static int[] indegree;

    static void topologicalSort() {
        Queue<Integer> queue = new ArrayDeque<>();

        for (int i = 0; i < V; i++) {
            if (indegree[i] == 0) {
                queue.offer(i);
            }
        }

        int processed = 0;

        while (!queue.isEmpty()) {
            int current = queue.poll();
            System.out.print(current + " ");
            processed++;

            for (int next : graph[current]) {
                indegree[next]--;

                if (indegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }

        if (processed < V) {
            System.out.println("사이클 존재 - 위상 정렬 불가능");
        }
    }
}
```

## 사이클 판별

위상 정렬 과정에서 처리한 정점의 수가 전체 정점 수보다 작다면 아직 처리하지 못한 정점들이 남아 있다는 뜻이다.

```text
processed < V
→ 사이클 존재
→ 위상 정렬 불가능
```

## 시간 복잡도

인접 리스트를 사용할 경우

```text
O(V + E)
```

- 각 정점을 한 번 처리
- 각 간선을 한 번 확인하며 진입 차수를 감소

## 활용

- 선수 과목 순서
- 작업 순서
- 빌드 순서
- 의존성 처리

## 핵심

> 위상 정렬을 사용할 수 있는 그래프의 구조적 조건은 **방향 그래프**이면서 **사이클이 없는 그래프**, 즉 DAG라는 것이다.
