
### 위상(Topology)
그래프에서 정점들이 **어떻게 연결되어 있고 어떤 선후 관계를 가지는지에 대한 구조**.

### 위상 정렬
방향 그래프에서 모든 선후 관계를 만족하도록 정점들을 일렬로 나열하는 알고리즘.

예:
```text
A → B
A → C
B → D
C → D
```

가능한 순서:
```text
A → B → C → D
A → C → B → D
```

### 조건
위상 정렬은 **DAG(Directed Acyclic Graph)** 에서만 가능하다.

- Directed: 방향 그래프
- Acyclic: 사이클이 없음

사이클이 존재하면 위상 정렬 불가능.

### 핵심 개념: 진입 차수(In-degree)

현재 정점으로 들어오는 간선의 개수.

```text
진입 차수 0
= 먼저 처리해야 할 정점이 없음
= 지금 처리 가능
```

### 기본 흐름
1. 모든 정점의 진입 차수를 계산
2. 진입 차수가 0인 정점을 Queue에 삽입
3. Queue에서 정점 하나를 꺼내 처리
4. 해당 정점과 연결된 다음 정점들의 진입 차수를 1 감소
5. 새롭게 진입 차수가 0이 된 정점을 Queue에 삽입
6. Queue가 빌 때까지 반복

### 활용
- 선수 과목
- 작업 순서
- 빌드 순서
- 의존성 처리

### 한 줄 정리
> 위상 정렬 = 그래프의 선후 관계를 지키면서 정점들을 순서대로 나열하는 알고리즘
