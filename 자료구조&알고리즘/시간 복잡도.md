# 시간 복잡도 계산

시험에서는 코드를 보고 반복 횟수와 탐색 범위가 어떻게 변하는지를 기준으로 시간 복잡도를 판단하면 된다.

## 대표 시간 복잡도

### O(1)
입력 크기와 관계없이 한 번의 연산만 수행한다.

```java
int value = arr[0];
```

### O(log N)
반복할 때마다 탐색 범위가 절반씩 줄어든다.

```java
for (int i = n; i > 1; i /= 2) {
    // 반복
}
```

[[이진 검색]]이 대표적이다.

### O(N)
N개의 원소를 한 번씩 확인한다.

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}
```

### O(N log N)
N번 반복하는 동안 내부 작업이 log N번 수행되는 형태이다.

```java
for (int i = 0; i < n; i++) {
    for (int j = 1; j < n; j *= 2) {
        // 반복
    }
}
```

바깥 반복은 N번, 안쪽 반복은 `log N`번이므로 `O(N log N)`이다.

병합 정렬도 대표적으로 `O(N log N)`이다.

### O(N²)
N번 반복하는 작업 안에서 다시 N번 반복한다.

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // 반복
    }
}
```

### O(2^N)
각 원소마다 선택 / 미선택처럼 두 가지 선택지가 생긴다.

```java
static void subset(int depth) {
    if (depth == n) return;

    subset(depth + 1); // 선택
    subset(depth + 1); // 미선택
}
```

[[부분집합]] 탐색이 대표적이다.

### O(N!)
첫 번째 자리에 N개, 두 번째 자리에 N-1개, 그 다음에는 N-2개 ... 의 선택지가 생긴다.

```java
static void permutation(int depth) {
    if (depth == n) return;

    for (int i = 0; i < n; i++) {
        if (visited[i]) continue;

        visited[i] = true;
        permutation(depth + 1);
        visited[i] = false;
    }
}
```

모든 원소의 [[순열]] 탐색이 대표적이다.

## 코드에서 시간 복잡도 계산하기

### 순차적으로 실행되는 코드

```java
for (int i = 0; i < n; i++) { } // O(N)
for (int i = 0; i < n; i++) { } // O(N)
```

두 반복문은 순서대로 실행되므로

```text
O(N) + O(N) = O(N)
```

### 중첩 반복문

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
    }
}
```

바깥 반복 N번마다 안쪽 반복 N번이 수행되므로

```text
O(N) × O(N) = O(N²)
```

### 반복문의 증가 폭

```java
for (int i = 0; i < n; i += 2) {
}
```

약 N/2번 반복하지만 시간 복잡도는 `O(N)`이다.

```java
for (int i = 1; i < n; i *= 2) {
}
```

1 → 2 → 4 → 8처럼 값이 두 배씩 증가하므로 `O(log N)`이다.

## 자주 연결되는 알고리즘

| 알고리즘 / 탐색 | 대표 시간 복잡도 |
|---|---:|
| 배열 한 번 순회 | `O(N)` |
| 이진 검색 | `O(log N)` |
| 인접 리스트 DFS / BFS | `O(V + E)` |
| 인접 행렬 DFS / BFS | `O(V²)` |
| 부분집합 완전탐색 | `O(2^N)` |
| N개 원소 전체 순열 | `O(N!)` |
| 비교 기반 정렬 | 보통 `O(N log N)` |

## 재귀 코드의 시간 복잡도

재귀 함수도 결국 **함수가 총 몇 번 호출되는지**를 생각하면 된다.

```java
static void func(int n) {
    if (n == 0) return;
    func(n - 1);
}
```

`n → n-1 → ... → 0`으로 총 N번 정도 호출되므로 `O(N)`이다.

반면 각 호출이 다시 두 번의 재귀 호출을 만든다면 호출 수가 급격히 증가할 수 있다.

```java
static void func(int n) {
    if (n == 0) return;
    func(n - 1);
    func(n - 1);
}
```

호출이 두 갈래로 계속 나뉘므로 `O(2^N)` 수준이 된다.
