데이터가 정렬되어있으면 여러 상황에서 효율적으로 사용이 가능하다. 그러나 [[배열]]은 시프트를 해야하고 [[해시 테이블]]은 순서를 유지하지 못한다.
순서를 유지하면서 빠른 검색과 삽입, 삭제가 가능한 자료구조가 필요할 때

트리도 [[연결리스트]]와 마찬가지로 노드 기반 자료구조이다.
- 루트 : 가장 상위 노드
- 부모 노드
- 자식 노드
- 자손 노드
- 조상 노드

균형 트리 : 모든 노드에서 하위 트리의 노드 개수가 같을때
불균형 트리 : 균형적이지 않고 한 쪽으로 노드 개수가 치우쳐져 있을 때
