# 트리

트리는 [[그래프]]의 한 종류로, **사이클이 없고 모든 노드가 서로 연결된 구조**이다.

트리도 [[연결리스트]]처럼 노드 기반 자료구조이다.

## 기본 용어

- 루트(root): 가장 상위의 노드
- 부모 노드(parent): 현재 노드의 바로 위에 연결된 노드
- 자식 노드(child): 현재 노드의 바로 아래에 연결된 노드
- 자손 노드(descendant): 현재 노드 아래에 연결된 모든 노드
- 조상 노드(ancestor): 현재 노드 위쪽에 연결된 모든 노드
- 형제 노드(sibling): 같은 부모를 가지는 노드
- 리프 / 단말 노드(leaf): 자식이 없는 노드
- 내부 노드(internal node): 하나 이상의 자식을 가진 노드
- 깊이(depth): 루트에서 해당 노드까지의 간선 수
- 레벨(level): 노드가 트리에서 위치한 단계. 수업/문맥에 따라 루트를 0 또는 1부터 세므로 기준을 확인한다.
- 높이(height): 해당 노드에서 가장 먼 리프까지 내려가는 간선 수. 트리의 높이는 루트의 높이이다.
- 차수(degree): 한 노드가 가진 자식의 수

## 균형 트리와 불균형 트리

- 균형 트리: 좌우 서브트리의 높이가 크게 치우치지 않은 트리
- 불균형 트리: 특정 방향으로 노드가 몰려 높이가 크게 치우친 트리

균형이 잘 잡혀 있으면 트리의 높이가 작게 유지되어 검색, 삽입, 삭제가 효율적인 경우가 많다.

## 이진 트리

각 노드가 최대 2개의 자식을 가지는 트리이다.

### 완전 이진 트리

마지막 레벨을 제외한 모든 레벨이 채워져 있고, 마지막 레벨은 왼쪽부터 차례대로 채워지는 이진 트리이다.

[[힙]]은 완전 이진 트리 구조를 사용한다.

### 포화 이진 트리

모든 레벨의 노드가 빈자리 없이 모두 채워진 이진 트리이다.

## 트리 순회

예를 들어 다음 트리가 있다고 하자.

```text
      A
     / \
    B   C
   / \
  D   E
```

### 전위 순회(Preorder)

```text
Root → Left → Right
```

결과:

```text
A B D E C
```

```java
static void preorder(Node node) {
    if (node == null) return;

    System.out.print(node.data + " ");
    preorder(node.left);
    preorder(node.right);
}
```

### 중위 순회(Inorder)

```text
Left → Root → Right
```

결과:

```text
D B E A C
```

```java
static void inorder(Node node) {
    if (node == null) return;

    inorder(node.left);
    System.out.print(node.data + " ");
    inorder(node.right);
}
```

[[이진 탐색 트리]]를 중위 순회하면 값이 오름차순으로 나온다.

### 후위 순회(Postorder)

```text
Left → Right → Root
```

결과:

```text
D E B C A
```

```java
static void postorder(Node node) {
    if (node == null) return;

    postorder(node.left);
    postorder(node.right);
    System.out.print(node.data + " ");
}
```

### 레벨 순회(Level Order)

루트에서 가까운 레벨부터 차례대로 방문한다. [[BFS]]와 같은 방식으로 Queue를 사용한다.

```text
A B C D E
```
