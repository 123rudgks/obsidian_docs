큐도 [[스택]]과 마찬가지로 임시데이터를 처리하기 위해 디자인된 추상 데이터 구조이다.
데이터를 처리하는 순서만 제외하면 스택과 비슷하다.

FIFO

스택과 마찬가지로 큐도 제약을 갖는 [[배열]]이다.
- 데이터는 큐의 끝에만 삽입할 수 있다.(스택과 동일)
- 데이터는 큐의 앞에서만 삭제할 수 있다. (스택과 반대)
- 큐의 앞에 있는 원소만 읽을 수 있다(스택과 반대)

[[연결리스트]]를 사용한 큐 구현
```java
public class LinkedQueue{
	// 노드 클래스
	private static class Node{
		int data;
		Node next;
		
		Node(int data){
			this.data = data;
			this.next = null;
		}
	}
	
	private Node front;
	private Node rear;
	// 큐의 원소 개수
	private int size;
	
	// 생성자
	public LinkedQueue(){
		front = null;
		rear = null;
		size = 0;
	}
	
	// 큐가 비어 있는지 확인
	public boolean isEmpty(){
		return front == null;
	}
	// 큐에 원소 삽입
	public void enqueue(int data){
		Node newNode = new Node(data);
		
		// 큐가 비어있는 경우
		if(!isEmpty){
			front = newNode;
			rear = newNode;
		}else{ 
			// 큐에 원소가 있는 경우
			rear.next = newNode;
			rear = newNode;
		}
		size++;
	}
	// 큐에서 원소 삭제 및 반환
	public int dequeue(){
		if(isEmpty()){
			throw new IllegalStateException("큐가 비어 있습니다.");
		}
		int data = front.data;
		
		// front를 다음 노드로 이동
		front = front.next;
		size--;
		
		// 마지막 원소까지 삭제한 경우
		if(front == null){
			rear = null;
		}
		
		return data;
	}
	// 맨 앞 원소 확인
	public int peek(){
		if(isEmpty()){
			throw new IllegalStateException("큐가 비어있습니다");
		}
		return front.data;
	}
	// 큐의 크기 반환
	public int size(){
		return size;
	}
	// 큐 출력
	public void printQueue(){
		Node current = front;
		System.out.print("front -> ");
		
		while(current != null){
			System.out.print(current.data + "->");
			current = current.next;	
		}
		System.out.println("null");
	}
	
	public static void main(String[] args) { 
		LinkedQueue queue = new LinkedQueue(); 
		queue.enqueue(10); 
		queue.enqueue(20); 
		queue.enqueue(30); 
		queue.printQueue(); 
		System.out.println("dequeue: " + queue.dequeue()); 
		System.out.println("peek: " + queue.peek()); 
		queue.enqueue(40); 
		queue.printQueue(); 
		System.out.println("size: " + queue.size()); 
	}
}
```
