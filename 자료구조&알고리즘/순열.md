N개의 원소 중 R개를 뽑아 **순서**있게 나열하는 것.
**순서**가 중요하기 때문에 `[1,2]`와 `[2,1]`은 서로 다른 경우로 보는게 포인트


### [[백트래킹]]을 이용해서 순열을 [[완전 탐색]]하는 방식

1. 현재 자리에 들어갈 원소 1개 선택
2. `visied`를 `true`로 변경
3. `selected[depth]`에 선택한 값 저장
4. `depth + 1`로 [[재귀]] 호출하여 다음 자리 채움
5. 순열이 완성되면 결과 처리
6. 재귀에서 돌아와 `visited`를 `false`로 되돌려 다른 경우 탐색

코드 예시
```java
static int[] arr = {1, 2, 3}; 
static boolean[] visited = new boolean[3]; 
static int[] selected = new int[2];

static void permutation(int depth){
	int(depth == arr.length){
		System.out.println(Arrays.toString(selected));
		return;
	}
	
	for(int i = 0; i < arr.length; i++){
		if(visited[i]) continue;
		
		visited[i] = true;
		selected[depth] = arr[i];
		
		permutation(depth + 1);
		
		visited[i] = false;
	}
}
```



### 비트 마스크를 이용한 순열
[[비트 마스킹]]은 [[부분집합]]을 표현하는 방법. 순열은 여기에 [[DFS]]를 결합한다.

```java
public class Main {
	
	static int[] arr = {1,2,3};
	static int[] result = new int[3];
	static int n = 3;
	
	static void permutation(int depth, int mask){
		if(depth == n){
			for(int value : result){
				System.out.println(value + " ");
			}
			System.out.println();
			return;
		}
		
		for(int i = 0; i < n; i++){
			
			// 이미 사용한 숫자
			if((mask & (1<<i)) != 0){
				continue;
			}
			
			result[depth] = arr[i];
			permutation(depth+1, mask | (1<<i)); // visited 체크
		}
	}
	
	public static void main(String[] args){
		permutation(0,0);
	}
}
```

### Next Permutation

1. 뒤에서부터 내림차순인 구간을 찾는다. 
   - 내림차순인 순열이 가장 최대 값임
1. 처음으로 a[i] < a[i+1]인 위치를 찾는다.
2. a[i]보다 큰 값 중 가장 작은 값을 뒤에서 부터 찾아 a[i]와 교환
3. 뒷부분을 가장 작게 만든다(오름차순)
   - 오름차순인 순열이 가장 최소 값임

핵심 아이디어
1. 뒤쪽에서 더 이상 증가시킬 수 없는 구간을 찾는다. (내림차순이 끝나는 지점)
2. pivot을 최소한으로 증가시킨다.
3. 나머지는 최소 상태로 만든다. (오름차순으로 만들기)

```java
static boolean netPermutation(int[] a){
	int i = a.length - 2;
	
	// 1. 뒤에서부터 a[i] < a[i+1]인 위치 찾기 (내림차순이 끝나는 지점)
	while(i >= 0 && a[i] >= a[i+1]){
		i--;
	}
	
	// 마지막 순열
	if(i < 0){
		return false;
	}
	
	// 2. 뒤에서부터 a[i]보다 큰 값 찾기, pivot 뒤 숫자들은 내림차순이기 때문에 맨 뒤에서 부터 조회시 처음 발견되는 수가 pivot보다 큰 수 중 가장 작은 값.
	int j = a.lengh - 1;
	
	while(a[i] >= a[j]){
		j--;
	}
	
	// 3. swap
	swap(a,i,j);
	
	// 4. 뒷 부분 뒤집기 (변경된 pivot 뒤의 수 오름차순 정렬)
	// pivot 뒤의 수들은 내림차순임이 보장되어있음
	int left = i + 1;
	int right = a.length - 1;
	
	while(left < right){
		swap(a, left++, right--);
	}
	return true;
}

static void swap(int[] a, int i, int j){
	int temp = a[i];
	a[i] = a[j];
	a[j] = temp;
}


public static void main(String[] args){
	int[] a = {3, 1, 2};
	
	// 아래 패턴 기억하는게 좋음
	Arrays.sort(a);
	do{
		System.out.println(Arrays.toString(a));
	}while(nextPermutation(a));
}

```

>[!note]
>모든 순열을 사전순으로 생성하려면 처음 배열을 오름차순으로 정렬해야 한다.
