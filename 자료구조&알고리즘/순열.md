N개의 원소 중 R개를 뽑아 **순서**있게 나열하는 것.
**순서**가 중요하기 때문에 `[1,2]`와 `[2,1]`은 서로 다른 경우로 보는게 포인트


### [[백트래킹]]을 이용해서 순열을 [[완전 탐색]]하는 방식

1. 현재 자리에 들어갈 원소 1개 선택
2. `visied`를 `true`로 변경
3. `selected[depth]`에 선택한 값 저장
4. `depth + 1`로 [[재귀]] 호출하여 다음 자리 채움
5. 순열이 완성되면 결과 처리
6. 재귀에서 돌아와 `visited`를 `false`로 되돌려 다른 경우 탐색

코드 예시
```java
static int[] arr = {1, 2, 3}; 
static boolean[] visited = new boolean[3]; 
static int[] selected = new int[2];

static void permutation(int depth){
	int(depth == arr.length){
		System.out.println(Arrays.toString(selected));
		return;
	}
	
	for(int i = 0; i < arr.length; i++){
		if(visited[i]) continue;
		
		visited[i] = true;
		selected[depth] = arr[i];
		
		permutation(depth + 1);
		
		visited[i] = false;
	}
}
```
