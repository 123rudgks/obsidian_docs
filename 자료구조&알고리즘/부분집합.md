부분집합(Subset)은 **주어진 집합의 원소들 중 일부를 선택해서 만든 집합**

부분 집합은 [[순열]] / [[조합]]과는 관점이 조금 다르다.
각 원소를 선택할지, 선택하지 않을지를 전부 확인하는 방식


1. 현재 원소를 선택
2. `depth+1`로 재귀 호출해서 다음 원소를 결정
3. 돌아온 뒤 현재 원소를 선택하지 않은 상태로 바꾼다.
4. 다시 `depth+1`로 재귀 호출한다.
5. 모든 원소의 선택 여부를 결정하면 부분집합 하나가 완성된다.
예시
```
1 선택
→ 2 선택
   → 3 선택   → [1,2,3]
   → 3 미선택 → [1,2]

→ 2 미선택
   → 3 선택   → [1,3]
   → 3 미선택 → [1]
```


```java
static int[] arr = {1,2,3};
static boolean[] selected = new boolean[3];

static void subset(int depth){
	if(depth == arr.length){
		for(int i = 0; i < arr.length; i++){
			if(selected[i]){
				System.out.println(arr[i] + " ");
			}
		}
		System.out.println();
		return;
	}
	
	//현재 원소 선택하는 경우
	selected[depth] = true;
	subset(depth+1);
	//현재 원소 선택 안하는 경우
	selected[depth] = false;
	subset(depth+1);
}

```
