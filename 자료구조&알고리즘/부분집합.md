# 부분집합

부분집합(Subset)은 **주어진 집합의 원소들 중 일부를 선택해서 만든 집합**이다.

[[순열]] / [[조합]]과 달리 각 원소에 대해

```text
선택한다 / 선택하지 않는다
```

두 가지를 결정하는 방식으로 생각하면 된다.

N개의 원소가 있다면 각 원소마다 2가지 선택이 있으므로 부분집합의 개수는

```text
2^N
```

개이다.

## 재귀로 부분집합 구현

1. 현재 원소를 선택
2. 다음 원소로 재귀 호출
3. 돌아온 뒤 현재 원소를 선택하지 않음
4. 다시 다음 원소로 재귀 호출
5. 모든 원소의 선택 여부를 결정하면 부분집합 하나 완성

```text
1 선택
→ 2 선택
   → 3 선택   → [1,2,3]
   → 3 미선택 → [1,2]

→ 2 미선택
   → 3 선택   → [1,3]
   → 3 미선택 → [1]
```

```java
static int[] arr = {1, 2, 3};
static boolean[] selected = new boolean[arr.length];

static void subset(int depth) {
    if (depth == arr.length) {
        for (int i = 0; i < arr.length; i++) {
            if (selected[i]) {
                System.out.print(arr[i] + " ");
            }
        }
        System.out.println();
        return;
    }

    selected[depth] = true;
    subset(depth + 1);

    selected[depth] = false;
    subset(depth + 1);
}
```

재귀 트리에서 매 단계마다 두 갈래로 나뉘므로 최종적으로 `2^N`개의 상태가 만들어진다.

## 비트 마스킹으로 부분집합 구현

각 비트를 원소의 선택 여부로 사용한다. 자세한 연산은 [[비트 마스킹]] 참고.

```java
static void subset(int[] arr) {
    int n = arr.length;

    for (int mask = 0; mask < (1 << n); mask++) {
        System.out.print("{");

        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) {
                System.out.print(arr[i] + " ");
            }
        }

        System.out.println("}");
    }
}
```

## 코딩 테스트에서 자주 쓰는 형태 — 부분집합의 합

```java
int[] arr = {1, 2, 3};
int n = arr.length;

for (int mask = 0; mask < (1 << n); mask++) {
    int sum = 0;

    for (int i = 0; i < n; i++) {
        if ((mask & (1 << i)) != 0) {
            sum += arr[i];
        }
    }

    System.out.println(sum);
}
```

## 핵심

> 부분집합 = 각 원소를 선택할지 말지 결정한다. 따라서 N개 원소의 전체 상태 수는 `2^N`이다.
