

## 비트 연산
| 연산          | Java     | 의미         |
| ----------- | -------- | ---------- |
| AND         | `a & b`  | 둘 다 1이면 1  |
| OR          | `a \| b` | 하나라도 1이면 1 |
| XOR         | `a ^ b`  | 서로 다르면 1   |
| NOT         | `~a`     | 비트 반전      |
| Left Shift  | `a << n` | 왼쪽으로 n칸    |
| Right Shift | `a >> n` | 오른쪽으로 n칸   |

## 비트 마스킹
> 여러 개의 boolean 상태를 정수 하나로 표현

예를 들어 4명이 있다고 할 때
```
0번 사람
1번 사람
2번 사람
3번 사람
```

비트 마스킹 사용하지 않으면
```
boolean[] selected = new boolean[4];
```
처럼 표현할 수 있다.

비트 마스크에서는 
```
0000
```
이라는 정수 하나로 표현 가능

### 특정 비트 켜기
i번째 원소를 선택한다고 할 때
```java
mask |= (1 << i);
```

ex
```java
int mask = 0;

mask |= (1 << 2);
```

```
0000
0100
----
0100
```
이렇게 3번째 원소(2번 인덱스)를 켤 수 있다.

### 특정 원소가 선택되어 있는지 확인
```java
if ((mask & (1 << i)) != 0) {
    // i번째 원소가 선택되어 있음
}

if ((mask & (1 << i)) == 0) {
    // 선택되지 않음
}
```

```
0101
0100
----
0100
// 3번째 원소 선택되어 있음
```

### 특정 비트 끄기

```java
mask &= ~(1 << i);
```

```
0101
0100 -> 1011
----
0001
// 3번째 원소 선택 해제
```

> DFS에서 파라미터로 새로운 mask를 넘기면 직접 끌 필요가 없는 경우도 많다.
> ```java
> dfs(mask | (1 << i));
> ```

### 특정 비트 토글
```java
mask ^= (1 << i);
```

```
0101
1100
----
1001
// 4번째 원소 on, 3번째 원소 off
```


코딩 테스트에서도 작은 N에 대해
```
비트마스크 + DP
비트마스크 + BFS
비트마스크 + DFS
```
[[동적 프로그래밍]], [[DFS]], [[BFS]] 조합을 자주 사용한다.


Java에서는 켜져 있는 비트의 개수를 직접 계산할 필요가 없다.
```java
Integer.bitCount();
Long.bitCount();

int mask = 13; // 1101
System.out.println(Integer.bitCount(mask)); // result : 3, 3개의 비트가 켜져 있다.
```

예제
```java
for (int mask = 0; mask < (1<<n); mask++){
	if(Integer.bitCount(mask) != k){
		continue;
	}
	// 정확히 k개가 선택된 경우
}
```
