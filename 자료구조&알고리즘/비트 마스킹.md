## 비트 연산

| 연산 | Java | 의미 |
|---|---|---|
| AND | `a & b` | 둘 다 1이면 1 |
| OR | `a \| b` | 하나라도 1이면 1 |
| XOR | `a ^ b` | 서로 다르면 1 |
| NOT | `~a` | 비트 반전 |
| Left Shift | `a << n` | 왼쪽으로 n칸 |
| Right Shift | `a >> n` | 오른쪽으로 n칸 |

## 비트 마스킹

> 여러 개의 boolean 상태를 정수 하나로 표현하는 방법

예를 들어 4명이 있다고 할 때 각 사람의 선택 여부를 다음처럼 저장할 수 있다.

```java
boolean[] selected = new boolean[4];
```

비트 마스킹에서는 같은 상태를 정수 하나로 표현할 수 있다.

```text
0000
```

각 비트를 하나의 원소 선택 여부로 본다.

```text
0번 원소 → 0번째 비트
1번 원소 → 1번째 비트
2번 원소 → 2번째 비트
3번 원소 → 3번째 비트
```

## 자주 사용하는 연산

### 특정 비트 켜기

i번째 원소를 선택한다.

```java
mask |= (1 << i);
```

예를 들어 2번 인덱스를 켜면

```text
0000
0100
----
0100
```

### 특정 비트가 켜져 있는지 확인

```java
if ((mask & (1 << i)) != 0) {
    // i번째 원소가 선택되어 있음
}

if ((mask & (1 << i)) == 0) {
    // i번째 원소가 선택되어 있지 않음
}
```

예:

```text
0101
0100
----
0100
```

결과가 0이 아니므로 2번 인덱스가 선택되어 있다.

### 특정 비트 끄기

```java
mask &= ~(1 << i);
```

예를 들어 `0101`에서 2번 인덱스를 끄면

```text
0101
0100 -> NOT -> 1011
----
0001
```

> DFS에서 파라미터로 새로운 mask 값을 넘기는 방식이라면 원상복구가 필요 없는 경우도 많다.
>
> ```java
> dfs(mask | (1 << i));
> ```

### 특정 비트 토글

켜져 있으면 끄고, 꺼져 있으면 켠다.

```java
mask ^= (1 << i);
```

예를 들어 `0101`에서 2번 인덱스를 토글하면

```text
0101
0100
----
0001
```

## 전체 부분집합 표현

N개의 원소가 있다면 가능한 상태는 총 `2^N`개이다.

```java
for (int mask = 0; mask < (1 << n); mask++) {
    // mask 하나가 부분집합 하나를 의미
}
```

예를 들어 N=3이면

```text
000
001
010
011
100
101
110
111
```

총 8개, 즉 `2^3`개의 상태가 존재한다.

## 켜진 비트 개수

```java
int mask = 13; // 1101
System.out.println(Integer.bitCount(mask)); // 3
```

```java
for (int mask = 0; mask < (1 << n); mask++) {
    if (Integer.bitCount(mask) != k) {
        continue;
    }

    // 정확히 k개가 선택된 상태
}
```

`long`을 사용할 때는 `Long.bitCount()`를 사용할 수 있다.

## int와 long

Java의 `int`는 32비트이므로 비트를 많이 사용할 때는 `long`을 고려해야 한다.

```java
long mask = 0L;
mask |= (1L << i);
```

`long`에서는 `1 << i`가 아니라 `1L << i`를 사용하는 것이 안전하다.

## 장점

- 여러 개의 선택 여부를 정수 하나로 표현할 수 있다.
- 상태 복사와 비교가 간단하다.
- AND, OR, XOR 등의 비트 연산을 이용해 상태를 빠르게 변경하거나 확인할 수 있다.
- 작은 N의 상태 탐색에서 [[DFS]], [[BFS]], [[동적 프로그래밍]]과 결합하기 좋다.

## 단점

- 처음 보면 코드의 의미를 파악하기 어려워 가독성이 떨어질 수 있다.
- 정수의 비트 수 때문에 한 정수로 표현할 수 있는 상태 개수에 제한이 있다.
- 상태를 압축하더라도 모든 부분집합을 확인하면 여전히 `2^N`개의 상태를 탐색해야 한다.

## 핵심

> 비트 마스킹은 탐색 횟수 자체를 무조건 줄여주는 기법이 아니라, 여러 boolean 상태를 하나의 정수로 간결하게 표현하고 조작하는 방법이다.
