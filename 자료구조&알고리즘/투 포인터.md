

### 투 포인터 문제 1

**문제**

- 서로 다른 자연수 `N개`가 주어짐
- 서로 다른 두 수를 골라 합이 `X`가 되는 **쌍의 개수**를 구함
```text
ai + aj = X
```

**조건**

- `1 ≤ N ≤ 100,000`
- `1 ≤ X ≤ 2,000,000`
- 각 수는 `1 이상 1,000,000 이하`
- 모든 수는 서로 다름

**풀이**

- 배열 정렬
- `left = 0`, `right = N - 1`
- 양쪽에서 투 포인터 이동
    
```text
sum == X → count++, left++, right--
sum < X  → left++
sum > X  → right--
```

**복잡도**

- 정렬: `O(N log N)`
- 투 포인터: `O(N)`
- 전체: `O(N log N)`
    

**핵심**

> 정렬된 배열에서는 합이 작으면 왼쪽 포인터를 키우고, 합이 크면 오른쪽 포인터를 줄인다.


구현 코드
```java
import java.io.BufferedReader;
import java.io.InputStreamReader; 
import java.util.Arrays; 
import java.util.StringTokenizer;

public class Main{
	public static void main(String[] args) throws Exception{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		// n, x 입력
		StringTokenizer st = new StringTokenizer(br.readLine());
		
		int n = Integer.parseInt(st.nextToken());
		int n = Integer.parseInt(st.nextToken());
		
		// 수열 입력
		int[] arr = new int[n];
		
		st = new StringTokenizer(br.readLine());
		
		for(int i = 0; i<n; i++){
			arr[i] = Integer.parseInt(st.nextToken());
		}
		
		// 투 포인터를 사용하기 위한 정렬
		Arrays.sort(arr);
		
		int left = 0;
		int right = n - 1;
		
		int count = 0;
		
		while(left < right){
			int sum = arr[left] + arr[right];
			
			if(sum == x){
				count++;
				left++;
				right--;
			}else if(sum < x){
				// 합이 작으므로 더 큰 숫자 필요;
				left++;
			}else{
				// 합이 크므로 더 작은 숫자 필요
				right--;
			}
		}
		System.out.println(count);
	}
}
```


### 투 포인터 메모 2
**문제**

- `N`개의 자연수로 이루어진 수열이 주어진다.
- 연속된 구간 `A[i] ~ A[j]`의 합이 목표값 `M`이 되는 **경우의 수**를 구한다.

```
A[i] + A[i+1] + ... + A[j] = M
```

**조건**

- `1 ≤ N ≤ 10,000`
- `1 ≤ M ≤ 300,000,000`
- 모든 원소는 **자연수(양수)**


```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {

    public static void main(String[] args) throws Exception {

        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        int[] arr = new int[n];

        st = new StringTokenizer(br.readLine());

        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        int left = 0;
        int sum = 0;
        int count = 0;

        for (int right = 0; right < n; right++) {

            // 오른쪽 값을 윈도우에 추가
            sum += arr[right];

            // 합이 m보다 크면 왼쪽을 줄임
            while (sum > m) {
                sum -= arr[left];
                left++;
            }

            // 합이 정확히 m이면 경우의 수 증가
            if (sum == m) {
                count++;
            }
        }

        System.out.println(count);
    }
}
```
