# 투 포인터

투 포인터는 배열이나 수열에서 **두 개의 인덱스(pointer)를 움직이면서 원하는 조건을 찾는 탐색 기법**이다.

모든 두 원소나 모든 구간을 직접 확인하면 `O(N²)`이 될 수 있지만, 조건에 따라 두 포인터를 한 방향으로만 이동시키면 `O(N)` 수준으로 탐색할 수 있는 경우가 있다.

대표적인 형태는 두 가지가 있다.

1. 양 끝에서 시작해 서로 가까워지는 방식
2. 두 포인터가 같은 방향으로 이동하며 구간을 관리하는 방식

---

## 투 포인터 문제 1 — 양 끝에서 좁히기

**문제**

- 서로 다른 자연수 `N개`가 주어짐
- 서로 다른 두 수를 골라 합이 `X`가 되는 **쌍의 개수**를 구함

```text
ai + aj = X
```

**조건**

- `1 ≤ N ≤ 100,000`
- `1 ≤ X ≤ 2,000,000`
- 각 수는 `1 이상 1,000,000 이하`
- 모든 수는 서로 다름

**풀이**

- 배열 정렬
- `left = 0`, `right = N - 1`
- 양쪽에서 투 포인터 이동

```text
sum == X → count++, left++, right--
sum < X  → left++
sum > X  → right--
```

정렬되어 있기 때문에

- 합이 작으면 더 큰 값이 필요하므로 `left++`
- 합이 크면 더 작은 값이 필요하므로 `right--`

할 수 있다.

**복잡도**

- 정렬: `O(N log N)`
- 투 포인터 탐색: `O(N)`
- 전체: `O(N log N)`

**핵심**

> 정렬된 배열에서는 합이 작으면 왼쪽 포인터를 키우고, 합이 크면 오른쪽 포인터를 줄인다.

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int x = Integer.parseInt(st.nextToken());

        int[] arr = new int[n];
        st = new StringTokenizer(br.readLine());

        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        Arrays.sort(arr);

        int left = 0;
        int right = n - 1;
        int count = 0;

        while (left < right) {
            int sum = arr[left] + arr[right];

            if (sum == x) {
                count++;
                left++;
                right--;
            } else if (sum < x) {
                left++;
            } else {
                right--;
            }
        }

        System.out.println(count);
    }
}
```

## 투 포인터 문제 2 — 같은 방향으로 이동하기

**문제**

- `N`개의 자연수로 이루어진 수열이 주어진다.
- 연속된 구간 `A[i] ~ A[j]`의 합이 목표값 `M`이 되는 **경우의 수**를 구한다.

```text
A[i] + A[i+1] + ... + A[j] = M
```

**조건**

- `1 ≤ N ≤ 10,000`
- `1 ≤ M ≤ 300,000,000`
- 모든 원소는 **자연수(양수)**

오른쪽 포인터를 이동하며 구간에 값을 추가하고, 합이 너무 커지면 왼쪽 포인터를 이동하여 구간을 줄인다.

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        int[] arr = new int[n];
        st = new StringTokenizer(br.readLine());

        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        int left = 0;
        int sum = 0;
        int count = 0;

        for (int right = 0; right < n; right++) {
            sum += arr[right];

            while (sum > m) {
                sum -= arr[left];
                left++;
            }

            if (sum == m) {
                count++;
            }
        }

        System.out.println(count);
    }
}
```

두 포인터는 각각 배열을 최대 한 번씩 지나가므로 탐색 자체는 `O(N)`이다.

> 이 방식은 모든 값이 양수이기 때문에 합이 커졌을 때 `left`를 오른쪽으로 이동하면 합이 반드시 감소한다는 성질을 이용한다.

## 투 포인터와 슬라이딩 윈도우

둘 다 두 개의 인덱스로 구간을 관리할 수 있다.

- 투 포인터: 조건에 따라 두 포인터의 위치를 움직이는 탐색 기법
- 슬라이딩 윈도우: 일정한 구간 또는 조건을 만족하는 연속 구간을 이동시키며 관리하는 방식

슬라이딩 윈도우를 투 포인터의 한 형태로 보는 경우도 많다.

## 핵심

> 투 포인터는 두 포인터를 무작정 움직이는 것이 아니라, **한쪽 포인터를 움직였을 때 값이나 조건이 어느 방향으로 변하는지 알 수 있을 때** 효과적이다.
