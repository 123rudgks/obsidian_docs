
루프를 사용할 수 있는 경우라면 거의 대부분 재귀도 쓸 수 있다.

모든 재귀 함수는 무한대로 호출되지 않게 하는 기저 조건이 적어도 하나 있어야 한다.

재귀함수 읽는 법
1. 기저 조건 찾기
2. 기저 조건에서 함수가 어떻게 동작하는지 살펴보기
3. "끝에서 두 번째" 조건 찾기 (기저 조건 바로 전 조건)
4. 방금 분석한 조건의 바로 전 조건을 찾아가며 위 절차 반복하며 함수가 어떻게 동작하는 지 살피기


재귀 함수는 계산된 값을 부모 함수에 반환 한다. ( 호출 스택을 통해 값 위로 전달하기 )

무한 재귀에서는 컴퓨터가 반복해서 같은 함수를 호출 스택에 푸시. 스택 오버플로우 발생


재귀가 유용한 상황
- 몇 단계나 깊이 들어가야 하는지 모르는 상황에서 문제를 여러 단계로 파고 들어야 할 때 재귀가 유용하다.
- 하위 문제의 계산 결과에 기반해 계산을 할 수 있을 때 유용하다. 
	하향식 사고 절차
	1. 작성 중이던 함수가 이미 구현되어있다고 가정
	2. 문제의 하위 문제를 찾자
	3. 하위 문제에 함수를 호출하면 어떻게 되는지 보고 거기서 부터 시작

그냥 루프 쓰면 되지 왜 재귀를 쓸 까?
	재귀를 사용했을 때 로직이 더 단순해 지는 경우가 있음
	얼마나 깊게 루프를 돌아야할 지 미리 알 수 없는 경우가 있음
