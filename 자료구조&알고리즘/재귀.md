# 재귀

재귀 함수는 **함수가 자기 자신을 다시 호출하여 더 작은 문제를 해결하는 방식**이다.

루프로 해결할 수 있는 문제 중 많은 문제를 재귀로도 표현할 수 있으며, 문제 구조가 반복적으로 쪼개질 때 재귀가 더 자연스러운 경우가 있다.

## 재귀 함수의 기본 구조

재귀 함수는 크게 두 부분으로 생각하면 된다.

1. **기저 조건(Base Case)**: 더 이상 재귀 호출하지 않고 종료하는 조건
2. **재귀 조건(Recursive Case)**: 문제를 더 작은 형태로 바꾸어 자기 자신을 다시 호출

```java
static void recursive(int n) {
    if (n == 0) {       // 기저 조건
        return;
    }

    // 현재 단계의 작업
    recursive(n - 1);   // 더 작은 문제 호출
}
```

기저 조건이 없거나 도달할 수 없다면 무한 재귀가 발생하여 `StackOverflowError`가 발생할 수 있다.

## 호출 스택

함수를 호출하면 현재 함수의 실행 정보가 호출 스택에 쌓인다.

```java
static void func(int n) {
    if (n == 0) return;

    System.out.println("down " + n);
    func(n - 1);
    System.out.println("up " + n);
}
```

`func(3)`을 실행하면

```text
down 3
down 2
down 1
up 1
up 2
up 3
```

순서가 된다.

호출 과정:

```text
func(3)
→ func(2)
→ func(1)
→ func(0)
```

`func(0)`이 종료된 뒤 호출했던 순서의 반대로 돌아온다.

```text
func(0) 종료
→ func(1) 복귀
→ func(2) 복귀
→ func(3) 복귀
```

## 재귀함수 읽는 법

1. 기저 조건 찾기
2. 재귀 호출에서 입력값이 어떻게 변하는지 확인
3. 가장 작은 문제에서 어떤 값이 반환되는지 확인
4. 호출이 끝난 뒤 이전 함수로 돌아오면서 어떤 작업이 수행되는지 확인

## 반환값

재귀 함수는 하위 문제에서 계산한 값을 호출한 함수로 반환할 수 있다.

```java
static int factorial(int n) {
    if (n == 1) {
        return 1;
    }

    return n * factorial(n - 1);
}
```

```text
factorial(3)
= 3 * factorial(2)
= 3 * 2 * factorial(1)
= 3 * 2 * 1
```

## 재귀가 유용한 상황

- 문제를 같은 형태의 더 작은 문제로 나눌 수 있을 때
- 트리 / 그래프처럼 탐색 깊이를 미리 알기 어려울 때
- [[순열]], [[조합]], [[부분집합]], [[백트래킹]], [[분할 정복]]처럼 단계별 선택 구조가 있을 때

## 재귀의 공간 복잡도

재귀 호출은 호출 스택을 사용한다.

예를 들어 `n → n-1 → ... → 0`처럼 최대 N단계까지 내려간다면 호출 스택에도 최대 N개의 함수가 쌓일 수 있으므로 스택 공간은 `O(N)`이 될 수 있다.

## 재귀 응용 — 하노이의 탑

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;

public class Main {
    static StringBuilder sb = new StringBuilder();

    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        int N = Integer.parseInt(br.readLine());

        hanoi(N, 1, 2, 3);
        System.out.print(sb);
    }

    static void hanoi(int n, int from, int via, int to) {
        if (n == 0) {
            return;
        }

        // 1. 위의 n-1개를 from → via로 이동
        hanoi(n - 1, from, to, via);

        // 2. 가장 큰 원판을 from → to로 이동
        sb.append(n)
          .append(" : ")
          .append(from)
          .append(" -> ")
          .append(to)
          .append('\n');

        // 3. n-1개를 via → to로 이동
        hanoi(n - 1, via, from, to);
    }
}
```

> 재귀를 구현할 때는 **기저 조건 + 더 작은 문제로의 변화 + 복귀 후 처리**를 먼저 찾는다.
