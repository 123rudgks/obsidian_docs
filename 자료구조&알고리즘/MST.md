## 신장 트리

신장 트리(Spanning Tree)는 그래프의 **모든 정점을 포함하면서 사이클이 없는 연결 그래프**이다.

정점이 `N`개라면 신장 트리의 간선 수는 항상 ```N-1```
why?
```
정점 1개 → 간선 0개
정점 2개 → 간선 1개
정점 3개 → 간선 2개
...
정점 N개 → 간선 N - 1개
```
> 모든 정점이 이미 연결된 상태에서 간선을 더 추가하면 사이클이 생길 수 있다.

# 최소 신장 트리의 목적
MST의 목적은 
- 모든 정점을 연결
- 전체 간선 비용 최소화

[[최단 경로]]와의 차이
MST와 최단 경로는 둘 다 가중치가 있는 그래프에서 비용을 다루지만 목적이 다르다.
```
최소 신장 트리
→ 모든 정점을 연결하는 전체 비용을 최소화

최단 경로
→ 특정 정점에서 다른 정점까지 이동하는 비용을 최소화
```
따라서 MST를 구성했다고 해서 MST 내부의 두 정점 사이 경로가 원래 그래프의 최단 경로라는 보장은 없다.

```
각 연결에는 비용이 존재한다.

모든 정점을 연결하면서 필요한 전체 비용을 최소화하라.
```
