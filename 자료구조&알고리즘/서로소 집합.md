서로소는 **두 수의 공약수가 1밖에 없는 관계**를 말해.
즉 
> **서로소 = 최대공약수(GCD)가 1인 두 수**


## 서로소 집합 (Disjoint Set)

서로 겹치지 않는 여러 집합을 관리하는 자료구조.

보통 **Union-Find**라고도 부른다.
### 핵심 연산

- `Find`
  - 특정 원소가 속한 집합의 대표 원소(root)를 찾음
  - 두 원소가 같은 집합에 속하는지 확인할 때 사용

- `Union`
  - 두 원소가 속한 집합을 하나로 합침

### 예시

초기 집합:

```text
{1, 2}
{3, 4}
{5}
```

`Union(2, 3)` 수행 후:

```text
{1, 2, 3, 4}
{5}
```

### 대표 활용

- 두 정점이 같은 집합에 속하는지 확인
- 그래프의 사이클 판별
- Kruskal 알고리즘
- 연결 요소 관리

### 핵심 정리
> 서로소 집합은 서로 겹치지 않는 집합들을 효율적으로 합치고, 특정 원소들이 같은 집합에 속하는지 확인하기 위한 자료구조이다.



## 서로소 집합 구현 ([[연결리스트]])

```java
public class LinkedListDisjointSet{
	static class Node{
		int value;
		Node next;
		
		// 현재 자신이 속한 집합의 대표 노드
		Node representative;
		
		Node(int value){
			this.value = value;
			this.representative = this;
		}
	}
	
	static class SetList{
		Node head;
		Node tail;
		int size;
		
		SetList(int value){
			Node node = new Node(value);
			
			head = node;
			tail = node;
			size = 1;
		}
	}
	
	// 대표 원소 찾기
	static Node find(Node node){
		return node.representative;
	}
	
	// 두 집합 합치기
	static void union(SetList set1, SetList set2){
		// 작은 집합을 큰 집합에 붙임
		if(set1.size < set2.size){
			SetList temp = set1;
			set1 = set2;
			set2 = temp;
		}
		
		// set2의 모든 노드의 대표를 set1의 대표로 변경
		Node current = set2.head;
		
		while(current != null){
			current.representative = set1.head;
			current = current.next;
		}
		
		// 연결 리스트 연결
		set1.tail.next = set2.head;
		set1.tail = set2.tail;
		
		set1.size += set2.size;
	}
	
	public static void main(String[] args){
		SetList set1 = new SetList(1);
		SetList set2 = new SetList(2);
		
		Node node1 = set1.head;
		Node node2 = set2.head;
		
		union(set1, set2);
		
		System.out.println(find(node1).value);
		System.out.println(find(node2).value);
	}
}
```


## 서로소 집합 구현([[트리]])
| 실제 코테에서 일반적으로 사용하는 방식

```java
public class TreeDisjointSet{
	static int[] parent;
	static int[] rank;
	
	public static void main(String[] args){
		int n = 5;
		
		parent = new int[n + 1];
		rank = new int[n + 1];
		
		// 처음에는 자기 자신이 대표
		for(int i = 1; i <= n; i++){
			parent[i] = i;
		}
		
		union(1,2);
		union(2,3);
		
		System.out.println(find(1));
		System.out.println(find(2));
		System.out.println(find(3));
		
		System.out.println(find(4));
	}
	
	// 대표 원소 찾기
	static int find(int x){
		if(parent[x] == x){
			return x;
		}
		// 경로 압축
		return parent[x] = find(parent[x]);
	}
	
	// 두 집합 합치기
	static void union(int a, int b){
		int rootA = find(a);
		int rootB = find(b);
		
		if(rootA == rootB){
			return;
		}
		
		// rank가 작은 트리를 큰 트리 밑에 연결
		if(rank[rootA] < rank[rootB]){
			parent[rootA] = rootB;
		}else if(rank[rootA] > rank[rootB]){
			parent[rootB] = rootA;
		}else{
			parent[rootB] = rootA;
			rank[rootA] ++
		}
	}
}
```
