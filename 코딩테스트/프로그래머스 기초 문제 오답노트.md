
**문자열의 뒤의 n글자**
```java
public String solution(String my_string, int n) {
        String answer = my_string.substring(my_string.length() - n);
        return answer;
    }
```
>[!note]
>전체 길이 : length
>출력할 글자의 개수 : n
>`length - n` 번 인덱스에서 부터 마지막까지 출력하면 n개 출력
>- prove
>	배열의 마지막 인덱스는 `length - 1`
>	인덱스 구간의 원소 개수는 다음과 같다. `끝 인덱스 - 시작 인덱스 + 1`
>	`n`개의 원소를 가져오려면: (length - 1) - 시작 인덱스 + 1 = n
>	정리하면: `시작 인덱스 = length - n`

**[글자 이어 붙여 문자열 만들기](https://school.programmers.co.kr/learn/courses/30/lessons/181915)**
```java
 public String solution(String my_string, int[] index_list) {
        String answer = "";
        for(int idx : index_list){ // for-each 문 사용법 확인
            answer+=my_string.charAt(idx); //
        }
        return answer;
    }
```
>[!note]
>for-each 기본 문법 확인
>Java의 배열의 길이는 `length` : 필드값, String의 길이는 `length()` : 메소드
>Java의 String은 배열처럼 바로 인덱스 사용 못 함. `.charAt(idx)` 사용


**n 번째 원소부터**
```java
// (1)번 솔루션
 public int[] solution(int[] num_list, int n) {
        int[] answer = new int[num_list.length - (n + 1)];
        for(int i = n-1; i< num_list.length ; i++){
            answer[i-(n-1)] = num_list[i];
        }
        return answer;
    }
// (2)번 솔루션
import java.util.*;
 public int[] solution(int[] num_list, int n) {
       return Arrays.copyOfRange(num_list, n-1, num_list.length);
    }
```
>[!note]
>(1)번
>Java의 배열의 크기는 고정적. 처음에 정해져야한다.
>`num_list.length - (n-1)` : 처음에 n-1대신 n을 뺐어서 틀렸었다. 
>배열의 크기를 `num_list.length - (n - 1)`로 계산하는 이유는 아래와 같다.
>자바 배열의 인덱스는 `0`부터 시작하므로:
>- `n`번째 원소의 인덱스 → `n - 1`
>- 마지막 원소의 인덱스 → `num_list.length - 1`
>따라서 필요한 배열의 크기는:
>```
>마지막 인덱스 - 시작 인덱스 + 1
= (length - 1) - (n - 1) + 1
= length - n + 1
= length - (n - 1)
>```
>처음에 `length - n`으로 계산하면 **n번째 원소부터 마지막까지의 개수에서 1개가 부족하다.**
>따라서 `n`번째 원소를 포함하기 위해 `+1`이 필요하다.
>```
>num_list.length - n + 1
= num_list.length - (n - 1)
>```
>
>(2)번
>`copyOfRange(원본배열, 시작인덱스, 끝인덱스)`
>**시작은 포함, 끝은 미포함(exclusive)** 이에요.


**문자열의 앞의 n글자**
```java
public String solution(String my_string, int n) {
        return my_string.substring(0, n);
    }
```
>[!note]
>**`substring(시작인덱스, 끝인덱스)`** 
>시작은 포함(inclusive), 끝은 미포함(exclusive) 
>`substring(0, n)`은 "0번째부터 n번째 직전까지" 즉 **앞에서부터 n글자**를 가져온다.


**마지막 두 원소**
```java
int[] answer = Arrays.copyOf(num_list, num_list.length+1);
```
>[!note]
`Arrays.copyOf(원본배열, 새길이)`는 원본 배열을 복사해서 원하는 크기의 새 배열을 만들어주는 메서드
>```java
>int[] num_list = {10, 20, 30};
int[] answer = Arrays.copyOf(num_list, num_list.length + 1);
>```
>- 원본 값들은 앞에서부터 그대로 복사됨
>- 새 길이가 더 크면, 남는 자리는 배열의 원소 기본값으로 자동으로 채워짐
