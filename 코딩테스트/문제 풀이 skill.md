import java.util.HashSet;
import java.util.Set;

public class Solution {
    public static boolean isSubset(int[] array1, int[] array2) {
        int[] largerArray = array1.length > array2.length ? array1 : array2;
        int[] smallerArray = array1.length > array2.length ? array2 : array1;

        Set<Integer> hashSet = new HashSet<>();
        for (int value : largerArray) {
            hashSet.add(value);
        }

        for (int value : smallerArray) {
            if (!hashSet.contains(value)) {
                return false;
            }
        }

        return true;
    }
}

# 2차원 누적합으로 영역의 합 빠르게 구하기

## 목적

2차원 배열에서 **특정 직사각형 영역의 합을 여러 번 구해야 하는 상황**에서 사용한다.

매번 해당 영역의 모든 값을 직접 더하는 대신,  
전체 배열의 누적 정보를 미리 저장해 두고 **필요한 영역의 합만 빠르게 계산**할 수 있다.

대표적으로 다음과 같은 문제에서 활용할 수 있다.

- 특정 크기의 사각형 영역을 계속 이동시키며 합을 구하는 경우
- 여러 개의 직사각형 구간 합을 반복해서 구해야 하는 경우
- 전체 영역 중 일부 영역만 빠르게 분리해서 계산해야 하는 경우

---

## 코드 예시

```java
int N = 4;

int[][] arr = {
        {0, 0, 0, 0, 0},
        {0, 1, 2, 3, 4},
        {0, 5, 6, 7, 8},
        {0, 9, 10, 11, 12},
        {0, 13, 14, 15, 16}
};

int[][] prefix = new int[N + 1][N + 1];

// 누적합 생성
for (int i = 1; i <= N; i++) {
    for (int j = 1; j <= N; j++) {
        prefix[i][j]
                = arr[i][j]
                + prefix[i - 1][j]
                + prefix[i][j - 1]
                - prefix[i - 1][j - 1];
    }
}


// (2, 2) ~ (3, 3) 영역의 합

int x1 = 2;
int y1 = 2;
int x2 = 3;
int y2 = 3;

int sum = prefix[x2][y2]
        - prefix[x1 - 1][y2]
        - prefix[x2][y1 - 1]
        + prefix[x1 - 1][y1 - 1];

System.out.println(sum); // 34
```

> [!note] 설명
> 누적합은 **같은 구간의 합을 반복해서 계산하는 비용을 줄이기 위한 방법**이다.
> 
> 2차원 누적합에서는 각 위치에  
> **왼쪽 위 시작점부터 현재 위치까지의 직사각형 전체 합**을 저장한다.
> 
> 원하는 직사각형 영역의 합은 다음 흐름으로 구한다.
> 
> ```text
> 전체 누적합
> - 위쪽 영역
> - 왼쪽 영역
> + 두 번 빠진 왼쪽 위 영역
> ```
> 
> 즉, **큰 영역의 합에서 필요 없는 부분을 잘라내는 방식**이다.
> 
> 따라서 문제에서 **직사각형 영역의 합을 여러 번 구해야 한다면 누적합을 떠올리면 된다.**
