## 1부. List / Set / Map 주요 메소드

### 1. Collection 핵심 메소드 종합 작성
`Collection<String> c1`, `c2`를 ArrayList로 만들고 아래 요구사항을 **순서대로** 수행하는 코드를 작성하시오. 각 단계마다 출력으로 확인할 것.
1. c1에 "A"를 추가하고(add), "B", "C"를 한 번에 추가(addAll)
2. c1이 "B"를 포함하는지(contains), "B"와 "C"를 모두 포함하는지(containsAll) 출력
3. c2에 "A", "B", "C"를 넣고 c1과 내용이 같은지 비교(equals)
4. c1의 비어있는지 여부(isEmpty)와 크기(size) 출력
5. iterator로 c1을 순회하며 출력
6. c1을 String 배열로 변환(toArray)하여 `Arrays.toString`으로 출력
7. "B" 하나 제거(remove) → "C"를 컬렉션 단위로 제거(removeAll) → 전체 비우기(clear) 후 각각 상태 출력

### 2. 실행 결과 예측 — Collection
```java
Collection<Integer> c = new ArrayList<>();
c.add(10);
c.addAll(List.of(20, 30));
c.remove(Integer.valueOf(20));
System.out.println(c.contains(20));
System.out.println(c.size() + ", " + c.isEmpty());
c.clear();
System.out.println(c.isEmpty());
```

### 3. List 인덱스 메소드 실행 결과 예측

System.out.println(list.get(2));

### 5. 조건 삭제 두 가지 방법 작성

### 6. HashSet 중복 제거 + 사용자 객체
1. int 배열 `{3, 1, 3, 5, 1}`의 중복을 HashSet으로 제거하는 코드를 작성하시오.

### 24. flatMap 작성

### 25. 매칭 연산 실행 결과 예측

### 29. for문 → 스트림 리팩토링
아래 코드를 스트림 한 문장으로 리팩토링하시오.
```java
List<String> heros = List.of("superman", "batman", "ironman", "hulk");
double sum = 0;
int cnt = 0;
for (String hero : heros) {
    int length = hero.length();
    if (length > 3) {
        sum += length;
        cnt++;
    }
}
double avg = sum / cnt;
System.out.println(avg);
```

### 31. try-catch-finally 흐름 예측

```java

    System.out.println("A");
    int i = 10 / num;
    System.out.println("B");
} catch (ArithmeticException e) {
    System.out.println("C");
} finally {
    System.out.println("D");

```

3. SQLException을 감싸서 던진 커스텀 예외에서, 원래 DB 예외가 무엇이었는지 확인하고 싶다

### 38. 부적절한 예외 처리 리팩토링
아래 두 코드가 왜 나쁜 예외 처리인지 각각 지적하고 올바르게 리팩토링하시오.
```java
// (A) 배열 순회

    int sum = 0;
    try {
        for (int i = 0; ; i++) {
            sum += nums[i];
        }
    } catch (ArrayIndexOutOfBoundsException e) {
        e.printStackTrace();
    }

// (B) Scanner 입력
private static void useScannerBad() {
    Scanner scanner = new Scanner(System.in);
    int sum = 0;
    try {
        while (true) {

            if (input == 0) break;
            sum += input;
        }
    } catch (InputMismatchException e) {
        e.printStackTrace();
    }
    scanner.close();
}
```
