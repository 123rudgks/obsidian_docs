### 3번

```java

    case 2: day = 29; break;
    case 4: case 6: case 9: case 11: day = 30; break;
    default: day = 31;
}
```
① `int day = switch (month) { case 2 -> 29; case 4,6,9,11 -> 30; default -> 31; };`
② `int day = switch (month) { case 2 -> 29; case 4|6|9|11 -> 30; default -> 31; };`
③ `int day = switch (month) { case 2 -> 29; case 4,6,9,11 -> 30; default -> { return 31; } };`
④ `int day = switch (month) { case 2: 29; case 4,6,9,11: 30; default: 31; };`
⑤ `int day = switch (month) { case 2 -> 29; case 4,6,9,11 -> 30; };`

④ static 메소드는 오버라이딩이 불가능하기 때문에
⑤ this는 Heap 영역에서만 사용 가능하기 때문에

