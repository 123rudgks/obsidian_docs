
#### if, switch 조건문에 들어갈 수 있는 타입
if 문 : boolean 타입만 가능
*파이썬이나 C처럼 숫자 0을 false로 취급하는 방식이 자바에선 안 됨*

switch문 : 
byte, short, int, chaar, Integer, Byte, String, enum ✅
long, float, double, boolean ❌

why?
switch는 내부적으로 jump table 만들어 사용. 
```java
switch (x) {
    case 1: ... // 주소 A
    case 2: ... // 주소 B
    case 3: ... // 주소 C
}
```
이걸 컴파일하면 내부적으로 이런 테이블이 만들어집니다:

```
index 1 → 주소 A로 점프
index 2 → 주소 B로 점프
index 3 → 주소 C로 점프
```

x의 값을 테이블의 인덱스로 사용해서 **"비교 없이 바로 해당 코드로 점프"** 하는 방식. 반면 if-else는 하나하나 비교하면서 (if, else 조건들을) 내려온다.

그럼 long 왜 안되는가? long의 범위는 -2^63 ~ 2^63 - 1 범위 (8byte) 이걸 jumb table의 인덱스로 사용하려면 이론상 2^64개의 슬롯이 필요한데 물리적으로 메모리에서 만들 수가 없다. 그래서 설계 단계에서 제외함.

float과 double은 왜 안되는가.
jump table은 정수 인덱스 기반. 0.1, 3.14 같은 실수는 인덱스 자체가 될 수 없다. 또한 실수는 정밀도 문제가 있다. switch의 case는 정확히 일치해야 매칭이 된다. 따라서 설계 단계에서 제외함

boolean은 왜 안되는가?
```java
switch (isValid){
	case true: ...
	case false : ...
}

// 이거랑 똑같음
if(isValid){
...
}else{
...
}
```
if-else 쓰면 되지 굳이 switch 쓸 이유가 없어서 설계 단계에서 제외함

##### switch expressions
표현식 자체가 반환 가능. 자동 break
```java
int month =3;
int day = -1;
switch(month){
  case 2:
    day = 29;
    break;
  case 4:
  case 6:
  case 9:
  case 11:
    day = 30;
    break;
  default:
    day = 31;
}
```
위 내용을 아래와 같이 작성할 수도 있음
```java
int month =3;
int day = switch(month){
  case 2 -> 29;
  case 4, 6, 9, 11 -> 30;
  default -> { yield 31;}
}
```
