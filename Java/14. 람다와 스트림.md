
Lambda식이 할당되는 인터페이스를 Lambda 식의 타겟 타입이라 함
타겟 타입은 abstract 메소드가 단 한개만 있어야 한다. (default, static 메소드는 괜찮음)

```java
@FunctionalInterface // 컴파일러가 재정의해야하는 abstract 메소드가 1개만 있음을 체크
Public interface Comparator<T>{
	int compare(T o1, T o2);
	boolean equals(Object obj);
	default Comparator<T> reversed(){
		return Collections.reverseOrder(this);
	}
}
```
> 위 코드에서 boolean equals는 Object에 있는 equals라서 interface에서 재정의해도 @FunctionalInterface 에 카운트 안한다.
> 그럼 왜 적었냐? **자바독(Javadoc) 주석을 달아서 "이 `equals()`가 어떤 계약을 지켜야 하는지" 문서로 설명해주기 위해** 관례적으로 재선언해놓은 것 뿐

만약 abstract method가 2개 이상이어야 하면 anonymous inner class를 사용해야함

```java
(String str)->{System.out.println("")};
(str)->{System.out.println("")}; // 매개변수 타입은 런타임 시 대입되는 값으로 자동 인식 되므로 일반적으로 생략함
(str)->{ // return이 필요할 경우 return 문장 사용
	System.out.println("");
	return num*2;
	}
str -> System.out.println(""); // 매개변수 또는 실행문이 1개이면 괄호 생략 가능
num->num*2; // return 문만 있을 경우 괄호와 return 생략 가능
```

Lambda 대신 메서드 참조를 해도 됨
```java
Integer [] nums = {1,7,3,4,5};
Arrays.sort(nums, (num1,num2)-> num1.compareTo(num2));
Arrays.sort(nums,Integer::compareTo); // 이렇게 해도 됨
```

```java
List<String> names = new ArrayList<>();
names.forEach(item->System.out.println(item));
names.forEach(System.out::println); // 같은거
```


## Stream
컬렉션, 배열 등 데이터 소스에 대한 공통된 접근 방식 제공
List, Array, Set ... -> stream -> stream 메소드


```java
public void oldStyle(){
	double sum = 0;
	int cnt = 0;
	for (String hero: heros){
		int length = hero.length();
		if(length > 3){
			sum+=length;
			cnt++;
		}
	}
	double avg = sum / cnt;
	System.out.println(avg);
}


public void streamStyle(){
	double avg = heros.stream().mapToInt(String::length).filter(len->len>3).average().getAsDouble();
	System.out.println(avg);
}
```
