
#### Java에서 문자열 뒤 n글자만 출력하는 법
```java
String str = "Hello, World!";
int n = 5;
String result = str.substring(str.length() - n);
System.out.println(result); // "orld!"
```

>[!note]
>문자열의 인덱스가 0부터 시작한다는 것은 알고 있었지만, `str.length()-n`이 왜 뒤에서부터 n번째 문자의 인덱스가 되는지 직관적으로 이해하지 못했다.
>lastIndex - n은 마지막 인덱스에서 n만큼 떨어진 위치를 의미한다. 
>예를 들어, 0 1 2 3 4 5인 문자열에서 lastIndex가 5이고 n이 3이면, 5 - 3 = 2 가 된다. 즉 마지막 인덱스 5에서 3칸 떨어진 2번 인덱스가 나온다.
>그러나 우리가 원하는 것은 마지막 인덱스인 5를 포함하여 뒤에 3개의 문자이므로, n이 아닌 n-1만큼 이동하여 5-3+1 = 3이 되어 3, 4, 5 가 나오도록 해야한다.
>또한, substring(idx)을 idx번 인덱스부터 문자열 n개 글자를 출력하는 관점으로 이해하고 있는것도 좋은 방법이다.
