
## 변수와 메서드


#### 선언위치에 따른 변수의 종류
| 종류    | 선언위치           | 변수종류      |
| ----- | -------------- | --------- |
| 맴버변수  | 클래스 영역(static) | 클래스 멤버변수  |
|       | 클래스 영역         | 인스턴스 멤버변수 |
| 지역 변수 | 함수 내부          | 지역 변수     |
|       | 함수 선언부         | 매개변수      |

**인스턴스 멤버변수**
변수의 생성 : 객체가 만들어질 때 Heap에 객체별로 생성됨
변수의 초기화 : 타입 별로 default 초기화 -> 명시적 할당값으로 초기화 -> 초기화 블록 -> 생성자에 의해 초기화
**클래스 멤버변수**
변수의 생성 : 클래스 로더에 의해 클래스가 로딩 될 때 구성
변수의 초기화 : 타입 별로 default 초기화 -> 할당된 값으로 초기화
소멸 시점 : 클래스가 unload 될 때
**지역변수 , 매개변수**
선언 위치 : 메서드, 생성자, 초기화블록
변수의 생성 : 선언된 라인 실행 될 때. stack의 메서드 프레임 내부
소멸 시점 : 선언 영역 {} 벗어날 때

#### JVM의 메모리 구조
Method Area는 왜 이름이 Method Area일까? 클래스 정보들이 들어가는데...
예전에는 클래스의 정보 중에서 메소드의 바이트코드(실행코드)가 이 영역의 핵심이었음. 그러나 점차 클래스 메타데이터, static 변수, 상수 풀, 생성자 코드 가 들어가면서 확장된것.
Java8 부터는 Metaspace라고 불린다.
