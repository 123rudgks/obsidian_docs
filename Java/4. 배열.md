
배열 요소의 초기화

| 자료형              | 기본값      | 비고           |
| ---------------- | -------- | ------------ |
| boolean          | false    |              |
| char             | '\u0000' | null 문자      |
| byte, short, int | 0        |              |
| long             | 0L       |              |
| float            | 0.0f     |              |
| double           | 0.0      |              |
| 참조형 변수           | null     | 아무것도 참조하지 않음 |


배열의 크기는 불변
- 최초 메모리 할당 이후 변경할 수 없음
- 개별 요소는 다른 값으로 변경 가능하나, 요소를 추가하거나 삭제할 수는 없음


`System.arraycopy()`와 `Arrays.copyOf()` 둘 다 이전에 HashSet에서 봤던 것과 똑같이, 객체 배열은 참조만 복사
```java
Person[] src  = {new Person("홍길동", 20)};
Person[] dest = Arrays.copyOf(src, 1);

dest[0].age = 999;
System.out.println(src[0].age); // 999 ← 같이 바뀜
```

2차원 Array 만들기
1차 Array만 생성 후, 필요에 따라 2차 배열을 생성함
이게 가능한 이유는 1차 배열은 배열을 담는 배열이기 때문, 즉 배열의 참조값이 들어간다. 이렇게 행마다 열의 크기가 다른 배열을 가변 배열이라고 한다.
```java
// 예: 1반 3명, 2반 5명, 3반 2명
String[][] students = new String[3][];

students[0] = new String[3]; // 1반
students[1] = new String[5]; // 2반
students[2] = new String[2]; // 3반
```
