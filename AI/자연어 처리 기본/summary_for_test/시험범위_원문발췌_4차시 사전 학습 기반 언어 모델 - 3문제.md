# 2. 사전학습의 두 단계

강의에서는 기본적인 Pre-trained Model 활용을 크게 두 Step으로 설명한다.

```text
Step 1
Pre-training

대규모 Text
↓
일반적인 Language Model 학습


Step 2
Fine-tuning

Pre-trained Model
+
특정 Task Data
↓
Task에 맞게 추가 학습
```

---

# 3. Pre-training

**Pre-training(사전학습)** 은 대규모 Data를 사용하여 Model에게 먼저 일반적인 언어 구조를 학습시키는 것이다.

예를 들어 Model은 Text를 통해

- Word 관계
    
- Context
    
- Sentence 구조
    
- 의미 관계
    
- Language Pattern
    

등을 넓게 학습한다.

즉 처음부터

```text
긍정 / 부정
```

같은 특정 Label만 배우는 것이 아니다.

---

# 4. Fine-tuning

Pre-training된 Model을 특정 Task Data에 맞춰 추가로 Training하는 것을 **Fine-tuning(미세조정)** 이라고 한다.

예:

```text
Pre-trained Language Model
      ↓
감성 분석 Data
      ↓
Fine-tuning
      ↓
Sentiment Model
```

또는

```text
Pre-trained Model
      ↓
문서 분류 Data
      ↓
Fine-tuning
```

으로 사용할 수 있다.

강의에서는 기존 Parameter가 특정 Task에 맞게 조금씩 수정되기 때문에 이를 미세조정이라고 설명한다.

---

# 5. 왜 Pre-training을 하는가?

과거에는 Task마다 별도의 Model을 만들고 별도로 Training하는 방식이 일반적이었다.

예:

```text
Sentiment Model
→ 별도 Architecture

NER Model
→ 별도 Architecture

Sentence Similarity Model
→ 별도 Architecture
```

하지만 이것은

- Architecture를 매번 설계해야 하고
    
- 각 Task마다 별도로 Training해야 하며
    
- Labelled Data도 많이 필요하다.
    

Pre-training은 이 구조를 바꾼다.

```text
하나의 거대한 General Model
      ↓
Task마다 조금씩 Fine-tuning
```

하는 방향이다.

---

# 66. 기존 Fine-tuning

기존에는 새로운 Task가 있으면

```text
Pre-trained Model
      ↓
Task Dataset
      ↓
Backpropagation
      ↓
Parameter Update
      ↓
Fine-tuned Model
```

이 필요했다.

즉 Model Parameter를 실제로 바꿨다.

---

# 67. In-context Learning

In-context Learning에서는 Parameter를 다시 Training하지 않는다.

대신 Input Context에

- Instruction
    
- Example
    
- Task Pattern
    

등을 제공한다.

Model이 이를 보고

> **지금 어떤 문제를 풀어야 하는지**

를 파악한다.

---

# 68. Training과 Learning을 강의에서 구분하는 방식

강의에서는 다음과 같이 구분한다.

### Training

```text
Model Parameter를 실제로 Update
```

### Learning

더 넓은 의미에서

```text
Pattern이나 Task를 파악하고
그에 맞는 행동을 하는 것
```

으로 설명한다.

따라서 In-context Learning은

```text
Parameter Update 없이
Forward Process만으로
Task Pattern을 파악
```

하는 Learning으로 설명한다.

---

# 69. In-context Learning 예

예를 들어 Prompt에

```text
English: hello
Korean: 안녕하세요

English: apple
Korean: 사과

English: book
Korean:
```

같은 Pattern을 주면 Model이

> 이것은 영어를 한국어로 번역하는 Task구나.

라고 Context에서 파악할 수 있다.

Parameter를 새로 Training하지 않아도 된다.

---

# 70. Example을 주는 이유

Task 설명만 제공할 수도 있고 Example을 같이 제공할 수도 있다.

```text
Instruction
+
Examples
```

가 있으면 Model이 Input Pattern을 더 명확하게 파악할 수 있다.

이것이 이후

- Zero-shot
    
- Few-shot
    

같은 Prompting 방식과 연결된다.

---

# 71. Chain-of-Thought

강의에서는 In-context Learning에서 단순히 정답 Example만 주는 것보다

> **문제를 해결하는 중간 사고/생성 과정의 Example**

까지 제공할 수 있다고 설명한다.

이를 **Chain-of-Thought(CoT)** 와 연결한다.

---

# 72. CoT의 직관

단순 Example:

```text
Question
→ Answer
```

보다

```text
Question
→ 중간 풀이 과정
→ Answer
```

형태의 Pattern을 제공한다.

그러면 Model이 수학·코딩 등의 문제에서 비슷한 중간 추론 Pattern을 생성하며 문제를 해결하도록 유도할 수 있다는 설명이다.
