# 0. 강의 전체 개요

Natural Language Processing, NLP에서는 결국 사람이 사용하는

- 단어
    
- 문장
    
- 문서
    

같은 Text를 Machine Learning Model이 처리할 수 있도록 만들어야 한다.

문제는 Text가 원래 숫자가 아니라는 것이다.

Machine Learning과 Deep Learning Model은 기본적으로 숫자 Vector와 Matrix를 입력으로 받는다.

따라서 가장 먼저 해결해야 하는 문제는

> **“단어를 어떻게 숫자로 표현할 것인가?”**

이다.

그 다음 문제는

> **“숫자로 바꾼 단어들을 어떻게 순서대로 연결해서 문장을 이해할 것인가?”**

이다.

이번 강의의 흐름은 다음과 같다.

```text
Text
 ↓
Word
 ↓
숫자로 표현해야 함
 ↓
One-hot Encoding
 ↓
문제
 ├─ 차원이 너무 큼
 └─ 단어 간 유사도 표현 불가
 ↓
Word Embedding
 ↓
Word2Vec
 ├─ Skip-gram
 └─ CBOW
 ↓
단어 표현 확보
 ↓
하지만 문장은
단어의 단순 집합이 아님
 ↓
Order / Sequence 중요
 ↓
RNN
 ↓
Hidden State로
이전 문맥 기억
 ↓
문장이 길어지면
Long-term Dependency 문제
 ↓
Vanishing Gradient
 ↓
LSTM
 ↓
Cell State
+
Forget/Input/Output Gate
 ↓
필요한 정보를
선택적으로 보존
```

---

# 1. NLP에서 Text는 계층적인 구조를 가진다

Text라고 해서 하나의 크기만 존재하는 것은 아니다.

```text
Word
 ↓
Sentence
 ↓
Document
```

처럼 길이와 복잡도가 증가한다.

따라서 강의에서는 가장 단순한 Word부터 시작해 Sentence 수준으로 확장한다.

### Word

Word Embedding

### Sentence / Sequential Data

RNN

### 더 긴 관계를 다루기 위한 개선

LSTM

이라는 흐름이다.

---

# 2. 자연어 처리의 첫 번째 문제 — Text는 숫자가 아니다

Machine Learning Model은 숫자 계산을 한다.

```text
Vector
Matrix
Probability
Gradient
```

등이 필요하다.

하지만

```text
"호텔"
"은행"
"사랑"
```

같은 단어 그 자체에는 Machine Learning이 바로 계산할 수 있는 Numerical Value가 없다.

따라서 먼저

```text
Word
 ↓
Numerical Representation
```

으로 변환해야 한다.

---

# 3. 문장에는 또 다른 문제가 있다

단어를 숫자로 바꾸는 것만으로 모든 NLP 문제가 해결되지는 않는다.

문장은 단어의 단순한 집합이 아니기 때문이다.

예:

```text
나는 너를 사랑해.
너는 나를 사랑해.
```

포함된 단어는 거의 동일하지만 **순서가 달라지면서 의미가 달라진다.**

따라서 NLP에서는

> **단어의 의미 + 단어의 순서**

를 함께 처리해야 한다.

---

# 4. 가장 단순한 단어 표현 — One-hot Encoding

단어를 숫자로 바꾸는 가장 기본적인 방법은 **One-hot Encoding**이다.

먼저 우리가 다루려는 모든 단어를 모아 Vocabulary를 만든다.

예:

```text
Vocabulary

1. Hotel
2. Conference
3. Work
```

그러면 각 단어를 Vocabulary 크기의 Vector로 만든다.

```text
Hotel
→ [1, 0, 0]

Conference
→ [0, 1, 0]

Work
→ [0, 0, 1]
```

이다.

---

# 5. One-hot Vector의 구조

Vocabulary Size가 `V`라면 각 Word Vector도 `V` Dimension이다.

그 Vector에서

```text
해당 단어의 위치
→ 1

나머지 모든 위치
→ 0
```

이다.

즉 One-hot의 `1`은 단어의 의미적인 크기를 뜻하는 것이 아니다.

> **Vocabulary에서 이 단어가 어느 Index에 해당하는가**

를 표시하는 것이다.

---

# 6. Vocabulary

**Vocabulary**는 Model이 처리할 대상으로 정한 단어들의 집합이다.

Vocabulary가

```text
50,000 Words
```

라면 Word 하나를 One-hot으로 표현할 때 Vector Dimension도

```text
50,000
```

이 된다.

즉

`Embedding Dimension = Vocabulary Size`

가 아니라 One-hot에서는

`One-hot Dimension = Vocabulary Size`

다.

---

# 7. Vocabulary가 커지면 One-hot도 매우 커진다

강의에서는 Task와 Corpus 규모에 따라 Vocabulary가 크게 달라질 수 있다고 설명한다.

예를 들어 강의에서는

- 음성 시스템: 약 수만 개 수준
    
- Penn Treebank 계열 Corpus: 약 5만 개 수준
    
- 큰 언어 모델 예시: 약 50만 개
    
- 검색 시스템: 훨씬 더 큰 Vocabulary
    

등의 규모를 예로 든다.

핵심은 정확한 숫자를 외우는 것이 아니라

> **현실적인 NLP에서는 Vocabulary가 매우 클 수 있다.**

는 것이다.

---

# 8. One-hot의 첫 번째 장점

One-hot은 최소한 서로 다른 단어를 확실히 구별한다.

```text
Hotel
≠
Conference
≠
Work
```

각 단어마다 서로 다른 Dimension의 위치에 `1`이 있기 때문이다.

따라서

> **단어 Identity를 표현하는 가장 단순한 방법**

이다.

---

# 9. 그런데 NLP에서 단어를 구별만 해서는 부족하다

실제 NLP에서는 단어 사이의 **Similarity**가 중요하다.

예:

```text
Size
Capacity
```

또는

```text
Smartphone
Mobile Phone
```

은 서로 관련된 의미를 가진다.

검색에서 사용자가

```text
노트북 배터리 사이즈
```

라고 검색했는데 문서에는

```text
노트북 배터리 용량
```

이라고 적혀 있을 수 있다.

Model이 `사이즈`와 `용량`의 관련성을 알 수 있어야 한다.

---

# 10. One-hot에서는 모든 서로 다른 단어가 완전히 독립적이다

예:

```text
Size
     = [1,0,0,0]

Capacity
     = [0,1,0,0]
```

두 Vector를 내적하면

`0`

이 된다.

다른 모든 서로 다른 One-hot Vector도 동일하다.

---

# 11. 같은 단어끼리는 내적이 1

같은 One-hot Vector끼리 내적하면

```text
[0,1,0]
·
[0,1,0]

= 1
```

이다.

하지만 다른 단어라면

```text
[0,1,0]
·
[0,0,1]

= 0
```

이다.

즉 One-hot 공간에서는

```text
같은 단어
→ 유사

다른 단어
→ 모두 동일하게 무관
```

처럼 처리된다.

---

# 12. One-hot은 Semantic Similarity를 표현하지 못한다

예를 들어

```text
Smartphone ↔ Mobile Phone
```

과

```text
Smartphone ↔ Banana
```

는 의미적으로 관계 정도가 매우 다르다.

그러나 One-hot에서는 두 관계 모두 Orthogonal하기 때문에 동일하게 내적값 `0`이 나온다.

따라서

> **One-hot은 단어 간 의미 관계를 표현하지 못한다.**

---

# 13. One-hot의 두 번째 문제 — Curse of Dimensionality

Vocabulary가 500,000개라면 단어 하나가

```text
500,000-dimensional Vector
```

가 된다.

그런데 실제 값 대부분은 `0`이다.

즉

```text
매우 높은 차원
+
매우 Sparse
```

한 Representation이다.

강의에서는 이러한 높은 차원에서 Pattern을 찾기 어려워지는 문제를 **Curse of Dimensionality(차원의 저주)** 와 연결한다.

---

# 14. One-hot의 문제 정리

One-hot Encoding에는 대표적으로 두 문제가 있다.

### 문제 1. Dimension이 너무 크다

```text
Dimension
=
Vocabulary Size
```

이므로 저장 및 계산 부담이 커진다.

### 문제 2. Semantic Similarity를 표현하지 못한다

다른 모든 단어가 서로 직교하므로

```text
은행 ↔ 금융

은행 ↔ 사과
```

의 차이를 제대로 표현할 수 없다.

---

# 15. 그래서 Word Embedding이 등장한다

우리가 원하는 표현은 다음과 같다.

```text
One-hot

[0,0,0,1,0,0,0,...]
매우 고차원
Sparse


Word Embedding

[0.17, -0.43, 0.82, ...]
상대적으로 저차원
Dense
```

즉

> **단어를 낮은 차원의 실수 Vector로 표현한다.**

이것이 **Word Embedding**이다.

---

# 16. Word Embedding의 핵심 아이디어 — Context

Word Embedding의 기본적인 철학은

> **“단어의 의미를 알고 싶으면 그 단어 주변에 어떤 단어들이 등장하는지를 보라.”**

이다.

사람 역시 단어의 뜻을 학습할 때 주변 문맥을 이용한다.

예를 들어

```text
은행
```

주변에

```text
금융
돈
규제
정부
위기
```

같은 단어가 반복적으로 나타난다면 이를 통해 `은행`이라는 단어의 의미적 특징을 배울 수 있다.

---

# 17. Distributional Representation

One-hot에서는 Word들이 서로 독립적인 Symbol처럼 표현된다.

Word Embedding에서는 다른 Word와의 관계를 통해 한 Word의 Representation을 학습한다.

이를 강의에서는 **Distributed Representation**의 관점으로 설명한다.

즉

> **단어 하나의 의미가 하나의 Dimension에만 들어가는 것이 아니라 여러 Dimension에 분산되어 표현된다.**

---

# 18. Dense Representation

One-hot은 대부분의 값이 `0`이다.

```text
Sparse
```

하다.

Word Embedding은 일반적으로

```text
[0.23, -0.71, 0.19, 0.84, ...]
```

처럼 여러 Dimension이 실수값을 가진다.

이를 **Dense Representation**이라고 한다.

---

# 19. Continuous Representation

One-hot은

```text
0 또는 1
```

의 Discrete Value를 사용한다.

Embedding은 연속적인 Real Number를 사용한다.

따라서 **Continuous Representation**이라고 볼 수 있다.

---

# 20. Word Embedding의 Dimension

Vocabulary가 500,000이라고 하더라도 Embedding Dimension까지 500,000일 필요가 없다.

예를 들어

```text
50
100
200
```

등 훨씬 작은 Dimension으로 표현할 수 있다.

따라서

```text
500,000-dimensional Sparse Vector
       ↓
100-dimensional Dense Vector
```

처럼 Dimension Reduction 효과를 얻는다.

---

# 21. 좋은 Embedding이란?

좋은 Word Embedding 공간에서는 의미적으로 관련된 Word들이 비슷한 Vector를 가지도록 학습된다.

```text
은행
금융
돈

→ Embedding Space에서 상대적으로 가까움
```

반대로 관계가 적은 단어들은 더 다른 Representation을 가진다.

---

# 22. Word2Vec

Word Embedding을 실제로 학습하는 대표적인 초기 방법이 **Word2Vec**이다.

Word2Vec에는 대표적으로 두 가지 학습 방식이 있다.

```text
Word2Vec
├─ Skip-gram
└─ CBOW
```

두 방식의 핵심 차이는

> **무엇을 Input으로 하고 무엇을 Output으로 예측하는가**

이다.

---

# 23. Skip-gram

Skip-gram에서는

```text
Center Word
→ Input

Context Words
→ Prediction Target
```

이다.

즉

> **중심 단어가 주어졌을 때 주변에 어떤 단어가 등장할지 예측한다.**

---

# 24. Skip-gram 예

문장에

```text
... into banking turning crisis ...
```

같은 Context가 있다고 하자.

중심 Word가

```text
banking
```

이면 주변 Word

```text
into
turning
crisis
...
```

들이 나타날 Probability를 높이도록 학습한다.

---

# 25. CBOW

CBOW는 **Continuous Bag of Words**다.

Skip-gram과 반대다.

```text
Context Words
→ Input

Center Word
→ Prediction Target
```

즉

> **주변 단어들을 보고 가운데 단어를 맞힌다.**

---

# 26. CBOW의 빈칸 맞히기 직관

예를 들어

```text
신데렐라는 궁전을 급히 떠나며
_____를 흘렸다.
```

라고 하자.

주변 Context를 보고

```text
구두
```

라는 Word를 예측해야 한다.

Model은 주변 단어를 먼저 Vector로 표현한 후 전체 Context Representation을 이용해 Vocabulary의 각 단어가 정답일 Probability를 예측한다.

---

# 27. Word2Vec의 Encoder와 Decoder

강의에서는 Word2Vec을

```text
Input
 ↓
Encoder
 ↓
Embedding
 ↓
Decoder
 ↓
Word Probability
```

구조로 설명한다.

### Encoder

Word를 낮은 차원의 Embedding으로 변환한다.

### Decoder

Embedding으로부터 Target Word의 Probability Distribution을 예측한다.

---

# 28. Word2Vec에서 정말 원하는 것은 무엇인가?

Decoder를 최종적으로 사용하려고 이 문제를 푸는 것만은 아니다.

중요한 결과물은

> **Word를 의미 있는 Vector로 변환하도록 학습된 Encoder**

다.

Context Prediction Task를 잘 풀기 위해 Encoder가 의미 관계를 담는 Representation을 학습하도록 만드는 것이다.

---

# 29. Ground Truth는 다시 One-hot을 사용할 수 있다

흥미로운 점은 Word Embedding이 One-hot 표현의 한계를 해결하기 위해 등장했지만, Word2Vec Training의 Target Label은 Vocabulary에 대한 One-hot 형태로 표현할 수 있다는 것이다.

예를 들어 정답이 `brown`이라면

```text
brown 위치
→ 1

나머지
→ 0
```

인 Probability Distribution을 Ground Truth로 사용할 수 있다.

---

# 30. Word2Vec의 학습 원리

전체적으로

```text
Input Word / Context
      ↓
Encoder
      ↓
Embedding
      ↓
Decoder
      ↓
Vocabulary Probability
      ↓
Ground Truth와 비교
      ↓
Loss
      ↓
Backpropagation
      ↓
Encoder / Decoder Update
```

를 반복한다.

앞에서 배운 일반 Neural Network Training과 동일한 구조다.

---

# 31. Context Window

Word2Vec에서는 문장 전체를 한 번에 모두 사용하는 것이 아니라 중심 Word 주변의 일정 범위를 사용한다.

이를 **Window**라고 한다.

예를 들어 Window Size가 5라면 강의에서는 중심 Word 앞뒤 일정 범위의 Word들을 Context로 사용하는 예를 설명한다.

---

# 32. CBOW 예 — The Quick Brown Fox...

예를 들어

```text
The quick brown fox ...
```

에서 `brown`이 Center Word이고 주변의

```text
the
quick
fox
...
```

를 Input Context로 사용할 수 있다.

CBOW는 이 Context를 이용해

```text
brown
```

Probability를 높이도록 학습한다.

---

# 33. 왜 이런 Training을 하면 Similarity가 생기는가?

비슷한 Context에서 등장하는 Word들은 비슷한 Prediction 문제를 반복해서 풀게 된다.

따라서

```text
Bank
Finance

Beautiful
Delightful
```

처럼 비슷한 Context를 공유하는 Word들이 비슷한 Embedding Representation을 갖도록 Parameter가 조정될 수 있다.

---

# 34. Skip-gram과 CBOW의 데이터 구성 차이

CBOW에서는 하나의 Context Window를

```text
Context 여러 개
→ Center 1개
```

라는 하나의 Sample로 볼 수 있다.

Skip-gram에서는 하나의 Center Word를 가지고 주변 Word 각각을 별도의 Prediction Pair로 만든다.

예:

```text
brown → quick
brown → fox
brown → the
...
```

따라서 같은 Window에서도 Skip-gram은 더 많은 Training Sample을 만들어낼 수 있다.

---

# 35. Skip-gram의 학습량

Skip-gram은 하나의 Center Word에 대해 Context Word별 Prediction을 반복한다.

따라서 CBOW에 비해

```text
Training Samples ↑
Training Time ↑
```

할 수 있다.

강의에서는 그 대신 상대적으로 정교한 Representation을 얻을 수 있다는 방향으로 설명한다.

---

# 36. Rare Word와 Skip-gram

자주 등장하는 Word는 어떤 방법에서도 많은 Training을 받을 수 있다.

반면 Rare Word는 CBOW처럼 Context를 합쳐 Center를 예측하는 과정에서는 상대적으로 Representation 학습 기회가 부족할 수 있다.

Skip-gram에서는 Rare Word가 Center가 되었을 때 여러 Context Prediction Pair를 만들 수 있으므로 강의에서는 Rare Word Representation을 더 정교하게 학습할 수 있다는 장점으로 설명한다.

---

# 37. 강의의 Skip-gram vs CBOW 정리

### CBOW

```text
Context
→ Center Word
```

- 상대적으로 학습이 빠름
    
- 주변 Context를 통합하여 Center를 예측
    

### Skip-gram

```text
Center Word
→ Context
```

- Training Pair가 더 많음
    
- 학습이 더 오래 걸릴 수 있음
    
- 강의에서는 희귀 Word 등에 더 정교한 Representation을 얻는 장점을 설명
    

---

# 38. 이제 Word에서 Sentence로

Word Embedding을 얻었다고 하자.

그러면 각 Word는 Vector다.

```text
나는
→ Vector A

너를
→ Vector B

사랑해
→ Vector C
```

그렇다면 이 Vector들을 단순히 더하면 문장을 표현할 수 있을까?

일부 간단한 Task에서는 사용할 수 있지만 문장의 중요한 특징인 **Order**가 사라진다.

---

# 39. 문장은 Bag가 아니라 Sequence다

예:

```text
나는 너를 사랑해.

너는 나를 사랑해.
```

Word Set은 비슷하지만 의미가 다르다.

따라서 문장을 이해하려면

```text
Word Identity
+
Order
```

가 모두 필요하다.

---

# 40. Sequence Data

순서가 중요한 Data를 **Sequential Data / Sequence Data**라고 한다.

Text뿐 아니라

### Audio

시간에 따른 Signal의 연속

### Video

Image Frame의 연속

등도 Sequence Data다.

따라서 Sequence Model은 NLP 외에도 다양한 분야에서 사용할 수 있다.

---

# 41. Sequence에서 발생하는 핵심 문제

Sequence에는 세 가지 중요한 특징이 있다.

### 1. Order

순서가 중요하다.

### 2. Variable Length

문장마다 Word 수가 다르다.

```text
5 Words
10 Words
30 Words
...
```

### 3. Long-term Dependency

서로 멀리 떨어진 Word 사이의 관계도 의미에 중요할 수 있다.

---

# 42. Long-term Dependency

문장 앞부분의 정보가 훨씬 뒤에 등장하는 Word 해석에 필요할 수 있다.

```text
초반 정보
───────────────→
              후반 해석
```

이를 **Long-term Dependency**와 연결한다.

문장이 길수록 이런 관계를 유지하기 어려워진다.

---

# 43. 일반 Feed-forward Network의 한계

기본 MLP는 보통 Fixed-size Input을 받는다.

예를 들어 MNIST라면

```text
784 Pixel Input
      ↓
Neural Network
      ↓
10-class Output
```

처럼 Dimension이 고정되어 있다.

하지만 Sentence Length는 계속 달라진다.

```text
Sentence A
→ 7 Words

Sentence B
→ 15 Words
```

따라서 일반적인 고정 Input 구조만으로 Sequence를 직접 다루기 어렵다.

---

# 44. Sequence Input/Output 형태

강의에서는 Sequence Task를 Input/Output Length 관점에서도 설명한다.

---

# 45. Many-to-One

가변 길이 Sequence를 입력으로 받고 하나의 Output을 만든다.

예:

### Sentiment Classification

```text
"The movie was incredibly ..."

여러 Words
      ↓
Positive / Negative
```

즉

```text
Many Inputs
→ One Output
```

이다.

---

# 46. One-to-Many

고정된 Input 하나에서 Sequence Output을 만든다.

대표적인 예:

### Image Captioning

```text
Image
 ↓
"A dog is running ..."
```

Image는 고정 Input이고 Text Output은 길이가 가변적이다.

---

# 47. Many-to-Many

Sequence를 입력받아 다른 Sequence를 출력한다.

예:

- Machine Translation
    
- Chatbot
    
- Text Generation
    
- 일부 Summarization
    

등이다.

```text
Input Sequence
      ↓
Model
      ↓
Output Sequence
```

---

# 48. RNN의 기본 아이디어

사람이 문장을 읽는 방식을 생각한다.

```text
첫 Word 읽음
↓
기억

두 번째 Word 읽음
↓
기존 기억 + 새 Word

세 번째 Word 읽음
↓
기존 기억 + 새 Word
```

처럼 한 Word씩 처리하면서 이전 내용을 기억한다.

이 아이디어를 Neural Network 구조로 만든 것이 **RNN(Recurrent Neural Network)** 이다.

---

# 49. Hidden State

RNN에서는 이전까지 읽은 정보를 담는 Vector를 **Hidden State**라고 한다.

`t` 시점의 Hidden State:

`h_t`

이는

> **t번째 Word까지 읽은 뒤 현재까지의 문맥을 요약한 Vector**

로 이해할 수 있다.

---

# 50. RNN의 기본 구조

현재 Hidden State는

- 이전 Hidden State `h_{t-1}`
    
- 현재 Input `x_t`
    

를 함께 이용해서 만든다.

개념적으로

`h_t = f(h_{t-1}, x_t)`

이다.

---

# 51. 기본 RNN 식

강의의 구조를 일반적인 형태로 정리하면

`h_t = tanh(W_hh h_{t-1} + W_xh x_t + b)`

처럼 생각할 수 있다.

즉

```text
이전 Context
h(t-1)
      +
현재 Word
x(t)
      ↓
Linear Transformation
      ↓
합산
      ↓
Non-linear Activation
      ↓
새로운 Hidden State
h(t)
```

이다.

---

# 52. RNN도 결국 기존 Neural Network 원리다

RNN이라고 해서 완전히 새로운 계산을 하는 것은 아니다.

앞에서 배운

```text
Linear Transformation
+
Activation
```

을 그대로 사용한다.

차이는

> **이전 Time Step의 Hidden State를 다시 Input으로 사용한다.**

는 점이다.

---

# 53. RNN에서 `x_t`

`x_t`는 현재 t번째 Word의 Numerical Representation이다.

따라서 실제 NLP에서는

```text
Word
 ↓
Word Embedding
 ↓
x_t
```

로 생각할 수 있다.

즉 Word Embedding과 RNN은 자연스럽게 연결된다.

---

# 54. Hidden State Dimension

예를 들어 Hidden State를

```text
50-dimensional Vector
```

라고 정했다면 매 Time Step마다

`h_t`

는 50 Dimension이다.

현재 Input Embedding Dimension이 다르더라도 Weight Matrix를 이용해서 Hidden State Dimension에 맞도록 Linear Transformation한다.

---

# 55. Weight Matrix의 역할

RNN에는 예를 들어

`W_hh`

와

`W_xh`

같은 Parameter가 있다.

### `W_hh`

이전 Hidden State를 새로운 Hidden Representation으로 변환.

### `W_xh`

현재 Input `x_t`를 Hidden Representation으로 변환.

두 결과를 더하고 Activation을 적용한다.

---

# 56. RNN의 중요한 특징 — Parameter Sharing

매 Time Step마다 새로운 Weight Matrix를 만드는 것이 아니다.

```text
Time 1
→ W_hh, W_xh

Time 2
→ 같은 W_hh, W_xh

Time 3
→ 같은 W_hh, W_xh
```

를 사용한다.

즉 **Parameters are shared across time.**

---

# 57. RNN의 순환 구조

처음

`h_0`

가 있다.

강의에서는 `h_0`를 초기값으로 두고 설명한다.

이후

```text
h₀ + x₁
→ h₁

h₁ + x₂
→ h₂

h₂ + x₃
→ h₃

...
```

를 반복한다.

---

# 58. `h₂`는 `x₂`만 표현하는 것이 아니다

매우 중요한 포인트다.

`h₂`는

```text
x₂만의 Representation
```

이 아니다.

`h₁`을 통해 `x₁`의 정보가 이미 전달되었기 때문에

```text
h₂
=
x₁과 x₂까지의 Context Representation
```

이라고 이해한다.

마찬가지로

`h_t`

에는 `x₁ ... x_t`까지의 문맥 정보가 압축되어 들어가기를 기대한다.

---

# 59. Hidden이라고 부르는 이유

Hidden State 내부의 각 Dimension이 정확히

```text
1번 Dimension = 주어
2번 Dimension = 감정
3번 Dimension = 과거형
```

처럼 인간이 직접 정의한 것은 아니다.

Task Loss를 줄이도록 Network가 Representation을 학습한다.

따라서 사람이 직접 해석하기 어려운 내부 Representation이라는 의미에서 **Hidden**이라는 표현을 사용한다.

---

# 60. RNN의 출력은 Task마다 다르게 사용할 수 있다

모든 Time Step의 Output을 반드시 사용할 필요는 없다.

어떤 Task냐에 따라 다르다.

---

# 61. Sentiment Classification

문장 전체를 읽은 뒤 긍정/부정을 판단한다면 마지막 Hidden State를 사용할 수 있다.

```text
x₁ → h₁
x₂ → h₂
...
x_T → h_T
          ↓
Sentiment
```

즉 **Many-to-One**이다.

---

# 62. Named Entity Recognition

**Named Entity Recognition(NER, 개체명 인식)** 은 각 Word가

- Person
    
- Location
    
- Organization
    
- 기타 Entity
    
- Entity 아님
    

등인지 판단한다.

따라서 각 Time Step마다 Output이 필요하다.

```text
Obama → Person
US    → Location
...
```

이 경우

```text
y₁
y₂
y₃
...
```

를 모두 사용할 수 있다.

---

# 63. Language Modeling에서도 각 Time Step Output 사용 가능

매 Time Step마다 다음 Word의 Probability Distribution을 예측한다면 Output Dimension은 Vocabulary Size가 될 수 있다.

예:

```text
h_t
 ↓
Vocabulary Probability
 ↓
다음 Word
```

따라서 RNN 구조 자체는 여러 Task에 적용할 수 있지만 실제 Model은 **주어진 Task와 Training Data에 맞게 학습**된다.

---

# 64. 하나의 RNN이 모든 Task를 자동으로 해결하는 것은 아니다

강의 Q&A에서도 이 부분을 구분한다.

RNN은 Sequence를 처리할 수 있는 **Architecture**다.

하지만

```text
영화 리뷰 감성 분석용 RNN
```

을 학습했다고 해서 자동으로

```text
상품 리뷰
번역
NER
```

까지 잘 수행하는 것은 아니다.

각 Task와 Dataset에 맞는 Training이 필요하다.

---

# 65. RNN Training

RNN도 Neural Network이므로

```text
Forward
 ↓
Prediction
 ↓
Loss
 ↓
Backpropagation
 ↓
Parameter Update
```

구조로 학습한다.

학습 Parameter는 대표적으로

- `W_xh`
    
- `W_hh`
    
- Output Weight 등
    

이다.

---

# 66. Time 방향으로도 Backpropagation해야 한다

RNN에서는 Parameter가 Time Step마다 공유된다.

그리고 현재 `h_t`가 이전 `h_{t-1}`에 의존한다.

따라서 뒤쪽 Loss가 앞 Time Step Parameter까지 영향을 미친다.

```text
Loss at t
 ↓
h_t
 ↓
h_(t-1)
 ↓
h_(t-2)
 ↓
...
```

로 Gradient가 전달된다.

---

# 67. RNN과 Vanishing Gradient

문장이 길어지면 Gradient를 앞 Time Step까지 전달하면서 여러 미분값을 계속 곱하게 된다.

```text
Gradient
× derivative
× derivative
× derivative
× ...
```

만약 이 값들의 절댓값이 반복해서 1보다 작으면 Gradient가 점점 작아진다.

이를 **Vanishing Gradient Problem**이라고 한다.

---

# 68. 왜 Vanishing Gradient가 NLP에서 문제가 되는가?

Gradient가 앞 Time Step까지 충분히 전달되지 않으면 오래전 Input이 현재 Prediction에 미친 영향을 제대로 학습하지 못한다.

즉

```text
가까운 Word 관계
→ 비교적 잘 학습

아주 멀리 떨어진 Word 관계
→ 학습 어려움
```

이 된다.

---

# 69. 결국 Long-term Dependency 문제가 생긴다

예를 들어 긴 영화 Review에서 후반의 표현을 해석하려면 앞에서 무엇을 이야기했는지를 기억해야 할 수 있다.

그런데 RNN이 오래전 Context를 충분히 보존하지 못하면

```text
"재미없다"
```

가

- 영화 전체가 재미없다는 것인지
    
- 특정 Joke 하나가 재미없다는 것인지
    

제대로 구분하기 어려워질 수 있다.

---

# 70. Machine Translation에서도 같은 문제

긴 영어 Sentence를 읽고 한국어를 생성한다고 하자.

입력 문장의 초반 정보가 Hidden State에서 사라져버리면 뒤에서 번역할 때

```text
처음에 어떤 내용이 있었는가?
```

를 충분히 활용하지 못한다.

따라서 Sequence가 길어질수록 Memory 유지가 중요하다.

---

# 71. RNN의 또 다른 구조적 한계

RNN은 매 Time Step마다

```text
기존 Hidden State
+
현재 Input
```

을 하나의 정해진 방식으로 계속 합친다.

하지만 모든 정보가 똑같이 중요한 것은 아니다.

예:

영화 Review 중간에 전혀 관련 없는 광고가 들어왔다면 이를 굳이 Memory에 강하게 저장할 필요가 없다.

RNN에는 기본적으로

> **“이 정보는 저장하고, 이 정보는 버리자.”**

라는 명시적인 Gate 구조가 없다.

---

# 72. 그래서 LSTM이 등장한다

**LSTM(Long Short-Term Memory)** 은 RNN의 장기 의존성 문제를 완화하기 위한 Architecture다.

가장 중요한 차이는 RNN의 Hidden State에 더해 별도의 **Cell State**를 둔다는 것이다.

```text
RNN

Hidden State h_t


LSTM

Hidden State h_t
+
Cell State c_t
```

---

# 73. Cell State

Cell State는 강의에서

> **장기간 유지할 정보를 저장하는 Memory**

로 설명된다.

RNN의 Hidden State 하나만으로 모든 정보를 계속 압축하는 대신 별도의 Memory Path를 만든다.

---

# 74. 왜 모든 정보를 그냥 저장하면 안 되는가?

Hidden State나 Cell State의 Dimension은 유한하다.

예:

```text
100-dimensional Vector
```

라고 하자.

무한한 정보를 전부 그대로 넣을 수는 없다.

따라서 중요한 것은

> **필요 없는 정보는 버리고 필요한 정보는 선택적으로 저장한다.**

는 것이다.

---

# 75. LSTM의 핵심 — Gate

어떤 정보를

- 잊을 것인가
    
- 새로 저장할 것인가
    
- 현재 Output으로 사용할 것인가
    

를 결정하기 위해 **Gate**를 둔다.

대표적으로

```text
Forget Gate
Input Gate
Output Gate
```

가 있다.

---

# 76. 왜 Gate에 Sigmoid를 사용하는가?

Sigmoid는 Output이

`0 ~ 1`

사이다.

그리고 Input이 충분히 크거나 작으면 Output이 각각

```text
1에 가까움
0에 가까움
```

이 된다.

따라서 강의에서는 이를

```text
0 ≈ OFF
1 ≈ ON
```

처럼 **Soft Switch**로 생각한다.

정확히 0 또는 1만 출력하는 것은 아니지만 정보를 얼마나 통과시킬지를 조절하기 좋다.

---

# 77. Gate는 사람이 직접 결정하지 않는다

예:

```text
이 Word는 중요하니까 Forget Gate = 1
```

처럼 사람이 수작업으로 정하지 않는다.

Gate 안에도 Weight와 Bias Parameter가 존재한다.

이 Parameter 역시 Loss를 기준으로 **Backpropagation을 통해 학습**된다.

---

# 78. Forget Gate

Forget Gate의 역할은

> **이전 Cell State `c_{t-1}`에서 어떤 정보를 얼마나 유지하거나 잊을지 결정하는 것**

이다.

개념적으로

```text
Previous Cell State
c(t-1)
      ↓
Forget Gate
      ↓
불필요한 정보 제거
```

이다.

---

# 79. Forget Gate의 Input

현재 무엇을 잊을지 결정하려면

- 이전 Context `h_{t-1}`
    
- 현재 Input `x_t`
    

를 사용한다.

즉

```text
Previous Context
+
Current Word
      ↓
Small Neural Network
      ↓
Sigmoid
      ↓
Forget Gate Vector
```

이다.

---

# 80. Forget Gate는 Vector다

Cell State가 100 Dimension이라면 Forget Gate도 100 Dimension으로 생각할 수 있다.

예:

```text
f_t
=
[0.99, 0.02, 0.87, ...]
```

각 Dimension마다 Cell State 정보를 어느 정도 남길지 결정한다.

---

# 81. Element-wise Multiplication

Forget Gate와 Cell State는 **Element-wise Multiplication**을 한다.

예:

```text
c_(t-1)
=
[5, 8, 3]

f_t
=
[1, 0, 1]

Element-wise Multiply
=
[5, 0, 3]
```

즉 Gate 값이 `0`에 가까운 Dimension은 정보가 제거되고 `1`에 가까운 Dimension은 유지된다.

---

# 82. Input Gate

Input Gate는

> **현재 새롭게 계산된 정보 중 어떤 것을 Cell State에 저장할지 결정한다.**

즉

```text
Current Information
      ↓
얼마나 Memory에 넣을까?
      ↓
Input Gate
```

이다.

---

# 83. Candidate Cell State

현재

- `h_{t-1}`
    
- `x_t`
    

를 이용해서 새롭게 Cell State에 넣을 후보 정보를 만든다.

이를 보통 Candidate Cell State로 생각한다.

강의에서는 `\tilde{c}_t` 형태로 설명한다.

---

# 84. Candidate는 RNN의 Hidden State 계산과 유사하다

기본적인 계산은

```text
Previous Context
+
Current Input
      ↓
Linear Transformation
      ↓
Non-linear Function
      ↓
Candidate Information
```

이다.

즉 RNN Hidden State를 계산했던 구조와 매우 비슷하다.

차이는 이 값을 바로 Hidden State로 사용하는 것이 아니라

> **Cell State에 저장할 후보 정보**

로 사용한다는 점이다.

---

# 85. Input Gate와 Candidate를 곱한다

```text
i_t
×
c̃_t
```

를 Element-wise하게 계산한다.

이를 통해 Candidate Information 중 실제로 저장할 부분만 선택한다.

예:

```text
Candidate
[0.8, -0.4, 0.9]

Input Gate
[1, 0, 0.5]

결과
[0.8, 0, 0.45]
```

처럼 생각할 수 있다.

---

# 86. 새로운 Cell State

새로운 `c_t`는 크게 두 부분으로 구성된다.

```text
이전 Memory 중
남길 정보

+

현재 Information 중
새로 넣을 정보
```

즉 개념적으로

`c_t = f_t ⊙ c_(t-1) + i_t ⊙ c̃_t`

이다.

여기서 `⊙`는 Element-wise Multiplication을 의미한다.

---

# 87. Cell State Update의 의미

결국 LSTM은 매 Time Step에서

```text
Previous Memory
      ↓
Forget
      ↓
필요한 것만 유지

Current Input
      ↓
Input Gate
      ↓
필요한 것만 추가

두 정보를 합침
      ↓
New Cell State
```

를 수행한다.

---

# 88. Output Gate

Cell State에는 현재 시점뿐 아니라 미래에도 필요한 정보가 들어 있을 수 있다.

따라서 Cell State의 모든 정보를 현재 Hidden State로 그대로 내보내는 것이 항상 적절한 것은 아니다.

Output Gate는

> **현재 Time Step에서 Cell State 중 어떤 정보를 Hidden State로 드러낼 것인가**

를 결정한다.

---

# 89. Cell State와 Hidden State는 역할이 다르다

강의의 직관은 다음과 같다.

### Cell State

전체적으로 보존하고 있는 장기 Memory.

### Hidden State

현재 Time Step에서 실제 계산 및 Output에 활용되는 보다 직접적인 Representation.

즉

```text
Cell State
= 저장된 넓은 Memory

Hidden State
= 현재 필요한 만큼 꺼낸 표현
```

으로 볼 수 있다.

---

# 90. Output Gate 구조

현재 Cell State를 Non-linear Transformation한 뒤 Output Gate를 곱해서 Hidden State를 만든다.

개념적으로

`h_t = o_t ⊙ tanh(c_t)`

형태로 이해할 수 있다.

즉

```text
Cell State
 ↓
tanh
 ↓
Output Gate와 Element-wise Multiply
 ↓
Current Hidden State
```

이다.

---

# 91. LSTM의 세 Gate 정리

|Gate|질문|역할|
|---|---|---|
|Forget Gate|과거 정보 중 무엇을 버릴까?|`c_(t-1)` 선택적 유지|
|Input Gate|현재 정보 중 무엇을 저장할까?|새 Candidate 선택|
|Output Gate|저장한 정보 중 지금 무엇을 사용할까?|현재 `h_t` 결정|

---

# 92. LSTM 한 Time Step의 전체 구조

```text
h_(t-1), x_t
      ↓
─────────────────────────
      ↓
Forget Gate
      ↓
c_(t-1)에서
불필요한 정보 제거
─────────────────────────
      ↓
Input Gate
+
Candidate c̃_t
      ↓
새로 저장할 정보 선택
─────────────────────────
      ↓
기존 정보 + 새 정보
      ↓
c_t
─────────────────────────
      ↓
Output Gate
      ↓
현재 사용할 정보 선택
      ↓
h_t
```

---

# 93. LSTM도 결국 학습 가능한 Neural Network다

Forget/Input/Output Gate가 Rule-based System은 아니다.

각 Gate 안의

- Weight
    
- Bias
    

가 모두 Trainable Parameter다.

Loss가 줄어드는 방향으로 Backpropagation을 통해 학습된다.

즉 Training 원리는 앞에서 배운 Neural Network와 같다.

---

# 94. LSTM이 RNN보다 더 긴 관계를 다루려는 이유

RNN에서는 정보를 매 Step마다 Hidden State 전체에 계속 혼합한다.

LSTM에서는 Cell State에 대해

```text
Forget
+
Add
```

라는 선택적 조작을 한다.

따라서 불필요한 정보를 버리고 필요한 정보를 더 오래 유지할 수 있도록 Architecture를 설계했다.

---

# 95. RNN과 LSTM 비교

|항목|RNN|LSTM|
|---|---|---|
|주요 Memory|Hidden State|Hidden State + Cell State|
|정보 저장|매 Step 동일한 기본 갱신|Gate로 선택적 갱신|
|Forget Mechanism|명시적 구조 없음|Forget Gate|
|New Information|Hidden State에 직접 통합|Input Gate로 선택|
|현재 Output 선택|기본 Hidden State|Output Gate|
|Long-term Dependency|어려움|개선 목적|
|구조|단순|복잡|

---

# 96. Cell State Dimension을 무한히 늘리면 좋은가?

강의 Q&A에서는 Cell/Hidden Vector의 Dimension을 무한히 늘리는 것이 무조건 좋은 것은 아니라고 설명한다.

Representation Dimension이 지나치게 커지면

```text
Information Compression
```

의 의미가 약해질 수도 있다.

즉 적절한 Dimension 안에 필요한 정보를 **Dense하게 압축**하도록 만드는 것이 중요하다는 관점이다.

---

# 97. Gate가 꼭 3개여야 하는가?

강의에서는 이것도 매우 중요한 Engineering 관점으로 설명한다.

```text
Forget
Input
Output
```

세 Gate가 자연법칙처럼 반드시 존재해야 하는 것은 아니다.

LSTM Architecture를 설계한 사람이 선택한 구조다.

따라서

- Gate 수가 다른 Architecture
    
- Gate 구조가 다른 Architecture
    

도 가능하다.

실제로 여러 LSTM Variant와 다른 Recurrent Architecture가 존재할 수 있다.

---

# 98. Architecture는 발명되고 실험된다

Machine Learning Architecture를 볼 때

> “왜 반드시 이 모양이어야 하지?”

라고 생각할 수 있다.

하지만 상당수 구조는

```text
아이디어 제안
 ↓
실험
 ↓
성능 확인
 ↓
표준적 방법으로 정착
```

한 Engineering Result다.

따라서 구조를 이해하되 절대적인 법칙으로 받아들이지 않는 관점도 중요하다.

# 99. Sigmoid와 tanh 차이

강의 Q&A에서는 두 Function의 사용 목적도 구분한다.

### Sigmoid

Output:

`0 ~ 1`

따라서

- Binary Probability
    
- Gate
    

등에 사용하기 좋다.

### tanh

Output:

`-1 ~ 1`

따라서 Hidden Representation 등에서 사용될 수 있다.

# 100. RNN에서 `h_t`는 언제 계산하는가?

새 Input `x_t`가 들어올 때마다 새로운 Hidden State를 계산한다.

```text
x₁
→ h₁

x₂
→ h₂

x₃
→ h₃
```

즉

> **새로운 Word가 들어올 때마다 지금까지의 Context를 새롭게 Update한다.**

---

# 101. Word Embedding과 RNN은 어떻게 연결되는가?

전체 NLP Pipeline에서 보면

```text
Raw Word
   ↓
Word Embedding
   ↓
x_t
   ↓
RNN / LSTM
   ↓
Context-aware Hidden State
   ↓
Task Output
```

이다.

Word Embedding은 **개별 Word의 Representation**을 만들고,

RNN/LSTM은 그 Word들을 순서대로 읽으면서 **Context를 포함하는 Sequence Representation**을 만든다.

---

# 102. Word Embedding과 Hidden State의 차이

### Word Embedding

```text
Word 자체의 Representation
```

예:

```text
bank
→ embedding vector
```

### Hidden State

```text
현재 Word뿐 아니라
이전 Context까지 반영한 Representation
```

예:

`h_t`

는 단순히 `x_t`가 아니다.

이전의 `h_(t-1)`까지 사용한다.

---

# 103. 왜 Word Embedding만으로 Sentence를 충분히 표현하기 어려운가?

Word Embedding을 단순히 합하면

```text
A + B + C
```

와

```text
C + B + A
```

가 같다.

즉 Order Information이 사라진다.

따라서

> **문장의 의미를 이해하기 위해 Sequence Model이 필요하다.**

---

# 104. One-hot → Embedding 변화

```text
[One-hot]

단어를 서로 구별한다.
        ↓
문제
 ├─ High Dimension
 ├─ Sparse
 └─ Semantic Similarity 없음
        ↓

[Embedding]

Low-dimensional
Dense
Continuous
Semantic Relation
```

---

# 105. Word2Vec의 역할

Word2Vec은

> **Word Embedding을 학습하기 위한 Training Task**

를 만든다.

단어 의미를 사람이 직접 Labeling하지 않는다.

대신 Corpus에서 자연스럽게 얻을 수 있는

```text
Center ↔ Context
```

관계를 Training Signal로 사용한다.

---

# 106. Word2Vec 전체 논리

```text
비슷한 의미의 Word는
비슷한 Context에서 자주 등장한다.
        ↓
그렇다면
Context Prediction Task를 시키자.
        ↓
Context를 잘 예측하려면
Word의 의미적 특징을
Encoder가 학습해야 한다.
        ↓
그 Encoder의 내부 Vector를
Word Embedding으로 사용
```

---

# 107. Skip-gram과 CBOW 최종 비교

|항목|Skip-gram|CBOW|
|---|---|---|
|Input|Center Word|Context Words|
|Output|Context Word|Center Word|
|핵심 질문|이 Word 주변에 무엇이 나오는가?|이 Context 가운데 무엇이 들어가는가?|
|Sample 수|상대적으로 많아질 수 있음|Window당 상대적으로 적음|
|강의 설명|느릴 수 있으나 희귀 Word 등에 강점|상대적으로 빠름|

---

# 108. Feed-forward와 RNN의 차이

### Feed-forward

```text
Fixed Input
→ Hidden
→ Fixed Output
```

각 Sample을 독립적으로 처리한다.

### RNN

```text
x₁ → h₁
      ↓
x₂ → h₂
      ↓
x₃ → h₃
```

이전 State를 다음 Step에 전달한다.

즉 **Memory 구조**가 존재한다.

---

# 109. RNN의 핵심 식을 구조로 기억하기

수식을 통째로 암기하기 전에 구조를 기억한다.

```text
Previous Memory
+
Current Input
      ↓
각각 Weight 적용
      ↓
합산
      ↓
Non-linear Activation
      ↓
New Memory
```

즉

`h_t = f(h_(t-1), x_t)`

가 본질이다.

---

# 110. RNN Parameter Sharing의 의미

Sequence Length가 10이라고 해서 서로 다른 RNN Model 10개를 만드는 것이 아니다.

하나의 RNN Cell을 시간축으로 반복해서 사용한다.

```text
Same RNN Cell
at t=1

Same RNN Cell
at t=2

Same RNN Cell
at t=3
```

Weight를 공유하기 때문에 Sequence Length가 달라져도 같은 Model을 적용할 수 있다.

---

# 111. RNN이 Variable Length를 처리할 수 있는 이유

Sentence Length가

```text
5
10
30
```

으로 달라도 동일한 RNN Operation을 필요한 만큼 반복하면 된다.

```text
Word 수가 5
→ 5 Step

Word 수가 30
→ 30 Step
```

따라서 Fixed Input Dimension이라는 일반 MLP의 제약을 완화한다.

---

# 112. 하지만 반복 구조 자체가 문제를 만든다

RNN의 장점인

```text
Repeated Recurrent Operation
```

이 Backpropagation에서는 반복적인 Gradient Multiplication으로 연결된다.

따라서 Sequence가 길어질수록 Vanishing Gradient 문제가 심해질 수 있다.

즉

```text
RNN의 순환 구조
→ Sequence 처리 가능

동시에

RNN의 순환 구조
→ 긴 Gradient Chain
→ Long-term Dependency 학습 어려움
```

이라는 Trade-off가 존재한다.

---

# 113. 앞선 신경망 적합 강의와 연결

앞 강의에서 Deep Network가 깊어지면

```text
Chain Rule
↓
여러 Gradient 곱
↓
Vanishing / Exploding Gradient
```

문제가 있다고 배웠다.

RNN에서도 비슷하다.

차이는 Layer Depth가 아니라 **Time Direction으로 Network를 펼쳤을 때 매우 깊어진다**는 것이다.

```text
t=1
 ↓
t=2
 ↓
t=3
 ↓
...
 ↓
t=T
```

이 긴 연결을 따라 Backpropagation해야 한다.

---

# 114. LSTM은 정보를 선택한다

RNN:

```text
이전 정보 + 현재 정보
→ 계속 갱신
```

LSTM:

```text
이전 정보
↓
무엇을 버릴까?

현재 정보
↓
무엇을 저장할까?

Cell Memory
↓
지금 무엇을 꺼내 쓸까?
```

로 바뀐다.

---

# 115. LSTM의 정보 흐름

```text
Past Cell State
       ↓
Forget Gate
       ↓
기억 유지/삭제
       ↓
      (+)
       ↑
Input Gate × Candidate
       ↑
현재 정보 중
저장할 부분
       ↓
New Cell State
       ↓
Output Gate
       ↓
Hidden State
```

---

# 116. Gate에서 Element-wise Multiplication을 쓰는 이유

Gate는 Vector의 Dimension별로 다른 정도로 정보를 통과시킨다.

```text
[정보 A, 정보 B, 정보 C]

Gate
[0.9, 0.1, 0.7]
```

이면

- A는 대부분 유지
    
- B는 대부분 억제
    
- C는 어느 정도 유지
    

처럼 선택적으로 조절할 수 있다.

---

# 117. LSTM의 목적을 한 문장으로

> **한정된 Memory 공간에서 모든 과거 정보를 무조건 같은 방식으로 누적하는 대신, Task에 필요한 정보만 선택적으로 유지·추가·출력해서 더 긴 Context를 다루려는 구조다.**

---

# 118. 자주 헷갈리는 점 ① — One-hot의 숫자에 의미가 있는가?

아니다.

`1`이 의미적으로 더 큰 Word라는 뜻이 아니다.

Vocabulary에서 해당 Word의 위치를 나타낼 뿐이다.

---

# 119. 자주 헷갈리는 점 ② — One-hot도 Vector이므로 Word Similarity를 계산할 수 있지 않은가?

계산 자체는 가능하지만 서로 다른 모든 Word가 직교한다.

따라서 의미적으로 가까운 Word와 먼 Word를 구분할 수 없다.

---

# 120. 자주 헷갈리는 점 ③ — Word Embedding Dimension은 Vocabulary Size인가?

아니다.

One-hot Dimension은 Vocabulary Size지만 Embedding Dimension은 훨씬 작게 설정할 수 있다.

예:

```text
Vocabulary = 500,000

Embedding = 100
```

---

# 121. 자주 헷갈리는 점 ④ — Word2Vec 자체가 RNN인가?

아니다.

Word2Vec은 Word Embedding을 학습하기 위한 방법이고, 강의에서는 Encoder/Decoder 구조의 Context Prediction Task로 설명한다.

RNN은 Sequence를 처리하기 위한 별도의 Architecture다.

---

# 122. 자주 헷갈리는 점 ⑤ — Skip-gram과 CBOW

반드시 방향을 기억한다.

```text
Skip-gram

Center
→ Context


CBOW

Context
→ Center
```

---

# 123. 자주 헷갈리는 점 ⑥ — CBOW에서 Word Order를 세밀하게 이해하는가?

강의에서 CBOW는 Context를 모아서 Center Word를 예측하는 단순한 구조로 설명한다.

따라서 Sentence 전체의 섬세한 Sequence Order를 다루기에는 한계가 있고, 이것이 RNN으로 넘어가는 배경 중 하나다.

---

# 124. 자주 헷갈리는 점 ⑦ — `h_t`는 현재 Word Embedding인가?

아니다.

```text
x_t
= 현재 Word Representation

h_t
= 이전 Context + 현재 Word를 반영한 State
```

다.

---

# 125. 자주 헷갈리는 점 ⑧ — RNN은 매 Time마다 다른 Parameter를 쓰는가?

아니다.

기본 RNN에서는 같은 Weight Matrix를 Time Step마다 공유한다.

---

# 126. 자주 헷갈리는 점 ⑨ — RNN은 마지막 Hidden State만 항상 사용하는가?

아니다.

Task에 따라 다르다.

### Sentiment Classification

마지막 State를 사용할 수 있음.

### NER

모든 Time Step Output 필요.

### Language Modeling

매 Time Step Output 사용 가능.

---

# 127. 자주 헷갈리는 점 ⑩ — Vanishing Gradient는 정보 자체가 즉시 0이 되는 것인가?

핵심 문제는 Training 시 Backpropagation Gradient가 앞 Time Step까지 갈수록 매우 약해져 먼 관계에 대한 Parameter Update가 어려워진다는 것이다.

그 결과 Model이 Long-term Dependency를 학습하기 어려워진다.

---

# 128. 자주 헷갈리는 점 ⑪ — LSTM은 Hidden State 대신 Cell State만 쓰는가?

아니다.

둘 다 사용한다.

```text
Cell State
+
Hidden State
```

가 존재한다.

---

# 129. 자주 헷갈리는 점 ⑫ — Forget Gate는 정보를 완전히 0 또는 1로만 결정하는가?

아니다.

Sigmoid Output은 연속적인

`0~1`

사이의 실수값이다.

따라서 실제로는 정보를 어느 정도 유지하거나 억제하는 **Soft Gating**이다.

---

# 130. 자주 헷갈리는 점 ⑬ — Gate 값은 사람이 정하는가?

아니다.

# 131. 자주 헷갈리는 점 ⑭ — Cell State에 있는 모든 정보가 현재 Hidden State로 출력되는가?

아니다.

Output Gate가 현재 Time Step에서 사용할 정보를 선택한다.

Cell State에는 미래에 사용할 정보까지 더 넓게 보존될 수 있다는 것이 강의의 직관이다.

# 134. 이번 강의에서 반드시 기억할 핵심

### 1. NLP Model이 Text를 처리하려면 먼저 Word를 Numerical Vector로 바꿔야 한다.

### 2. One-hot은 Vocabulary Size만큼 Dimension을 가진다.

### 3. One-hot은 다른 Word들을 구별할 수 있지만 Semantic Similarity를 표현하지 못한다.

### 4. Vocabulary가 커지면 One-hot은 High-dimensional Sparse Representation이 된다.

### 5. Word Embedding은 Word를 Low-dimensional Dense Continuous Vector로 표현한다.

### 6. Word Embedding의 핵심은 Context를 통해 Word의 의미적 관계를 학습하는 것이다.

### 7. Word2Vec은 대표적인 Word Embedding 학습 방법이다.

### 8. Skip-gram은 Center Word로 Context Word를 예측한다.

### 9. CBOW는 Context Word들로 Center Word를 예측한다.

### 10. Word2Vec Training의 핵심 결과물은 의미 있는 Word Representation을 만드는 Encoder다.

### 11. 문장은 Word들의 단순한 집합이 아니라 Order가 중요한 Sequence다.

### 12. Sequence는 Variable Length이며 Long-term Dependency가 존재한다.

### 13. RNN은 이전 Hidden State와 현재 Input을 이용해 새로운 Hidden State를 만든다.

### 14. `h_t`는 현재 Word만이 아니라 이전 Context까지 포함하는 Representation이다.

### 15. RNN은 Time Step마다 동일한 Parameter를 공유한다.

### 16. RNN은 Variable-length Sequence를 순차적으로 처리할 수 있다.

### 17. RNN은 긴 Sequence에서 Vanishing Gradient 때문에 Long-term Dependency 학습이 어려울 수 있다.

### 18. LSTM은 Hidden State와 별도로 Cell State를 둔다.

### 19. Forget Gate는 과거 정보 중 무엇을 버릴지 결정한다.

### 20. Input Gate는 현재 정보 중 무엇을 새 Memory에 저장할지 결정한다.

### 21. Output Gate는 Cell State 중 지금 Hidden State로 사용할 정보를 선택한다.

### 22. Gate는 Sigmoid를 이용한 0~1 사이의 Soft Switch다.

### 23. Gate의 판단 역시 사람이 정하는 것이 아니라 Trainable Parameter를 Backpropagation으로 학습한 결과다.

### 24. LSTM은 불필요한 정보를 선택적으로 제거하고 필요한 정보를 보존함으로써 RNN보다 긴 Context를 다루려는 Architecture다.

# 135. 이번 강의의 핵심을 한 문장으로

> **자연어 처리에서는 먼저 단어를 계산 가능한 Vector로 표현해야 하며, One-hot Encoding의 높은 차원과 의미 관계 부재를 해결하기 위해 Context를 이용한 Dense Word Embedding을 학습하고, 이러한 Word Vector를 순서대로 처리하기 위해 RNN이 이전 문맥을 Hidden State에 누적하며, 긴 Sequence에서 발생하는 장기 의존성과 Gradient 소실 문제를 완화하기 위해 LSTM이 Cell State와 Gate를 통해 기억할 정보를 선택적으로 관리한다.**

가장 짧은 흐름으로 기억하면 다음과 같다.

```text
One-hot
→ "어떤 단어인가?"

Embedding
→ "이 단어는 다른 단어와 어떤 의미 관계인가?"

RNN
→ "지금까지 읽은 문맥은 무엇인가?"

LSTM
→ "그 문맥 중 무엇을 오래 기억하고 무엇을 버릴 것인가?"
```
