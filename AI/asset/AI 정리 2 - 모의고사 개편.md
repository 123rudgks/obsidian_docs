## Ⅰ. 객관식 — 1~20번

### LSTM 게이트

**1.** LSTM이 일반 RNN보다 장기 의존성을 학습하기 유리한 핵심 이유는?

- a. 모든 과거 입력을 원본 그대로 저장하기 때문에
- b. 순환 구조를 완전히 제거했기 때문에
- c. 장기 기억용 cell state와 현재 출력용 hidden state를 분리하고, 게이트로 정보 흐름을 조절하기 때문에
- d. 모든 게이트의 값을 사람이 직접 정하기 때문에
- e. 역전파를 사용하지 않기 때문에

> [!success]- 정답 및 해설
>
> **정답: c**
>
> LSTM은 장기 정보가 이동하는 cell state를 별도로 두고, Forget·Input·Output gate로 정보의 유지·추가·출력을 조절한다. 기울기 소실을 완전히 제거하는 것은 아니지만 일반 RNN보다 장기 정보 전달에 유리하다.
>
> **오답 해설**
>
> - **a.** 모든 입력을 원본 그대로 저장하는 것이 아니라 게이트로 필요한 정보만 선택한다.
> - **b.** LSTM도 RNN의 순환 구조를 유지한다.
> - **d.** 게이트 값은 현재 입력과 이전 상태에 따라 모델이 동적으로 계산한다.
> - **e.** LSTM도 시간축 역전파를 통해 학습한다.

**2.** LSTM의 세 게이트 역할을 올바르게 연결한 것은?

- a. Forget gate—새 후보 정보 생성 / Input gate—현재 출력 결정 / Output gate—기존 기억 삭제
- b. Forget gate—이전 기억의 유지 비율 / Input gate—후보 정보의 반영 비율 / Output gate—cell state를 hidden state로 내보낼 비율
- c. Forget gate—단어 순서 저장 / Input gate—기울기 계산 / Output gate—파라미터 갱신
- d. 세 게이트 모두 동일한 역할을 한다
- e. Output gate만 cell state 갱신에 사용된다

> [!success]- 정답 및 해설
>
> **정답: b**
>
> Forget gate는 기존 기억의 유지 정도, Input gate는 candidate의 반영 정도, Output gate는 새 cell state 가운데 현재 hidden state로 드러낼 정도를 결정한다.
>
> **오답 해설**
>
> - **a.** 세 게이트의 역할을 서로 잘못 연결했다.
> - **c.** 단어 순서 저장·기울기 계산·파라미터 갱신은 세 게이트의 직접 역할이 아니다.
> - **d.** 각 게이트는 유지·추가·출력이라는 서로 다른 정보 흐름을 제어한다.
> - **e.** cell state 갱신에는 Forget gate와 Input gate가 직접 사용된다.

**3.** Input gate $i_t$와 candidate cell state $\tilde C_t$의 차이로 옳은 것은?

- a. $i_t$는 무엇을 넣을지, $\tilde C_t$는 얼마나 넣을지 결정한다
- b. 둘은 항상 같은 벡터이다
- c. $i_t$는 얼마나 반영할지 정하는 비율이고, $\tilde C_t$는 새로 추가할 후보 정보이다
- d. 둘 다 이전 기억을 얼마나 유지할지만 정한다
- e. 둘 다 sigmoid를 거친 0 또는 1의 이산값이다

> [!success]- 정답 및 해설
>
> **정답: c**
>
> $i_t$는 “얼마나 넣을 것인가”, $\tilde C_t$는 “무엇을 넣을 것인가”에 해당한다. 실제 추가되는 정보는 $i_t\odot\tilde C_t$이다.
>
> **오답 해설**
>
> - **a.** $i_t$와 $\tilde C_t$의 역할을 반대로 설명했다.
> - **b.** 두 벡터는 별도 가중치와 활성화 함수로 계산되며 같지 않다.
> - **d.** 이전 기억의 유지 비율은 Forget gate $f_t$가 담당한다.
> - **e.** $i_t$는 sigmoid의 연속값이고 candidate는 주로 tanh를 사용한다.

### 언어모델

**4.** 언어모델의 핵심 역할로 가장 적절한 것은?

- a. 모든 문장을 동일한 확률로 평가한다
- b. 가능한 단어 시퀀스에 확률을 부여하고 이전 문맥으로 다음 단어의 확률을 예측한다
- c. 문장의 단어 순서를 무시하고 단어 개수만 센다
- d. 반드시 번역 병렬 코퍼스만으로 학습한다
- e. 단어를 이미지 픽셀로 변환한다

> [!success]- 정답 및 해설
>
> **정답: b**
>
> 언어모델은 모든 가능한 유한 단어 시퀀스에 확률을 부여한다. 문장 생성 관점에서는 이전 단어들이 주어졌을 때 다음 단어의 조건부 확률을 반복해서 예측한다.
>
> **오답 해설**
>
> - **a.** 자연스러운 시퀀스와 부자연스러운 시퀀스에 서로 다른 확률을 부여한다.
> - **c.** 언어모델의 조건부 확률에는 단어 순서와 이전 문맥이 중요하다.
> - **d.** 일반 언어모델은 단일 언어 텍스트만으로도 학습할 수 있다.
> - **e.** 텍스트를 이미지 픽셀로 변환하는 모델이 아니다.

**5.** 문장 확률의 조건부 확률 분해로 옳은 것은?

- a. $p(w_1,\ldots,w_N)=\sum_{t=1}^N p(w_t)$
- b. $p(w_1,\ldots,w_N)=p(w_N)$
- c. $p(w_1,\ldots,w_N)=p(w_1)\prod_{t=2}^N p(w_t\mid w_1,\ldots,w_{t-1})$
- d. $p(w_1,\ldots,w_N)=\prod_{t=1}^N p(w_{t-1}\mid w_t)$
- e. $p(w_1,\ldots,w_N)=1/N$

> [!success]- 정답 및 해설
>
> **정답: c**
>
> 연쇄법칙에 따라 문장 전체 확률은 첫 단어의 확률과, 그 뒤 각 단어가 이전 문맥 뒤에 나타날 조건부 확률의 곱으로 분해된다.
>
> **오답 해설**
>
> - **a.** 서로 이어지는 사건의 결합확률은 단순 주변확률의 합이 아니다.
> - **b.** 마지막 단어의 확률 하나만으로 전체 문장 확률을 나타낼 수 없다.
> - **d.** 일반 자기회귀 언어모델은 미래에서 과거가 아니라 과거에서 다음 단어를 조건화한다.
> - **e.** 문장 확률은 길이의 역수로 고정되지 않고 각 조건부 확률에 따라 달라진다.

**6.** 4-gram 언어모델이 다음 단어를 예측할 때 직접 사용하는 문맥은?

- a. 문장 전체의 모든 이전 단어
- b. 직전 1개 단어
- c. 직전 2개 단어
- d. 직전 3개 단어
- e. 다음에 올 4개 단어

> [!success]- 정답 및 해설
>
> **정답: d**
>
> n-gram 모델은 다음 단어를 예측할 때 직전 $n-1$개 단어만 사용한다고 근사한다. 따라서 4-gram은 직전 3개 단어를 본다.
>
> **오답 해설**
>
> - **a.** 전체 문맥을 쓰는 대신 제한된 범위만 사용한다는 것이 n-gram 근사의 핵심이다.
> - **b.** 직전 1개만 보는 것은 bigram이다.
> - **c.** 직전 2개만 보는 것은 trigram이다.
> - **e.** 아직 생성되지 않은 미래 단어를 조건으로 사용할 수 없다.

### 어텐션

**7.** 기본 Seq2Seq에 Attention이 필요해진 직접적인 원인은?

- a. 입력과 출력의 길이가 항상 같기 때문에
- b. 입력 전체를 마지막 hidden state 하나에 압축하면서 긴 문장의 정보가 손실되는 병목 문제 때문에
- c. 인코더와 디코더가 같은 가중치를 공유하기 때문에
- d. 디코더가 출력을 한 번에 모두 생성하기 때문에
- e. Attention이 없으면 단어 임베딩을 만들 수 없기 때문에

> [!success]- 정답 및 해설
>
> **정답: b**
>
> 기본 Seq2Seq은 입력 길이와 관계없이 문장 전체를 고정 길이 벡터 하나로 압축한다. 문장이 길수록 정보 손실이 커지는 병목을 완화하기 위해 디코더가 인코더의 모든 상태를 직접 참조하도록 Attention이 도입되었다.
>
> **오답 해설**
>
> - **a.** 입력과 출력 길이가 다를 수 있는 것이 Seq2Seq의 장점이다.
> - **c.** 인코더와 디코더는 서로 다른 가중치를 사용한다.
> - **d.** RNN 기반 디코더는 출력을 순차적으로 생성한다.
> - **e.** Attention 없이도 임베딩은 만들 수 있으며 문제는 고정 벡터 병목이다.

**8.** Attention의 context vector $a_t=\sum_i\alpha_i^t h_i$에 대한 설명으로 옳은 것은?

- a. Attention 확률 $\alpha_i^t$만 모두 더한 숫자이다
- b. 인코더의 마지막 hidden state만 복사한 값이다
- c. Attention 가중치를 이용해 인코더 hidden state들을 가중합한 정보 벡터이다
- d. 디코더가 시작하기 전에 한 번만 계산되고 고정된다
- e. 항상 모든 $h_i$에 같은 가중치를 부여한다

> [!success]- 정답 및 해설
>
> **정답: c**
>
> $\alpha_i^t$는 각 입력 위치를 참고할 비율이고, $h_i$는 실제 입력 정보를 담은 벡터이다. context vector는 확률의 단순합이 아니라 이 비율로 정보 벡터들을 섞은 가중합이다.
>
> **오답 해설**
>
> - **a.** Attention 확률만 더하면 항상 1일 뿐 실제 입력 정보가 담기지 않는다.
> - **b.** Attention은 마지막 상태만이 아니라 모든 인코더 hidden state를 사용한다.
> - **d.** Attention context vector는 출력 시점마다 새로 계산된다.
> - **e.** 디코더 상태와 입력 위치의 관련도에 따라 가중치가 달라진다.

**9.** Seq2Seq Attention의 Q, K, V 출처로 옳은 것은?

- a. Query는 인코더, Key와 Value는 디코더
- b. Query는 디코더 상태, Key와 Value는 인코더 hidden state
- c. Query, Key, Value가 모두 출력 정답 토큰
- d. Query와 Key는 손실 함수, Value는 학습률
- e. Query, Key, Value가 항상 서로 같은 벡터

> [!success]- 정답 및 해설
>
> **정답: b**
>
> 디코더의 현재 상태가 “지금 원문의 어떤 정보가 필요한가”를 묻는 Query가 되고, 인코더의 각 hidden state가 비교 대상인 Key이자 실제 전달할 정보인 Value가 된다.
>
> **오답 해설**
>
> - **a.** Query와 Key·Value의 출처를 반대로 적었다.
> - **c.** 정답 토큰이 Q·K·V 전체를 직접 구성하는 것은 아니다.
> - **d.** 손실 함수와 학습률은 Attention의 Q·K·V가 아니다.
> - **e.** Seq2Seq Attention에서는 Query와 Key·Value가 서로 다른 시퀀스에서 온다.

### 셀프 어텐션

**10.** Self-Attention과 Seq2Seq Attention의 가장 핵심적인 차이는?

- a. Self-Attention은 가중합을 사용하지 않는다
- b. Self-Attention은 같은 시퀀스 내부의 토큰끼리 서로 참조하고, Seq2Seq Attention은 디코더와 인코더라는 서로 다른 시퀀스를 연결한다
- c. Seq2Seq Attention만 Q, K, V를 사용한다
- d. Self-Attention은 순차적으로 한 토큰씩만 계산할 수 있다
- e. 두 메커니즘은 출처까지 완전히 동일하다

> [!success]- 정답 및 해설
>
> **정답: b**
>
> Self-Attention에서는 Q, K, V가 같은 시퀀스에서 만들어진다. Seq2Seq Attention에서는 디코더의 상태가 Query, 인코더의 상태가 Key·Value가 되어 입력과 출력을 연결한다.
>
> **오답 해설**
>
> - **a.** Self-Attention도 Value의 가중합으로 출력을 만든다.
> - **c.** 두 방식 모두 일반화하면 Q, K, V 관점으로 설명할 수 있다.
> - **d.** Self-Attention은 한 층의 모든 토큰 표현을 병렬로 계산할 수 있다.
> - **e.** 핵심 계산 원리는 비슷하지만 Q·K·V의 출처가 다르다.

**11.** Self-Attention에서 하나의 토큰 임베딩으로 Q, K, V를 따로 만드는 이유는?

- a. 같은 벡터를 세 번 복사해 파라미터 수만 늘리기 위해
- b. 관련도를 요청하는 역할, 비교되는 역할, 실제 전달되는 정보 역할을 서로 다른 표현 공간에서 학습하기 위해
- c. 단어의 위치를 자동으로 완벽히 알기 위해
- d. softmax를 사용하지 않기 위해
- e. 미래 토큰을 자동으로 제거하기 위해

> [!success]- 정답 및 해설
>
> **정답: b**
>
> $W^Q,W^K,W^V$를 각각 적용하면 같은 토큰이 Query, Key, Value라는 서로 다른 역할에 적합한 표현을 학습할 수 있다.
>
> **오답 해설**
>
> - **a.** 세 행렬은 단순 복사가 아니라 서로 다른 학습 파라미터이다.
> - **c.** 토큰 위치는 별도의 Positional Encoding으로 제공한다.
> - **d.** 관련도 점수를 확률분포로 바꾸기 위해 softmax를 사용한다.
> - **e.** 미래 참조 차단은 causal mask의 역할이다.

**12.** Self-Attention의 한계와 보완 방법의 연결로 옳지 않은 것은?

- a. 순서 정보 부재 — Positional Encoding
- b. 위치별 비선형 변환 부족 — Feed-Forward Network
- c. 미래 참조 문제 — Masked Self-Attention
- d. 모든 토큰 쌍 비교의 메모리 비용 — Teacher Forcing
- e. 미래 위치 점수를 $-\infty$로 설정 — softmax 후 해당 가중치 0

> [!success]- 정답 및 해설
>
> **정답: d**
>
> Teacher Forcing은 Seq2Seq 디코더 학습에서 이전 예측 대신 정답 토큰을 다음 입력으로 주는 기법이다. Self-Attention의 $O(n^2)$ 계산·메모리 문제를 해결하는 방법은 아니다.
>
> **오답 해설**
>
> - **a.** 위치 벡터를 더하면 순서 정보 부재를 보완한다.
> - **b.** FFN은 모은 정보를 위치별로 비선형 변환한다.
> - **c.** Masked Self-Attention은 미래 정답 토큰의 참조를 막는다.
> - **e.** $\exp(-\infty)=0$이므로 해당 위치의 softmax 가중치가 0이 된다.

### 멀티 헤드 어텐션

**13.** Multi-Head Attention을 사용하는 주된 이유는?

- a. 모든 head가 같은 관계만 반복해서 보게 하기 위해
- b. 문법, 의미, 시제 등 여러 관점의 토큰 관계를 동시에 포착하기 위해
- c. Attention Score 계산을 제거하기 위해
- d. 단어 순서를 역순으로 바꾸기 위해
- e. head마다 서로 다른 입력 문장을 요구하기 때문에

> [!success]- 정답 및 해설
>

### 셀프 어텐션

**30.** Self-Attention의 Q, K, V 생성식을 쓰시오.

> [!success]- 정답 및 해설
>
> $$q_i=W^Qx_i,\qquad k_i=W^Kx_i,\qquad v_i=W^Vx_i$$
>
> 같은 토큰 임베딩 $x_i$에 서로 다른 학습 가능 행렬을 곱해 세 역할의 표현을 만든다.

**31.** $e_{ij}=q_i^\top k_j$ 이후 Attention 가중치 $\alpha_{ij}$와 출력 $o_i$를 구하는 수식을 쓰시오.

> [!success]- 정답 및 해설
>
> $$
> \alpha_{ij}=\frac{\exp(e_{ij})}{\sum_{j'}\exp(e_{ij'})},
> \qquad
> o_i=\sum_j\alpha_{ij}v_j
> $$
>
> Query·Key의 유사도를 softmax로 정규화한 뒤 Value를 가중합한다.

**32.** Self-Attention의 정보 전달 경로 길이가 $O(1)$이지만 계산량과 메모리는 일반적으로 $O(n^2)$인 이유를 쓰시오.

> [!success]- 예시 답안 및 해설
>
> 한 층에서 어떤 두 토큰도 직접 연결되므로 두 토큰 사이의 경로 길이는 상수이다. 그러나 길이 $n$의 시퀀스에서 모든 토큰 쌍의 점수를 계산해야 하므로 점수 행렬의 크기와 연산량은 $n^2$에 비례한다.

### Seq2Seq와 Transformer

**35.** Seq2Seq 디코더가 추론 시 직전 시점에 자신이 예측한 토큰을 다음 입력으로 다시 사용하는 구조를 무엇이라고 하는가?

> [!success]- 정답 및 해설
>
> **정답: 자기회귀(autoregressive) 구조**
>
> 디코더는 지금까지 생성한 토큰을 조건으로 다음 토큰을 순차적으로 예측한다.

**36.** Transformer의 Encoder Self-Attention에는 일반적으로 causal mask를 사용하지 않지만 Decoder Self-Attention에는 사용하는 이유를 쓰시오.

> [!success]- 예시 답안 및 해설
>
> Encoder는 입력 전체를 이해하는 것이 목적이므로 앞뒤 문맥을 모두 볼 수 있다. Decoder는 다음 토큰을 예측하므로 학습 시 미래 정답 토큰을 보지 못하도록 causal mask가 필요하다.

**37.** Transformer의 Cross-Attention에서 Query, Key, Value가 각각 어디에서 오는지 쓰시오.

> [!success]- 정답 및 해설
>
> **Query:** Decoder 상태  
> **Key·Value:** Encoder 출력
>
> Decoder가 현재 생성에 필요한 입력 정보를 Encoder 표현에서 검색하는 구조이다.

### 파인튜닝

**38.** 사전학습과 파인튜닝의 학습 목적을 각각 한 문장으로 구분하시오.

**39.** BERT를 문장 감성 분류에 파인튜닝할 때 주로 어느 위치의 출력에 분류기를 연결하는가?

## Ⅲ. 서술형 — 41~50번

> 핵심 개념 사이의 관계가 드러나도록 서술하세요.

**41. LSTM 게이트**  
일반 RNN이 장기 의존성을 학습하기 어려운 이유와 LSTM이 이를 완화하는 구조를 설명하시오. 답변에는 cell state, hidden state, 세 게이트, 덧셈 기반 업데이트를 포함하시오.

> [!success]- 예시 답안 및 채점 요소
>
> 일반 RNN은 과거 정보를 하나의 hidden state에 반복적으로 비선형 변환하여 전달하므로, 긴 시퀀스의 역전파에서 미분값이 계속 곱해져 기울기가 사라지기 쉽다. LSTM은 장기 기억을 전달하는 cell state $C_t$와 현재 표현인 hidden state $h_t$를 분리한다. Forget gate는 이전 기억의 유지 비율을, Input gate는 후보 정보의 반영 비율을, Output gate는 새 cell state 중 현재 출력으로 드러낼 비율을 정한다. 특히 $C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$처럼 이전 상태를 조절해 이어받고 새 정보를 더하는 경로가 있어 장거리 기울기와 정보를 비교적 직접 전달할 수 있다. 다만 기울기 소실을 완전히 없애는 것은 아니다.
>
> **채점 요소**: RNN의 반복 변환 · 두 상태의 분리 · 세 게이트 · additive update · 완전 제거가 아닌 완화

**42. 언어모델**  
언어모델이 문장 전체에 확률을 부여하는 원리를 조건부 확률의 곱으로 설명하시오. 이어서 n-gram 근사가 필요한 이유와 장기 문맥 측면의 한계를 서술하시오.

> [!success]- 예시 답안 및 채점 요소
>
> 언어모델은 $p(w_1,\ldots,w_N)=p(w_1)\prod_{t=2}^N p(w_t\mid w_1,\ldots,w_{t-1})$처럼 이전 문맥 아래 다음 단어의 조건부 확률을 차례로 곱해 문장 확률을 구한다. 그러나 전체 과거 단어 조합을 빈도로 추정하려 하면 가능한 조합이 너무 많아 대부분 충분히 관측되지 않는 데이터 희소성 문제가 생긴다. n-gram은 이를 단순화하기 위해 직전 $n-1$개 단어만 본다고 근사한다. 계산 가능한 통계를 얻는 대신 이 범위를 벗어난 오래된 정보와 장기 의존성을 반영하지 못한다.
>
> **채점 요소**: 조건부 확률 분해 · 데이터 희소성 · $n-1$ 범위 · 장기 문맥 손실

**43. 어텐션**  
기본 Seq2Seq의 병목 문제를 설명하고, Attention이 디코더의 각 시점에서 context vector를 만드는 과정을 서술하시오. Attention 분포와 context vector의 차이도 포함하시오.

> [!success]- 예시 답안 및 채점 요소
>
> 기본 Seq2Seq은 길이에 관계없이 입력 문장 전체를 인코더의 마지막 hidden state 하나에 압축해 디코더에 전달하므로 긴 문장일수록 정보가 손실될 수 있다. Attention은 디코더의 현재 상태와 인코더의 모든 hidden state 사이의 유사도 점수를 구하고, softmax로 각 입력 위치의 참조 비율인 Attention 분포 $\alpha_i^t$를 만든다. 그런 다음 $a_t=\sum_i\alpha_i^t h_i$로 인코더 정보 벡터들을 가중합한다. Attention 분포는 어디를 얼마나 볼지 나타내는 비율이고, context vector는 그 비율을 실제 정보에 적용한 결과이다. 필요한 원문 부분이 출력 단어마다 달라서 이 과정은 매 생성 시점 다시 수행된다.
>
> **채점 요소**: 고정 벡터 병목 · 점수와 softmax · 가중합 · 분포와 정보 벡터의 구분 · 시점별 재계산

**44. 셀프 어텐션**  
Self-Attention의 Q, K, V 생성부터 문맥화된 출력까지의 계산을 설명하고, RNN과 비교했을 때 장거리 의존성과 병렬화 측면의 장점을 서술하시오.

> [!success]- 예시 답안 및 채점 요소
>
> 각 토큰 임베딩 $x_i$에 서로 다른 행렬을 곱해 $q_i=W^Qx_i$, $k_i=W^Kx_i$, $v_i=W^Vx_i$를 만든다. 토큰 $i$의 Query와 모든 토큰 $j$의 Key를 내적해 $e_{ij}=q_i^\top k_j$를 구하고, softmax로 $\alpha_{ij}$를 만든 뒤 $o_i=\sum_j\alpha_{ij}v_j$로 관련 토큰의 정보를 섞은 문맥적 표현을 얻는다. RNN은 멀리 있는 두 토큰이 여러 시점을 순서대로 거쳐야 하지만 Self-Attention에서는 한 층에서 직접 연결되므로 정보 전달 경로가 $O(1)$이다. 또한 각 시점이 이전 시점의 계산 완료를 기다릴 필요가 없어 한 층의 토큰 표현을 병렬로 계산할 수 있다. 다만 모든 토큰 쌍을 비교하므로 일반적 계산량과 메모리는 $O(n^2)$이다.
>
> **채점 요소**: Q·K·V · 내적과 softmax · Value 가중합 · $O(1)$ 경로 · 병렬화 · $O(n^2)$ 계산량 구분

**45. 멀티 헤드 어텐션**  
단일 Attention head보다 Multi-Head Attention이 유리한 이유와 각 head가 다른 관점을 학습할 수 있는 구조적 근거를 설명하시오. head 수를 무한히 늘릴 수 없는 이유도 덧붙이시오.

> [!success]- 예시 답안 및 채점 요소
>
> 단일 head는 하나의 Q·K·V 투영 공간에서 관계를 찾으므로 한 가지 관점에 치우칠 수 있다. Multi-Head Attention은 각 head가 독립적인 $W^Q,W^K,W^V$를 사용하여 문법 관계, 의미 관계, 시제 등 서로 다른 Attention 분포를 동시에 학습한 뒤 결과를 결합한다. 그러나 head를 지나치게 늘리면 비슷한 관계를 반복 학습하는 중복 head가 생길 수 있고 계산량도 증가한다. 전체 표현 차원을 고정한 채 head 수를 늘리면 head당 차원도 작아지므로 각 head의 표현력이 제한될 수 있다. 따라서 데이터와 모델 크기에 맞는 적절한 수가 필요하다.
>
> **채점 요소**: 다양한 관점 · 독립 파라미터 · 결과 결합 · 중복과 계산 비용 · head당 차원

**46. Seq2Seq**  
RNN/LSTM 기반 Seq2Seq이 길이가 다른 입력 시퀀스를 출력 시퀀스로 변환하는 과정을 설명하시오. 인코더와 디코더의 역할, 자기회귀 생성, Teacher Forcing, End-to-End 학습을 포함하시오.

> [!success]- 예시 답안 및 채점 요소
>
> 인코더는 입력 토큰을 순서대로 읽어 hidden state를 만들고 마지막 상태에 입력 문장의 정보를 압축한다. 디코더는 이 표현을 초기 조건으로 받아 `<SOS>`에서 시작해 출력 토큰을 한 개씩 생성하며, 직전에 만든 토큰을 다음 시점 입력으로 사용하는 자기회귀 구조를 가진다. 학습 초기에 오답 토큰이 다음 입력으로 들어가면 오류가 누적되므로 Teacher Forcing은 모델의 예측 대신 정답 토큰을 다음 입력으로 제공해 학습을 안정화한다. 디코더의 손실은 역전파를 통해 인코더까지 전달되므로 두 부분은 하나의 통합 네트워크로 End-to-End 최적화된다. 이 구조는 입력과 출력 길이가 달라도 처리할 수 있다.
>
> **채점 요소**: 인코딩 · 자기회귀 디코딩 · Teacher Forcing · End-to-End · 가변 길이

**47. Seq2Seq와 Transformer**  
전통적인 RNN 기반 Seq2Seq와 Transformer Encoder-Decoder의 공통점과 차이점을 비교하시오. 답변에는 순차 계산, Self-Attention, Masked Self-Attention, Cross-Attention을 포함하시오.

> [!success]- 예시 답안 및 채점 요소
>
> 두 구조 모두 인코더가 입력을 표현으로 바꾸고 디코더가 그 표현을 조건으로 출력 시퀀스를 생성한다는 공통점이 있다. 전통적 Seq2Seq은 RNN/LSTM이 hidden state를 시간 순서대로 전달하므로 병렬화가 어렵고 멀리 있는 정보가 여러 단계를 거친다. Transformer Encoder는 마스크 없는 Self-Attention으로 입력의 앞뒤 문맥을 병렬로 처리한다. Transformer Decoder는 미래 정답을 보지 않도록 Masked Self-Attention으로 지금까지의 출력 문맥을 만들고, Cross-Attention에서 Decoder 상태를 Query, Encoder 출력을 Key·Value로 사용해 입력 정보를 가져온다. 따라서 Transformer는 시간축 순환을 제거하면서도 인코더와 디코더를 Attention으로 연결한다.
>
> **채점 요소**: 인코더-디코더 공통점 · RNN의 순차성 · Encoder Self-Attention · Decoder masking · Cross-Attention 출처

**48. 파인튜닝**  
Pretrain → Fine-tuning 패러다임이 각 태스크별 모델을 처음부터 학습하는 방식보다 효율적인 이유를 설명하시오. 사전학습 데이터, 레이블 데이터, 파라미터 재사용, 다운스트림 태스크를 포함하시오.

> [!success]- 예시 답안 및 채점 요소
>
> 사전학습은 웹 문서처럼 방대한 레이블 없는 텍스트에서 다음 토큰 예측이나 마스킹 복원으로 일반적인 언어 패턴과 표현을 학습한다. 이렇게 얻은 파라미터를 저장해 두면 감성분석, 질의응답, 번역 같은 다운스트림 태스크마다 모델을 무작위 상태에서 다시 학습할 필요가 없다. 파인튜닝은 사전학습 파라미터를 좋은 초기값으로 재사용하고 비교적 적은 레이블 데이터로 특정 태스크에 맞게 추가 갱신한다. 따라서 만들기 비싸고 제한적인 레이블 데이터의 부담을 줄이면서도 대규모 텍스트에서 배운 지식을 활용할 수 있다.
>
> **채점 요소**: 자기지도 사전학습 · 레이블 비용 · 파라미터 재사용 · 태스크별 추가 학습

**49. 어텐션 계열 비교**  
Seq2Seq Attention, Self-Attention, Transformer Cross-Attention을 Query와 Key·Value의 출처 및 역할을 기준으로 비교하시오.

> [!success]- 예시 답안 및 채점 요소
>
> Seq2Seq Attention에서는 디코더의 현재 hidden state가 Query가 되고 인코더의 모든 hidden state가 Key·Value가 되어, 현재 출력에 필요한 원문 정보를 선택한다. Self-Attention에서는 Q, K, V가 모두 같은 시퀀스의 각 토큰에서 만들어져 같은 문장 내부의 토큰 관계를 반영한 문맥적 표현을 만든다. Transformer Cross-Attention은 Seq2Seq Attention과 같은 입력-출력 연결 원리를 사용하되, Decoder 표현에서 Query를 만들고 Encoder 출력에서 Key·Value를 만든 뒤 학습된 투영 행렬, Scaled Dot-Product, Multi-Head 방식으로 구현한다.
>
> **채점 요소**: 세 메커니즘의 Q/K/V 출처 · 같은 시퀀스와 다른 시퀀스 구분 · 입력 정보 선택이라는 공통 원리

**50. Transformer와 파인튜닝**  
Transformer가 대규모 사전학습과 파인튜닝 패러다임의 표준 아키텍처가 된 이유를 설명하시오. 또한 Encoder-only, Encoder-Decoder, Decoder-only 모델을 파인튜닝할 때 각각 잘 맞는 태스크 유형을 비교하시오.

> [!success]- 예시 답안 및 채점 요소
>
> Transformer는 RNN의 시간축 순환을 제거하고 Self-Attention으로 토큰 표현을 병렬 계산할 수 있어 방대한 텍스트를 효율적으로 사전학습하기에 적합하다. 사전학습한 일반 언어 표현을 이후 태스크별 데이터로 파인튜닝할 수 있어 BERT, T5, GPT 계열의 공통 기반이 되었다. Encoder-only 모델은 양방향 문맥을 활용하므로 문장 분류, NER, 질의응답 같은 이해 중심 태스크에 적합하다. Encoder-Decoder 모델은 입력 전체를 이해한 뒤 출력을 자기회귀적으로 생성하므로 번역, 요약 등 시퀀스 변환에 적합하다. Decoder-only 모델은 이전 토큰으로 다음 토큰을 예측하는 구조라 대화와 텍스트 생성에 자연스럽고, 분류에 사용할 때는 마지막 hidden state 위에 분류기를 추가해 파인튜닝할 수 있다.
