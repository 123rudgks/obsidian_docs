
# 01-1 AI&기계학습 기초 : AI와 ML은 무엇인가?
1. **AI, ML, DL의 정의**
   - AI(Artificial Intelligence) 개념
   - ML(Machine Learning) 개념
   - DL(Deep Learning) 개념 및 관계
   - 예시(생성형 AI, 규칙 기반 시스템 등)

2. **데이터와 학습의 이해**
   - 데이터, 모델, 학습의 반복적 개선 루프
   - 데이터 구성 요소(Feature/Label)
   - Feature/Label 예시(유튜브 추천, 스팸 분류 등)
   - 데이터와 정답(라벨) 관계, 중요성

3. **단일 피쳐 기반 학습 (1D Feature)**
   - 1D 피쳐 기반 학습의 의미
   - 데이터-함수 관계(미지의 참 함수, 측정 오차)
   - 여러 후보 함수(가설)
   - 최적의 함수 학습

4. **모델과 가설 공간**
   - 가설 공간(Hypothesis Space) 정의
   - 모델(model)의 개념(가설 공간 내 함수)
   - 모델 선택 과정
   - 선형/비선형 가설 공간 비교

5. **학습(learning)의 정의와 과정**
   - 데이터와 정답에 맞는 모델 규칙 조정
   - 학습의 3가지 필수 요소(데이터, 가설 공간, 선택 기준-손실 함수)
   - 반복적 최적화(예측→오차 측정→파라미터 조정)
   - 데이터→가설 공간→모델 선택 논리

6. **복수 피쳐 기반 학습 (2D 이상 Feature)**
   - 2D 피쳐 기반 예시(학력·경력→수입)
   - 다차원 입력의 일반적 수식화
   - 선형/비선형 가설공간 확장

1. **일반적 용어 정리 및 모델 가정** **( 시험 )**
   - 피쳐(입력), 라벨(목표) 변수 표기(Y, X₁, X₂, ... Xₚ)
   - 입력 벡터와 함수 $f^*(X)$ 구조
   - 측정오차($\epsilon$) 및 그 특성

8. **왜 $f(X)$를 학습하는가?**
   - 예측 목적(새로운 입력에 대한 결과 추론)
   - 중요 특성 파악(어떤 Feature가 결과에 영향)
   - 해석 가능성(각 Feature가 결과에 미치는 영향 이해)

# 01-2 AI&기계학습 기초 : 지도학습 (2개)
## 키워드별 강의 진행 순서 요약

1. **지도학습 개념 소개** **( 시험 )**
   - 지도학습 정의(입력과 정답 쌍, 예측 규칙 학습)
   - 훈련 데이터와 테스트 데이터 구분
   - 실전에서 새로운 데이터 예측 중요성

2. **지도학습의 종류**
   - 회귀(Regression): 출력값이 숫자인 문제
   - 분류(Classification): 출력값이 범주(카테고리)인 문제

3. **지도학습 주요 용어 정리**
   - 특성(Feature), 라벨(Label), 예측값, 오류(Error)

4. **회귀(Regression)**
   - 회귀 문제 정의 및 예시(집값, 매출 등)
   - **평가 지표: 평균제곱오차(MSE), RMSE, 결정계수(R²)** **(시험)**

5. **분류(Classification)**
   - 분류 문제 정의, 이진/다중 분류 예시(스팸/정상, 질병, 학점 등)
   - 결정 경계(Decision Boundary) 개념 소개
   - 평가 지표: 정확도(Accuracy), 혼동행렬(Confusion Matrix), 정밀도(Precision), 재현율(Recall), F1-score

6. **손실 함수(Loss Function)**
   - 회귀: 평균제곱오차(MSE)
   - 분류: 교차 엔트로피(Cross Entropy)
   - 손실 함수의 역할과 목표

7. **분류 문제 평가 및 지표의 한계**
   - 불균형 데이터 문제
   - 정확도의 한계 및 혼동행렬 활용 필요성

8. **학습의 목적과 일반화**
   - 모델 평가: 훈련 데이터 vs. 새 데이터(일반화)
   - 테스트 오류 최소화 목표
   - 측정오차와 예측오차 구분(학습으로 줄일 수 없는 오차 존재)

9. **오버피팅과 언더피팅**
   - 오버피팅: 훈련 데이터 잡음까지 학습, 테스트 성능 저하
   - 언더피팅: 모델이 너무 단순하거나 학습 부족, 주요 패턴을 놓침
   - 오버피팅 vs 언더피팅의 시각적 비교 및 균형 필요성

1. **오버피팅에 대한 오해와 분포 변화** **( 시험 )**
    - 오버피팅과 데이터 분포 변화(Distribution Shift) 구분
    - 분포가 다르면 성능 저하(오버피팅과 별개)

2. **실전 모델 선정 및 일반화 성능 향상 방법 예고**
    - 모델 평가 방법(교차 검증, 추가 학습 등) 차후 심층 학습 안내




# 01-3 AI&기계학습 기초 : 교차검증
## 키워드별 강의 진행 순서 요약 (교차검증, 검증, 평가 파트)

1. **머신러닝의 순환 구조**
   - 데이터, 모델, 학습, 평가의 반복적 개선 루프
   - 학습 결과를 바탕으로 데이터·모델·학습방법 계속 개선  
   
2. **테스트 성능 평가의 필요성**
   - 훈련 오류와 테스트 오류의 개념:  
     훈련 오류는 학습 데이터에서,  
     테스트 오류는 새로운 데이터에서의 평균 예측오류  
   - 훈련 오류 < 테스트 오류 (훈련 오류가 테스트 오류를 과소평가하는 경향)  
   - 목표: 테스트 오류를 최소화하는 모델 선택  

3. **테스트 예측 오류 추정의 현실적인 어려움**
   - 별도 테스트 데이터 확보가 어렵고,  
     데이터가 부족할 때 테스트셋을 따로 떼기 힘듦

4. **재표본화 방식(Resampling) 도입**
   - 데이터를 여러 번 “훈련→평가”로 나눠 테스트 오류 추정
   - 대표적 방법: 검증셋(홀드아웃), K겹 교차검증

5. **검증셋(Validation Set) 접근**
   - 데이터를 무작위로 훈련셋/검증셋으로 나눔  
   - 훈련셋으로 모델 학습, 검증셋에서 성능 평가
   - 예시: 자동차 데이터 실습  

6. **검증셋 접근의 한계**
   - 어떤 표본이 훈련/검증에 속하는지에 따라 추정치가 많이 변동
   - 전체 데이터 일부만으로 학습하므로 테스트 오류를 과대 추정할 수 있음

7. **K-겹 교차검증(K-fold Cross-Validation)**
   - 데이터를 K개 폴드(그룹)로 나눠, 각 폴드를 번갈아 검증셋으로 사용  
   - K회 반복 후, 각 폴드별 오류의 평균으로 테스트 오류 추정
   - 모든 데이터가 검증에 한 번씩 활용됨 → 일반화 성능 추정이 더 정확
   - K=n이면 Leave-One-Out(LOOCV)  
   - K-fold CV 오류 계산 수식 사용

8. **K-겹 교차검증 vs LOOCV**
   - LOOCV: 데이터 하나만 검증셋, 나머지 모두 훈련셋 (연산량 많음)
   - 10-겹 교차검증 등 적합한 K를 선택하면 충분한 성능과 효율성 확보  

9. **K-겹 교차검증 시뮬레이션 및 일반화 예시**
   - 참 MSE와 다양한 교차검증 방식의 추정치 비교  
   - 실제 테스트 성능을 잘 추정한다는 점 확인

10. **오버피팅과 언더피팅 비교**
    - 오버피팅: 모델이 복잡, 훈련 성능↑ 테스트 성능↓
    - 언더피팅: 모델이 단순, 패턴을 놓쳐 오류 큼
    - 균형 잡힌 모델 복잡도 선택의 중요성  


# 01-4 AI&기계학습 기초 : 비지도 학습 (2개)
## 키워드별 강의 진행 순서 요약 (비지도 학습: 클러스터링 중심)
1. **비지도 학습 개념**
   - 레이블(정답) 없는 데이터 구조·패턴·집단 탐색
   - 주요 과제: 군집화(Clustering), 차원축소(PCA 등), 이상치 탐지
   - 지도 학습과의 차이: 라벨 부재, 예측이 아닌 구조 찾기  

2. **비지도 학습 vs 지도 학습**
   - 지도학습: 입력+라벨로 예측 모델, 예시: 가격·이메일 분류
   - 비지도학습: 입력 데이터만으로 군집 등 구조 파악, 예시: 고객 세분화, 비슷한 뉴스 그룹  

1. **클러스터링(Clustering)** **( 시험 )**
   - 데이터 내에서 유사 집단(클러스터) 식별
   - 집단 내 유사성, 집단 간 상이성 강조
   - 마케팅 세그먼테이션 등 실제 응용  

4. **클러스터링 대표 기법**
   - **K-means:** 클러스터 개수(K) 사전 지정, 군집 내 분산(변동) 최소화 목표
   - **계층적 군집(Hierarchical):** K 미리 지정하지 않고, 덴드로그램으로 전체 구조 시각화

5. **K-means 클러스터링 상세**
   - K를 미리 지정, 각 데이터가 정확히 하나의 군집에만 속함(비중첩)
   - 군집 내 변동 최소화
   - 대표 분기: 초기화 → 중심점 계산 → 재할당(수렴할 때까지 반복)
   - 여러 초기화로 반복 필요(지역 최솟값 문제)  
   
6. **K-means 알고리즘 예시**
   - K=2, K=3, K=4 등 다양한 클러스터 수 실험 및 시각화

7. **K-means 및 계층적 군집 비교**
   - K-means: 대규모 데이터에 효율적, K 미리 결정 필요
   - 계층적 군집: 덴드로그램 활용, K 미지정, 대용량 비효율, 상향식 병합 방식

8. **계층적 군집 시각화**
   - 덴드로그램 구조에서 임계치(수평선 높이)로 군집 분할

5. **클러스터링시 주의점** **( 시험 )**
   - 변수 단위 차이(스케일링) 영향 주의
   - 적절한 클러스터 수 선정 어려움: 여러 번 시도 권장

10. **비지도 학습/클러스터링 대표 예시**
    - (라벨이 없는 상태에서) 고객 행동 패턴에 따라 그룹화
    - 데이터 탐색, 시각화, 분포 구조 파악 등 실무 활용 예시

# 02-2. AI&기계학습 방법론 : 로지스틱회귀 (1개)
## 키워드별 강의 진행 순서 요약 (로지스틱 회귀 강의)

1. **분류(Classification) 기본 개념**
   - 분류의 정의 및 목표 (정해진 범주 중 하나 예측)
   - 범주형 변수와 예시 (성별, 혈액형, 이메일 구분 등)

1. **신용카드 연체 예시** (Coefficient, Std.error, z-statistic, p-value) **( 시험 )**
   - 입력 변수(신용카드 사용량, 소득)와 연체 여부(예/아니오) 관계
   - 그룹별 분포(Boxplot) 해석: 사용량과 연체의 상관, 소득과의 약한 관계

3. **분류 문제에서 선형 회귀의 한계**
   - 선형 회귀 사용 시 예측값이 확률(0~1) 범위 벗어남
   - 예측값이 음수나 1초과 가능 → 분류에 부적절

1. **로지스틱 회귀 도입** **( 시험 )**
   - 시그모이드(Sigmoid) 함수 소개: 입력값을 0~1로 변환하는 S자(곡선) 함수

5. **로지스틱 회귀 모형식**
   - 선형 회귀식(z = β₀ + β₁ x)을 시그모이드에 입력
   - 모델 수식:
     y = frac{e^{β₀ + β₁ x}}{1 + e^{β₀ + β₁ x}} = frac{1}{1 + e^{-(β₀ + β₁ x)}}
   - 입력이 여러 개인 경우(X₁, …, X_p)로 확대 가능

6. **로지스틱 회귀 vs 선형 회귀**
   - 로지스틱 함수는 선형 함수 내포
   - 오즈(Odds)와 로짓(Logit) 변환: 확률을 선형함수의 로그-오즈 형태로 해석
     log(p(x;β))/(1-p(x;β)) = β₀ + β₁ x

7. **모수 추정: 최대 우도 추정(MLE)**
   - 확률 모델의 적합도는 우도(likelihood)로 평가
   - 우도함수 최댓값을 찾는 β 추정이 목표
   - log-likelihood 변환으로 계산 용이화:
     log L(β) = Σ_{i=1}^n [y_i log p(x_i;β) + (1-y_i)log(1-p(x_i;β))]
   - 수치적 최적화 알고리즘(반복 계산) 통해 파라미터 추정

8. **신용카드 연체 데이터 실전 적용 및 해석**
   - 회귀계수의 의미: 예시로 balance(사용량)이 1 증가할 때 연체의 log-odds가 얼마만큼 증가
   - 실제 확률 변화 해석(0.0055가 확률 증가량이 아닌 log-odds 증가)
   - 입력 변수 확장: 소득, 학생 여부 등 추가 가능한 다변량 적용

9. **로지스틱 회귀의 확률 예측 범위**

# 03-1. 자연어 처리 기본 : 워드 임베딩과 순환신경망 기반 모델 (1개)
## 키워드별 강의 진행 순서 요약: 워드 임베딩과 RNN/LSTM

1. **워드 임베딩의 필요성**
   - 자연어 데이터를 숫자로 표현  
   - 원-핫 인코딩의 한계(차원의 저주, 의미 정보 없음)  
   - 워드 임베딩: 단어를 실수값 벡터로 저차원 밀집 표현, 의미 정보 반영

2. **워드 임베딩 모델**
   - Word2Vec 기본 구조  
   - Skip-gram: 중심 단어 → 주변 단어 예측  
   - CBOW: 주변 단어 → 중심 단어 예측  
   - Skip-gram과 CBOW의 장단점, 예측 방식 차이

3. **순차적 데이터(Sequential Data)의 개념**
   - 텍스트, 오디오, 비디오 등에서 순서 중요  
   - 순차적 데이터 특징:  
     - 순서(문맥) 중요  
     - 장기 의존성(Long-term dependency)  
     - 가변 길이 처리 필요

4. **순차적 데이터용 신경망의 필요성**
   - 기존 신경망(MLP, CNN)의 한계: 고정 길이 입력, 순서 정보 미반영  
   - 순차적 데이터 처리를 위한 RNN, LSTM, Transformer 도입 필요성

5. **RNN (Recurrent Neural Network)**
   - 가변 길이 입력 처리, 순서/문맥 정보 기억  
   - 각 시점에서 이전 hidden state 활용  
   - 다양한 입력-출력 구조(One-to-One, Many-to-One, One-to-Many, Many-to-Many)  
   - 주요 구조: h_t = tanh(W_{hh}h_{t-1} + W_{xh}x_t)

6. **RNN의 장점 및 한계**
   - 장점: 시퀀스 데이터(텍스트, 음성, 시계열 등) 적합, 가변 길이와 순서 정보 반영  
   - 한계:  
     - 기울기 소실(Vanishing Gradient) 문제  
     - 장기 의존성(long-term dependency) 학습 어려움

1. **LSTM (Long Short-Term Memory)** **( 시험 )**
   - RNN의 기울기 소실 문제 해결  
   - cell state(장기 기억), hidden state(단기 기억) 구조  
   - 3가지 게이트(Forget, Input, Output)로 정보 흐름 동적 제어  
   - 각 게이트의 수식  
     - Forget: f_t = σ(W_f[h_{t-1}, x_t] + b_f)  
     - Input: i_t = σ(W_i[h_{t-1}, x_t] + b_i), C̃_t = tanh(W_C[h_{t-1}, x_t] + b_C)  
     - Output: o_t = σ(W_o[h_{t-1}, x_t] + b_o), h_t = o_t * tanh(C_t)  
     - cell state update: C_t = f_t * C_{t-1} + i_t * C̃_t

8. **LSTM의 동작 원리와 정보 선별**
   - 각 게이트가 정보를 읽고, 지우고, 기록하는 방식  
   - 동적 게이트 값으로 불필요한 정보 필터링, 장기/단기 정보 조합 가능

## 키워드별 강의 진행 순서 요약

1. **언어 모델(Language Model)의 개념과 역할** **( 시험 )**
   - 언어 모델의 정의

   - 고정된 차원의 벡터로 입력 시퀀스 인코딩, 출력 시퀀스 생성
   - 입력과 출력 길이가 다른 문제 처리

   - 정보 손실 위험, 긴 문장/복잡한 정보에 대한 성능 저하

6. **Attention 메커니즘**
   - 디코더가 인코더의 각 hidden state를 동적으로 참조
   - 타임스텝마다 중요한 입력 단어/구절에 집중하여 가중치 계산
   - Bottleneck 문제 완화, 긴 시퀀스에서 정보 손실 해결
   - 번역 등 다양한 자연어 생성 태스크에서 핵심적 역할


# 03-3. 자연어 처리 기본 : Transfomer (3개)
## 키워드별 강의 진행 순서 요약 (Transformer/Self-Attention)

1. **RNN의 정보 전달 방식**
   - 순차적(hidden state) 정보 전달  
   - 시퀀스(문장, 단어)의 순서 의존성  
   - 예시: "정보 희석" 문제, LSTM 사용해도 멀리 떨어진 단어 관계 파악 어렵다

2. **RNN의 한계**
   - **장기 의존성 문제**  
     - 시퀀스가 길어질수록 정보를 여러 단계 거쳐 전달  
     - 기울기 소실/폭발 문제  
     - 현실 언어의 비선형적 의존성 파악이 어려움  
     - 예시: 오래 방치된 책 예시, "chef who ... was"처럼 멀리 떨어진 단어 상호작용 어려움  
     - 상호작용 거리: O(sequence length)

   - **병렬화의 어려움**  
     - 연산이 순차적으로 이루어져 병렬처리 불가  
     - GPU병렬 처리 이점 활용 어려움 → 대규모 학습 비효율  
     - Forward/Backward 모두 시퀀스 길이만큼 단계 필요

1. **Attention의 도입** **( 시험 )**
   - 필요한 순간 입력 전체를 한 번에 참고 및 결합  
   - 기존 RNN의 순차적 정보전달을 대체  
   - Encoder-Decoder Attention에서 시작, 더 확장 가능

1. **Self-Attention의 등장** **( 시험 )**
   - Attention을 문장 내부(입력 내)에서 직접 사용  
   - 한 문장 안의 모든 단어가 서로를 한 번에 참조  
   - 단어 간 정보 전파가 한 층에서 O(1), 각 단계별 직접 상호작용 가능

5. **Self-Attention의 장점**
   - **연산 효율성:**  
     - 연산 단계 수가 시퀀스 길이에 따라 증가하지 않음  
     - 모든 단어가 동시에 상호작용 → 순차성 제거  
   - **병렬 처리 가능:**  
     - 모든 타임스텝(단어) 히든 벡터를 동시에 처리  
     - 병렬화 통해 대규모 데이터 학습에 적합  
   - **장기 의존성 처리:**  
     - 정보 희석 없이 멀리 떨어진 단어 간 즉각적인 상호작용 가능

1. **Transformer 구조로 확장** **(시험)**
   - Multi-Head Attention, Feed-Forward, Encoder/Decoder block 등 추가  
   - 다양한 자연어 처리(NLP) 및 대형 언어 모델 기반 구조로 활용


# 03-4. 자연어 처리 기본 : 사전 학습 기반 언어 모델 (2개)
## 키워드별 강의 진행 순서 요약  
1. **사전학습(Pretraining) 개념과 필요성**
   - 대규모 데이터 기반 학습, 일반적인 언어 패턴 및 문맥 이해  
   - 파라미터 초기화, 파인튜닝 단계와의 연계  
1. **대표 모델 유형 소개** **( 시험 )**
   - Encoder(인코더): BERT, 양방향 문맥 이해, Masked LM, NSP  
   - Encoder-Decoder: T5, 입력→출력 변환(Text-to-Text), Span Corruption  
   - Decoder(디코더): GPT, 단방향 구조, 텍스트 생성, Autoregressive LM  
3. **Encoder 모델(BERT 등) 구조와 학습 방법**
   - Masked Language Model(MLM)  
   - Next Sentence Prediction(NSP)
   - 다양한 다운스트림 태스크 적용(Sentence/Token Level NLU)  
   - 분류·질문응답·개체명 인식 등  
   - 성능 향상: 레이어, hidden size, head 수 확대  
4. **Encoder-Decoder 모델(T5 등) 구조와 학습 방법**
   - Span Corruption: 입력 span을 마스킹, placeholder로 치환, 디코더 복원  
   - 모든 태스크를 Text-to-Text로 변환  
   - 다양한 응용 분야: 번역, 요약, 질의응답 등  
   - 범용적, 다목적 학습  
5. **Decoder 모델(GPT 등) 구조와 학습 방법**
   - Autoregressive Next Token Prediction  
   - 생성(Text Generation) 태스크에 강점  
   - 파인튜닝: 시퀀스 생성, 분류 태스크 모두 활용 가능   **( 시험 )**
   - Prompt에 따라 다양한 태스크 적용  
6. **In-Context Learning(ICL)과 Prompting**
   - 파인튜닝 없이 자연어 프롬프트·예시만으로 태스크 수행  
   - Zero-shot, One-shot, Few-shot 방식  
   - Shot 수 및 파라미터 규모가 클수록 성능 향상  
7. **Chain-of-Thought(CoT) Prompting**
   - 논리적 사고 단계 유도, 복잡한 문제 해결 능력 강화  
   - Standard Prompting과 비교해 추론력·정답률 대폭 향상  
   - Fine-tuning 모델보다 더 우수한 성과 측정  
8. **Zero-Shot Chain-of-Thought Prompting**
   - 예시 없이 “Let's think step by step” 한 줄로 추론 프로세스 유도  
   - 기존 Zero-shot/Few-shot 대비 큰 성능 개선  
   - 다양한 실제 벤치마크에서 성능 수치 비교

   - 다양한 디코딩 전략의 필요성

   - 가장 확률 높은 토큰을 차례로 선택

   - 여러 후보 시퀀스(beam) 동시 탐색
   - 누적 확률 기준, 결과 다양성·품질 증진
   - 계산량 증가

1. **Sampling 계열 디코딩** **(시험)**
   - Sampling(무작위성): 다양성/품질 트레이드오프
   - Temperature 조절: 창의성 ↔ 신뢰성 조정
   - Top-K Sampling: 확률 상위 K개 후보에서 무작위 선택
   - Top-P(Nucleus) Sampling: 누적 확률이 P를 넘는 후보 집합에서 무작위 추출

6. **디코딩 알고리즘 비교 및 실제 적용 사례**
   - 각 알고리즘의 장단점/특징 요약
   - 실제 서비스(예: ChatGPT, GPT-4)의 대표 설정 메뉴(Temperature, Top-P 등)와 연계

7. **프롬프트 엔지니어링 도입**

   - 프롬프트 설계가 모델 성능에 미치는 영향
   - 시스템 프롬프트/유저 쿼리 구분 및 역할

8. **Chain-of-Thought(CoT) 프롬프팅**
   - 표준 프롬프트 vs. CoT 프롬프트(단계적 추론 과정 추가)
   - 모델 크기·창발성과 CoT 성능 관계
   - Few-shot, Zero-shot-CoT 비교 및 효과

9. **프롬프트 예시 구성 및 선택 전략**
   - 좋은 예시 선정 중요성(성능 변화)
   - 거리 기반(KNN 등) in-context example selection 알고리즘
   - 유사성 높은 예시 선택 → 정확도 개선

10. **프롬프트 엔지니어링의 실전 적용**
    - 시스템 프롬프트를 통한 모델 제약/페르소나/개인화
    - 작업 자동화를 위한 Skill.md 및 프롬프트 템플릿 활용
    - 실서비스에서의 프롬프트 최적화 사례

   - 입력 모달리티별 인코더(예: Vision Encoder→Projection→토큰 표현)와 텍스트 토크나이저를 통합, 다양한 형태의 정보를 LLM이 이해할 수 있도록 변환
   - 서로 다른 모달리티(이미지/텍스트/음성 등) 데이터를 토큰화하고 추가 학습을 거쳐, 복합 응답 생성

2. **멀티모달 LLM 적용 예시와 구조**
   - 예시 1: LLaVA  
     - 이미지와 텍스트를 동시에 입력받아, 장면의 특이점 등 응답 생성
     - Vision Encoder 및 프로젝션 과정을 통해 이미지를 언어 모델의 입력 공간에 맞는 토큰으로 변환
   - 예시 2: VideoPoet  
     - 텍스트, 이미지, 비디오, 오디오 등 다양한 입력을 받아 대응되는 멀티모달 출력 생성
     - 각 입력은 전용 인코더(예: MAGVIT-v2, Sound Stream 등)에서 전처리되고, 언어 모델을 통해 새로운 멀티모달 결과(동영상, 오디오 등) 도출
   - 예시 3: HELIX (로보틱스)  
     - 비디오 등 비정형 입력을 통해 행동 의미 해석, 로봇 제어 신호로 변환하여 실제 행동으로 연결  
     - Vision-Language Model과 제어 구조 통합

3. **거대 언어 모델 기반 합성 데이터 생성**
   - Self-Instruct: 사람이 소량 작성한 데이터를 기초로, LLM을 이용해 대량(수만 개)의 합성 데이터를 자동 생성  
   - 4단계(시드 셋→지시문 생성→분류(과제 식별)→예시/정답 데이터 생성→결과 필터링) 과정을 거치며, 고품질 합성 데이터를 대규모로 구축  
   - 덕분에 소량의 사람이 만든 연산 기반 데이터도 모델을 효과적으로 학습시킬 수 있음
