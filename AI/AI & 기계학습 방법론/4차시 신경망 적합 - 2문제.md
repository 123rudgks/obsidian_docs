# 0. 강의 전체 개요

앞 차시에서는 Neural Network가 어떤 Function을 표현하는지를 배웠다.

```text
Input
 ↓
Linear Mapping
 ↓
Activation
 ↓
Hidden Representation
 ↓
...
 ↓
Output
```

그리고 Network 안의

- Weight
    
- Bias
    

가 모두 학습해야 하는 Parameter라고 배웠다.

이번 강의의 질문은 다음이다.

> **그 수많은 Parameter를 실제로 어떻게 좋은 값으로 찾아가는가?**

전체 흐름은 다음과 같다.

```text
Loss Function
      ↓
Loss를 최소화하는
Parameter를 찾고 싶다
      ↓
Gradient
      ↓
Gradient의 반대 방향
      ↓
Gradient Descent
      ↓
Learning Rate
      ↓
여러 Parameter
      ↓
Partial Derivative / Gradient Vector
      ↓
Convex vs Non-convex
      ↓
Neural Network는
Non-convex Optimization
      ↓
Full Gradient Descent의 한계
      ↓
SGD / Mini-batch
      ↓
신경망의 모든 Parameter Gradient는?
      ↓
Chain Rule
      ↓
Backpropagation
      ↓
각 Layer의 Weight/Bias Update
      ↓
깊어질수록
Vanishing / Exploding Gradient 문제
```

---

# 1. Loss Function의 역할

Loss Function은

> **현재 Model이 Data를 얼마나 잘 예측하고 있는지를 숫자로 나타내는 함수**

다.

Loss는 다음 요소들에 의해 결정된다.

- Data
    
- Model 구조
    
- Parameter
    

강의에서는 Data와 Model 구조가 현재 고정되어 있다고 생각하고, Loss를 **Parameter에 대한 함수**로 바라본다.

즉

`L(θ)`

와 같은 관점이다.

여기서 `θ`는 Model의 모든 Parameter를 의미한다.

---

# 2. 우리가 해결하려는 문제

목적은 단순하다.

> **Loss를 가장 작게 만드는 Parameter를 찾는다.**

수학적으로는

`θ* = argminθ L(θ)`

의 형태로 생각할 수 있다.

즉

```text
여러 Parameter 후보
      ↓
각 Parameter마다 Loss 계산
      ↓
가장 작은 Loss를 만드는
Parameter 선택
```

이다.

---

# 3. 사실 지금까지 계속 같은 문제를 풀었다

강의에서는 이 Optimization 문제가 새로운 것이 아니라고 강조한다.

## Linear Regression

```text
RSS 최소화
→ 기울기와 절편 찾기
```

## Logistic Regression

```text
Log-Likelihood 최대화
```

또는 부호를 바꾸면

```text
Negative Log-Likelihood 최소화
```

로 표현할 수 있다.

즉 Machine Learning에서 계속 반복되는 핵심 구조는

```text
Objective Function
      ↓
가장 좋은 Parameter 찾기
```

이다.

---

# 4. Linear Regression으로 다시 시작

Gradient Descent를 이해하기 위해 이미 익숙한 Linear Regression으로 돌아간다.

Model:

`ŷ = wx + b`

Loss:

`RSS = Σ(yᵢ - ŷᵢ)²`

또는 평균을 사용하면 MSE다.

우리가 원하는 것은

```text
w
b
```

를 적절히 정해 Loss를 최소화하는 것이다.

---

# 5. Loss를 Parameter 공간에서 바라보기

Parameter가

- Slope `w`
    
- Intercept `b`
    

두 개라면 Loss는

`L(w,b)`

라는 두 Parameter의 함수다.

이를 3D Surface로 생각하면 그릇처럼 생긴 형태를 가질 수 있다.

```text
          Loss
            ↑
         \     /
          \   /
           \_/
            ↑
        Minimum
```

각 위치 하나가 특정

```text
(w,b)
```

조합을 의미한다.

---

# 6. Parameter 공간과 Data 공간

두 그림을 구분해서 이해할 수 있다.

## Data Space

```text
x-y Data
+
Regression Line
```

을 본다.

## Parameter / Loss Space

```text
w,b
→ 해당 Parameter에서의 Loss
```

를 본다.

같은 학습 과정을 서로 다른 관점에서 보는 것이다.

---

# 7. 처음 Parameter는 좋지 않을 수 있다

처음 `w`, `b`를 어떤 값으로 초기화했다고 하자.

그러면 Data Space에서는 Data를 잘 Fit하지 못하는 직선이 만들어질 수 있다.

Loss Space에서는 높은 위치에 존재한다.

```text
Initial Parameter
      ↓
좋지 않은 Prediction
      ↓
Large Loss
```

---

# 8. 목표는 Loss Surface의 아래쪽으로 내려가는 것

현재 위치에서 Loss가 더 작아지는 쪽으로 조금씩 Parameter를 수정한다.

```text
현재 Parameter
      ↓
Loss 감소 방향 탐색
      ↓
조금 이동
      ↓
새로운 Parameter
      ↓
다시 Loss 감소 방향 탐색
```

이를 반복해서 Minimum에 가까워진다.

이것이 **Gradient Descent**의 기본 직관이다.

---

# 9. Gradient Descent

Gradient Descent는

> **현재 위치에서 Loss가 가장 빠르게 감소하는 방향으로 Parameter를 조금씩 이동시키는 Optimization 방법**

이다.

이를 이해하려면 먼저 미분의 의미를 잡아야 한다.

---

# 10. 미분은 현재 위치의 기울기다

어떤 1차원 함수가 있다고 하자.

`f(x)`

그 함수의 Derivative

`f'(x)`

는 현재 `x` 위치에서의 **Slope**를 알려준다.

즉

```text
Derivative > 0
→ 오른쪽으로 갈수록 함수가 증가

Derivative < 0
→ 오른쪽으로 갈수록 함수가 감소

Derivative = 0
→ 평평한 지점
```

이다.

---

# 11. 최소값에서는 기울기가 0

단순한 2차 함수의 Minimum에서는

`f'(x)=0`

이 된다.

앞선 Linear Regression 강의에서 Closed-form Solution을 구할 때도

```text
Loss 미분
      ↓
0으로 설정
      ↓
최솟값 Parameter 계산
```

이라는 원리를 사용했다.

---

# 12. 그런데 Gradient Descent는 Minimum을 처음부터 모른다고 생각한다

이번에는 미분값을 0으로 놓고 한 번에 Solution을 풀지 않는다.

대신 어떤 Initial Point에서 시작한다.

```text
Start
 ↓
현재 Gradient 계산
 ↓
어느 방향으로 내려갈지 결정
 ↓
조금 이동
```

을 반복한다.

---

# 13. Gradient가 Positive라면?

예를 들어 현재 `x=3`에서

`f'(3)=2`

라고 하자.

Derivative가 Positive라는 것은 오른쪽으로 가면 함수값이 증가하는 방향이라는 뜻이다.

Minimum으로 내려가려면 반대로 움직여야 한다.

```text
Gradient 방향
→ 올라가는 방향

Gradient 반대 방향
→ 내려가는 방향
```

따라서 **Gradient의 반대 방향**으로 이동한다.

---

# 14. Gradient가 Negative라면?

현재 Gradient가

`-2`

라면 Gradient 방향은 왼쪽이다.

그러므로 Gradient의 반대 방향은 오른쪽이다.

결국 Gradient의 부호가 무엇이든

> **항상 Gradient의 반대 방향으로 이동한다.**

가 핵심이다.

---

# 15. Gradient 크기도 중요하다

Derivative의 절댓값은 현재 Surface가 얼마나 가파른지를 알려준다.

```text
|Gradient| 큼
→ Surface가 가파름

|Gradient| 작음
→ Surface가 완만함
```

따라서 같은 Learning Rate라면 Gradient가 클수록 Parameter Update도 커진다.

---

# 16. Gradient Descent Update Rule

기본적인 Update는

`θ_new = θ_old - α ∇L(θ_old)`

이다.

여기서

- `θ` = Parameter
    
- `∇L` = Gradient
    
- `α` = Learning Rate
    

다.

---

# 17. 왜 Minus가 붙는가?

Gradient는

> **Loss가 가장 빠르게 증가하는 방향**

을 가리킨다.

우리는 Loss를 감소시키고 싶다.

따라서

`-∇L`

방향으로 간다.

즉 Minus는

> **Gradient의 반대 방향으로 내려간다.**

는 뜻이다.

---

# 18. Learning Rate

`α`는 **Learning Rate**다.

강의에서는 이를 Step Size라고도 설명한다.

Gradient가 방향과 상대적인 크기를 알려준다면 Learning Rate는 실제로 한 번에 얼마나 움직일지를 조절한다.

```text
Update
=
Learning Rate
×
Gradient
```

이다.

Learning Rate는 Positive 값이다.

---

# 19. Learning Rate가 크면

```text
α 큼
→ 한 번에 크게 이동
```

한다.

빠르게 이동할 수 있지만 너무 크면 적절한 Minimum 주변을 지나칠 수도 있다.

이번 강의에서는 Learning Rate가 Gradient Update 크기를 Scaling하는 값이라는 기본 원리를 중심으로 설명한다.

---

# 20. Learning Rate가 작으면

```text
α 작음
→ 한 번에 조금 이동
```

한다.

좀 더 조심스럽게 이동하지만 많은 Step이 필요할 수 있다.

---

# 21. Parameter가 여러 개라면?

Neural Network에서는 Parameter가 하나가 아니다.

```text
w₁
w₂
w₃
...
b₁
b₂
...
```

매우 많다.

따라서 각 Parameter에 대해

> **Loss가 이 Parameter 변화에 얼마나 민감하게 변하는가?**

를 계산해야 한다.

---

# 22. Partial Derivative

Parameter가 여러 개일 때 각각 하나씩 미분하는 것을 **Partial Derivative(편미분)** 로 이해할 수 있다.

예를 들어

`L(w,b)`

라면

`∂L/∂w`

와

`∂L/∂b`

를 각각 계산한다.

강의에서는 편미분을 어렵게 생각하지 말고

> **여러 Parameter가 있으므로 각각에 대해 하나씩 미분한 것**

으로 설명한다.

---

# 23. Gradient Vector

각 Partial Derivative를 한꺼번에 묶으면 Gradient가 된다.

개념적으로

`∇L = [∂L/∂θ₁, ∂L/∂θ₂, ..., ∂L/∂θₚ]`

이다.

즉 Gradient는

> **모든 Parameter 방향에서 Loss가 얼마나 변하는지를 담은 Vector**

다.

---

# 24. Linear Regression에서의 Gradient

Linear Regression의 Parameter가

```text
Slope
Intercept
```

두 개라면 각각에 대해 Loss를 미분한다.

```text
∂L/∂Slope
∂L/∂Intercept
```

두 값을 합쳐 현재 Loss Surface에서의 Gradient 방향을 얻는다.

---

# 25. 두 Gradient를 동시에 적용한다

Slope 방향으로도 움직이고 Intercept 방향으로도 움직인다.

따라서 실제 Parameter Space에서는 두 방향을 합친 한 Vector 방향으로 이동한다.

```text
Slope Update
+
Intercept Update
      ↓
새로운 (Slope, Intercept)
```

이다.

---

# 26. 한 번 Update했다고 끝나는 것이 아니다

Gradient Descent는 **Iterative Algorithm**이다.

```text
Initialization
      ↓
Gradient 계산
      ↓
Parameter Update
      ↓
새 위치
      ↓
다시 Gradient 계산
      ↓
Parameter Update
      ↓
...
```

을 반복한다.

---

# 27. 매 Step마다 Regression Line이 달라진다

Parameter가 바뀌기 때문에 Data Space에서의 Regression Line도 계속 바뀐다.

```text
Iteration 0
→ 좋지 않은 Line

Iteration 1
→ 조금 개선

Iteration 2
→ 더 개선

...

최종
→ 낮은 Loss의 Line
```

이다.

---

# 28. 실제 학습은 그림을 보고 움직이는 것이 아니다

강의에서 중요한 설명이다.

실제로 Algorithm이

```text
Loss Surface 그림
Data에 그어진 직선
```

을 눈으로 보고 움직이는 것은 아니다.

컴퓨터가 사용하는 것은 Numerical Value다.

```text
현재 Parameter
현재 Loss
Gradient
```

를 계산하여 Update한다.

그림은 우리가 이해하기 위한 시각화다.

---

# 29. Gradient는 가장 가파른 증가 방향

다차원 Loss Surface에서도 Gradient는 현재 위치에서 가장 가파르게 올라가는 방향을 나타낸다.

따라서 Negative Gradient는

> **현재 위치에서 가장 가파르게 내려가는 방향**

이다.

이 때문에 이름이 Gradient **Descent**다.

---

# 30. Loss Function 모양이 중요하다

지금까지 사용한 2차 함수는 Optimization하기 매우 쉬운 형태였다.

하지만 모든 Loss Function이 이렇게 단순한 것은 아니다.

Function의 Shape에 따라 Gradient Descent가

- 쉽게 최적점을 찾을 수도 있고
    
- 매우 어려워질 수도 있다.
    

이를 이해하기 위해 **Convex Function**을 배운다.

---

# 31. Convex Function

강의에서는 Convex Function을

> 함수 위 임의의 두 점을 연결했을 때 그 선분이 함수 아래로 내려가지 않는 형태

로 설명한다.

직관적으로 아래로 볼록한 그릇 형태를 생각하면 된다.

```text
Loss
 ↑
 │ \       /
 │  \     /
 │   \___/
 └────────→ θ
```

---

# 32. Convex Optimization이 쉬운 이유

Convex Function에서는 Local Minimum에 도달하면 그것이 Global Minimum이 된다.

즉

```text
Local Minimum
=
Global Minimum
```

이라는 좋은 성질을 가진다.

따라서 Gradient를 따라 내려가다가 Minimum에 도착했을 때

> 다른 곳에 더 낮은 골짜기가 있을까?

라는 걱정을 상대적으로 하지 않아도 된다.

---

# 33. 2차 함수는 대표적인 Convex 예

앞에서 본 Linear Regression의 Quadratic Loss Surface는 대표적으로 Optimization이 쉬운 형태다.

```text
하나의 그릇
      ↓
계속 내려감
      ↓
Minimum
```

이라는 직관이 가능하다.

---

# 34. Non-convex Function

반대로 Convex 조건을 만족하지 않는 함수를 **Non-convex Function**이라고 한다.

이런 Function에는 여러 개의

- 골짜기
    
- 봉우리
    
- 평평한 지점
    

등이 존재할 수 있다.

```text
Loss
 ↑
 │\__      __
 │   \____/  \___
 │
 └──────────────→ θ
```

---

# 35. Local Minimum

주변에서는 가장 낮지만 전체 Function에서 가장 낮지는 않은 지점을 **Local Minimum**이라고 한다.

```text
주변에서는 최소
하지만
Global Minimum은 아님
```

이다.

Gradient Descent가 이런 곳에 도달하면 더 이상 내려갈 Gradient가 없어 멈출 수 있다.

---

# 36. Global Minimum

전체 Parameter Space를 통틀어서 가장 낮은 Loss를 가지는 지점이 **Global Minimum**이다.

```text
Local Minimum
→ 주변에서만 가장 낮음

Global Minimum
→ 전체에서 가장 낮음
```

이다.

---

# 37. Saddle Point

강의에서는 **Saddle Point**도 설명한다.

Gradient가 0이지만 반드시 Minimum은 아닌 지점이다.

즉

```text
Gradient = 0
```

만 보고

```text
Global Minimum
```

이라고 결론내릴 수 없는 Non-convex 상황이 존재한다.

---

# 38. Neural Network Optimization은 Non-convex

강의의 중요한 결론이다.

Neural Network에 Hidden Layer가 들어가면 Optimization 문제는 일반적으로 **Non-convex**하다.

따라서

```text
Gradient Descent 실행
      ↓
어떤 Minimum으로 수렴
```

하더라도 그것이 반드시 Global Minimum이라는 보장은 없다.

---

# 39. Initialization의 영향

Non-convex Loss Surface에서는 시작 위치가 달라지면 다른 경로를 따라갈 수 있다.

```text
Initial Point A
→ Minimum A

Initial Point B
→ Minimum B

Initial Point C
→ Minimum C
```

이처럼 Initial Parameter가 학습 결과에 영향을 줄 수 있다.

---

# 40. Full Gradient Descent의 또 다른 문제

일반적인 Gradient Descent에서는 한 번 Gradient를 계산할 때 **전체 Training Data**를 사용한다.

Dataset이

`N`

개라면 한 Step마다 모든 `N`개의 Data를 이용해 Loss와 Gradient를 계산한다.

---

# 41. Data가 매우 크다면?

Data가 수백만, 수십억 개라면 매 Step마다 전체 Dataset을 사용하는 것은 계산 비용이 매우 크다.

강의에서는 Large-scale Neural Network나 Language Model처럼 Dataset이 거대한 경우 전체 Dataset을 매 Step마다 사용하는 것이 현실적으로 매우 어렵다고 설명한다.

---

# 42. 해결 아이디어

그렇다면 매 Step마다 전체 Dataset을 사용하지 않고

> **일부 Data만 뽑아서 Gradient를 추정하면 되지 않을까?**

라는 아이디어가 나온다.

이것이 **Stochastic Gradient Descent**와 Mini-batch 학습으로 이어진다.

---

# 43. Stochastic Gradient Descent

**Stochastic Gradient Descent(SGD)** 는 전체 Data가 아닌 Random하게 Sampling한 Data를 이용해 Gradient를 계산한다.

강의에서는 특히 실전에서 많이 사용하는 **Mini-batch 형태**를 함께 설명한다.

```text
전체 Training Data
      ↓
Random Sampling
      ↓
Mini-batch
      ↓
Gradient 계산
      ↓
Parameter Update
```

---

# 44. Mini-batch

Mini-batch는 전체 Dataset의 작은 부분집합이다.

예를 들어

```text
Training Data = 1,000,000개
Batch Size = 50
```

이라면 한 Step에서 100만 개가 아니라 50개 Data에 대해서만 Gradient를 계산한다.

---

# 45. Mini-batch의 계산상 장점

Full Gradient:

```text
1 Step
→ 전체 1,000,000개 Data 계산
```

Mini-batch:

```text
1 Step
→ 50개 Data 계산
```

이므로 한 Step의 계산 비용이 크게 감소한다.

---

# 46. Gradient Descent와 SGD의 경로 차이

Full Gradient Descent는 모든 Data를 사용하기 때문에 현재 전체 Loss Surface 기준의 Gradient를 비교적 정확하게 계산한다.

따라서 경로가 상대적으로 매끄럽다.

```text
Gradient Descent
→ 비교적 Smooth Path
```

---

# 47. SGD는 왜 지그재그로 움직이는가?

Mini-batch는 전체 Dataset의 일부만 본다.

Batch가 바뀔 때마다 Gradient Estimate가 조금씩 달라진다.

따라서

```text
SGD
→ Noisy Gradient
→ Zigzag Path
```

를 보일 수 있다.

---

# 48. Stochastic의 의미

`Stochastic`은 확률적이라는 의미다.

이 Randomness는

```text
어떤 Data를 Mini-batch로 Sampling했는가?
```

에서 발생한다.

다른 Batch를 뽑으면 다른 Gradient Estimate를 얻을 수 있다.

---

# 49. Noise가 꼭 단점만은 아니다

SGD의 Noisy Step은 최적 경로를 정확하게 따라가지 못한다는 단점이 있다.

하지만 Non-convex Optimization에서는 이 Randomness가 도움이 될 수도 있다.

강의에서는 Noise 때문에

```text
Local Minimum
Saddle Point
```

주변에서 빠져나올 가능성이 생길 수 있다고 설명한다.

---

# 50. 그렇다고 SGD가 Global Minimum을 보장하는 것은 아니다

중요하다.

```text
SGD 사용
→ 무조건 Global Minimum
```

은 아니다.

강의 역시 Global Minimum으로 반드시 수렴하는 것은 아니라고 설명한다.

다만 Full Gradient보다 Randomness가 존재하여 일부 좋지 않은 지점에서 벗어날 가능성이 있을 수 있다는 것이다.

---

# 51. Large-scale Neural Network에서는 SGD 계열이 일반적

강의에서는 대규모 Neural Network Training에서 Full Gradient Descent보다 **Stochastic / Mini-batch Gradient 방식**을 대부분 사용한다고 설명한다.

그 가장 현실적인 이유는 계산량이다.

```text
Data 너무 큼
      ↓
전체 Data Gradient 비현실적
      ↓
Mini-batch 사용
```

이다.

---

# 52. Training 중 Checkpoint

강의 중 큰 Model을 여러 번 처음부터 학습하기 어려운 상황도 이야기한다.

따라서 Training 중 특정 시점의 Model 상태를 저장해두고

```text
좋은 지점 저장
      ↓
이후 학습이 좋지 않을 경우
      ↓
저장된 지점으로 복귀
```

하는 방식도 사용할 수 있다고 설명한다.

즉 Training 과정 자체를 관리하는 것도 중요하다.

---

# 53. SGD의 특성 정리

### 장점

- 매 Step 계산량 감소
    
- 대규모 Dataset 처리 가능
    
- Randomness가 Non-convex Optimization에서 도움이 될 수 있음
    

### 단점

- Gradient가 Noise를 포함
    
- 경로가 Zigzag
    
- Full Gradient처럼 매끄럽게 수렴하지 않음
    
- Global Minimum 보장 없음
    

---

# 54. 평균적으로는 좋은 방향을 추정한다

강의에서는 Mini-batch Gradient가 하나하나는 Noisy하지만 충분히 반복하면 평균적으로 전체 Loss가 감소하는 방향을 추정할 수 있다고 설명한다.

적절한

- Step
    
- Learning Rate
    

를 사용하면 좋은 Solution 부근으로 수렴할 수 있다는 흐름이다.

---

# 55. Convex 문제에서는 Noise가 무조건 좋은 것은 아니다

또 하나의 중요한 구분이다.

Convex Problem에서 Full Gradient 계산이 충분히 가능하다면 굳이 Noisy한 Step이 Optimization을 항상 더 빠르게 만드는 것은 아니다.

즉

> **SGD가 모든 Optimization 문제에서 무조건 Full Gradient보다 우월하다.**

는 것은 아니다.

강의에서는 Neural Network가 주로 Non-convex이고 Dataset도 크기 때문에 SGD의 장점이 특히 중요해진다고 설명한다.

---

# 56. 이제 Neural Network의 Gradient를 어떻게 구할까?

Gradient Descent Update Formula는 이미 알았다.

`θ ← θ - α∇L`

문제는 Neural Network의 `θ`가 너무 많다는 것이다.

각 Layer에는

- Weight Matrix
    
- Bias Vector
    

가 있다.

우리는 이 모든 Parameter에 대해

`∂L/∂θ`

를 계산해야 한다.

---

# 57. 앞 Layer의 Parameter도 최종 Loss에 영향을 준다

예를 들어 첫 번째 Layer의 Weight를 조금 바꾸면

```text
Layer 1 Output 변화
      ↓
Layer 2 Input 변화
      ↓
Layer 2 Output 변화
      ↓
...
      ↓
최종 Prediction 변화
      ↓
Loss 변화
```

가 일어난다.

즉 초반 Layer의 Parameter도 최종 Loss에 영향을 준다.

---

# 58. Neural Network는 합성 함수였다

앞 차시에서 Neural Network는 여러 Function이 연결된 **Composition Function**이라고 배웠다.

개념적으로

`L(f₃(f₂(f₁(x))))`

와 같은 구조다.

따라서 합성 함수의 미분법이 필요하다.

그것이 **Chain Rule**이다.

---

# 59. Chain Rule

합성 함수가

`y = f(g(x))`

라면

`dy/dx = dy/dg × dg/dx`

처럼 바깥 함수의 변화율과 안쪽 함수의 변화율을 곱한다.

강의에서는 이를

> **바깥쪽 변화율 × 안쪽 변화율**

로 설명한다.

---

# 60. Layer가 여러 개라면?

Function이 계속 연결되어 있다면 Chain Rule도 계속 연결된다.

```text
f₁
→ f₂
→ f₃
→ Loss
```

이라면 앞쪽 Function이 Loss에 미치는 영향은 각 구간의 Derivative를 연속해서 곱하여 구할 수 있다.

개념적으로

`∂L/∂f₁ = ∂L/∂f₃ × ∂f₃/∂f₂ × ∂f₂/∂f₁`

와 같은 구조다.

---

# 61. 이것이 Backpropagation의 기반

**Backpropagation(역전파)** 은 완전히 새로운 미분법이 아니다.

> **Neural Network라는 합성 함수에 Chain Rule을 체계적으로 적용하여 각 Parameter의 Gradient를 계산하는 방법**

이라고 이해하면 된다.

---

# 62. Forward Direction과 Backward Direction

Forward에서는

```text
Input
 ↓
Layer 1
 ↓
Layer 2
 ↓
...
 ↓
Prediction
 ↓
Loss
```

를 계산한다.

Backward에서는 반대로

```text
Loss
 ↑
Layer Gradient
 ↑
Layer Gradient
 ↑
...
 ↑
초기 Layer
```

로 Gradient 정보를 전달한다.

---

# 63. Pre-activation과 Activation이 다시 중요해진다

앞 차시에서

```text
Pre-activation
z = Wh + b

Activation
h = A(z)
```

를 배웠다.

Backpropagation에서는 이 각각의 Function이 Chain Rule의 한 Component가 된다.

즉

```text
Loss
→ 다음 Layer
→ Activation
→ Pre-activation
→ Weight/Bias
```

순서로 미분 관계를 추적한다.

---

# 64. Loss에서 이전 Layer까지 Gradient를 연결한다

예를 들어 Loss `L`이 마지막 Layer의 Function에 의존하고 그 Function이 이전 Hidden Unit에 의존한다면

```text
∂L/∂Previous
=
∂L/∂Next
×
∂Next/∂Previous
```

형태로 계속 연결한다.

강의에서는 여러 구간을 하나씩 분리해서 보여주지만 한 번에 Chain Rule로 길게 표현할 수도 있다고 설명한다.

---

# 65. 하지만 우리가 진짜 원하는 것은 Function 값의 Gradient가 아니다

최종 목적은

```text
∂L/∂Weight
∂L/∂Bias
```

다.

왜냐하면 실제 Update 대상은 Weight와 Bias이기 때문이다.

따라서 중간 Hidden Function까지 Gradient를 계산한 뒤 다시 Parameter까지 Chain Rule을 연결한다.

---

# 66. Linear Mapping을 미분하면 Weight가 등장한다

한 Layer가

`f = Wh + b`

형태라면 `h`에 대한 미분에서는 Weight가 등장한다.

강의에서는 복잡하게 보이는 Backpropagation 식도 실제 Component 하나하나를 미분해보면 매우 단순한 연산이라는 점을 강조한다.

---

# 67. 결국 Parameter Gradient를 얻는다

예를 들어 첫 번째 Layer의 Weight에 대한 Gradient를 구하고 싶다면

```text
Loss에서 시작
      ↓
마지막 Layer
      ↓
Activation
      ↓
이전 Layer
      ↓
...
      ↓
첫 번째 Layer Weight
```

까지 연결된 Derivative들을 Chain Rule로 계산한다.

그 결과

`∂L/∂W¹`

을 얻는다.

---

# 68. 두 번째 Layer도 똑같다

두 번째 Layer의 Weight를 Update하고 싶다면 Loss부터 해당 Weight까지 연결된 Chain만 계산한다.

```text
Loss
 ↓ backward
해당 Layer
 ↓
∂L/∂W²
```

를 구한다.

즉 Layer마다 원리는 동일하다.

---

# 69. Backpropagation 이후 Gradient Descent

Backpropagation의 역할:

```text
각 Parameter의 Gradient 계산
```

Gradient Descent의 역할:

```text
계산된 Gradient를 이용해
Parameter Update
```

이다.

따라서 둘을 구분해야 한다.

---

# 70. Backpropagation과 Gradient Descent 관계

```text
Forward Pass
      ↓
Prediction / Loss
      ↓
Backpropagation
      ↓
각 Parameter Gradient
      ↓
Gradient Descent / SGD
      ↓
Parameter Update
```

이다.

즉

> **Backpropagation은 Gradient를 계산하고, Gradient Descent는 그 Gradient로 Parameter를 움직인다.**

---

# 71. Neural Network Training 한 Step

전체를 한 번 연결하면 다음과 같다.

```text
Mini-batch Input
      ↓
Forward Pass
      ↓
Prediction
      ↓
Loss
      ↓
Backpropagation
      ↓
∂L/∂W, ∂L/∂b
      ↓
W ← W - α∂L/∂W
b ← b - α∂L/∂b
      ↓
다음 Mini-batch
```

이것이 Neural Network Training의 기본적인 반복 구조다.

---

# 72. 깊은 Network의 장점과 대가

앞 차시에서는 Depth가 증가하면 비슷한 Parameter 수에서도 더 높은 표현력을 얻을 수 있다고 배웠다.

하지만 이번 차시에서는 Depth의 대가를 설명한다.

```text
Depth 증가
→ 표현력 증가

하지만

Depth 증가
→ Chain Rule의 곱 증가
→ 학습 어려움 증가
```

즉 Trade-off가 존재한다.

---

# 73. 깊어질수록 Gradient 곱이 길어진다

Backpropagation은 Chain Rule이므로 여러 Derivative를 곱한다.

```text
Gradient
=
g₁ × g₂ × g₃ × ... × gₙ
```

Layer가 많을수록 곱의 개수도 많아진다.

---

# 74. Vanishing Gradient

각 Derivative가 반복적으로 1보다 작은 값을 가진다고 생각해보자.

예:

`0.99 × 0.99 × ...`

를 아주 많이 반복하면 점점 작은 값이 된다.

따라서 초반 Layer로 전달되는 Gradient가 매우 작아질 수 있다.

이를 **Vanishing Gradient**와 연결한다.

```text
Gradient ≈ 0
      ↓
앞쪽 Layer가 거의 Update되지 않음
      ↓
학습 어려움
```

---

# 75. Exploding Gradient

반대로 Chain Rule에서 곱해지는 값들이 반복적으로 1보다 크다면 값이 급격하게 커질 수 있다.

```text
Gradient
× 큰 값
× 큰 값
× 큰 값
...
      ↓
매우 큰 Gradient
```

이를 **Exploding Gradient**라고 한다.

---

# 76. 깊은 Network Training의 핵심 문제

따라서 Deep Network에서는 Backpropagation 과정에서 Gradient가

```text
너무 작아지거나
→ Vanishing

너무 커지거나
→ Exploding
```

하는 문제가 발생할 수 있다.

이것이 Depth가 증가할수록 Optimization이 어려워지는 중요한 이유 중 하나다.

---

# 77. 그래서 여러 Training Technique이 필요하다

강의에서는 현대 Neural Network에서

- Normalization
    
- 여러 Optimization Technique
    
- 기타 Training Engineering
    

을 사용하는 이유 중 하나로 Gradient의 Vanishing/Explosion을 관리하는 문제를 설명한다.

---

# 78. 그래도 Backpropagation을 포기할 수 없는 이유

앞 Layer의 Parameter가 최종 Prediction과 Loss에 영향을 준다.

따라서 각 Layer가 Loss에 어떤 영향을 주었는지를 계산해야 한다.

Backpropagation은 바로 이 정보를 각 Layer에 제공한다.

즉 Gradient 문제가 있다고 해서 앞 Layer의 정보를 버릴 수는 없다.

---

# 79. 전체 Neural Network 학습 구조

```text
Training Data
      ↓
Mini-batch Sampling
      ↓
Forward Pass
      ↓
Prediction
      ↓
Loss 계산
      ↓
Backpropagation
      ↓
Chain Rule
      ↓
각 Weight/Bias의 Gradient 계산
      ↓
SGD
      ↓
Gradient 반대 방향으로 Update
      ↓
새로운 Parameter
      ↓
다음 Mini-batch
      ↓
반복
```

---

# 80. Linear Regression에서 Neural Network까지 연결

## Linear Regression

```text
Parameter
w,b
 ↓
RSS
 ↓
RSS 최소화
```

Closed-form으로 풀 수도 있다.

---

## Logistic Regression

```text
Parameter β
 ↓
Likelihood
 ↓
Maximum Likelihood
```

Closed-form이 없어 Numerical Optimization이 필요하다.

---

## Neural Network

```text
수많은 W,b
 ↓
Prediction
 ↓
Loss
 ↓
Loss 최소화
 ↓
Gradient 계산
 ↓
Parameter Update
```

즉 모든 Model에서 **Parameter Optimization**이라는 본질은 동일하다.

---

# 81. Gradient Descent의 핵심 직관

```text
현재 위치
      ↓
Gradient 계산
      ↓
Gradient = 가장 가파른 증가 방향
      ↓
그 반대 방향으로 이동
      ↓
Loss 감소
```

이다.

---

# 82. Gradient Descent Update 핵심식

`θ ← θ - α∇L(θ)`

각 부분의 의미:

|항목|의미|
|---|---|
|`θ`|현재 Parameter|
|`L`|Loss Function|
|`∇L`|Gradient|
|`-`|감소 방향|
|`α`|Learning Rate|
|새로운 `θ`|Update된 Parameter|

---

# 83. Full Gradient와 Mini-batch 비교

|항목|Full Gradient|Mini-batch / SGD|
|---|---|---|
|한 Step Data|전체|일부|
|Gradient|전체 Data 기준|Sampling된 근사값|
|경로|비교적 Smooth|Noisy / Zigzag|
|Step 계산량|큼|작음|
|Large Dataset|부담 큼|적합|
|Local Minimum 탈출 가능성|상대적으로 낮음|Randomness가 도움될 수 있음|
|Global Minimum 보장|Non-convex에서는 없음|역시 없음|

---

# 84. Convex와 Non-convex 비교

|Convex|Non-convex|
|---|---|
|그릇 형태 직관|여러 골짜기 가능|
|Local Minimum = Global Minimum|Local ≠ Global 가능|
|Optimization 상대적으로 쉬움|Optimization 어려움|
|Linear Regression의 대표 Loss 예|Neural Network Loss|
|Gradient Descent 분석 쉬움|Initialization 등의 영향 큼|

---

# 85. Gradient와 Backpropagation 차이

### Gradient

Loss가 각 Parameter에 대해 얼마나 변하는지를 나타내는 값.

### Backpropagation

Neural Network의 합성 구조에서 **Chain Rule을 이용해 그 Gradient들을 효율적으로 계산하는 과정**.

### Gradient Descent

계산된 Gradient를 이용해 Parameter를 실제로 Update하는 Optimization Algorithm.

---

# 86. 자주 헷갈리는 점 ① — Gradient 방향으로 내려가는가?

아니다.

Gradient는 증가 방향이다.

Loss를 줄이려면

`-Gradient`

방향으로 움직인다.

---

# 87. 자주 헷갈리는 점 ② — Gradient가 크면 무조건 많이 움직이는가?

실제 Update 크기는

`Learning Rate × Gradient`

로 결정된다.

따라서 Gradient뿐 아니라 Learning Rate도 중요하다.

---

# 88. 자주 헷갈리는 점 ③ — 편미분은 완전히 다른 미분인가?

강의에서는 그렇게 어렵게 볼 필요가 없다고 설명한다.

Parameter가 여러 개이므로 하나씩 각각 미분하고 이를 모아서 Gradient Vector로 만드는 것이다.

---

# 89. 자주 헷갈리는 점 ④ — Gradient가 0이면 항상 Global Minimum인가?

아니다.

Convex Function에서는 좋은 성질을 가지지만 Non-convex Function에서는

- Local Minimum
    
- Saddle Point
    

등에서도 Gradient가 0일 수 있다.

---

# 90. 자주 헷갈리는 점 ⑤ — Neural Network는 Convex 문제인가?

강의 기준으로 Hidden Layer가 존재하는 Neural Network Optimization은 Non-convex Problem이다.

따라서 Global Minimum을 단순하게 보장하기 어렵다.

---

# 91. 자주 헷갈리는 점 ⑥ — SGD는 항상 Gradient Descent보다 정확한가?

아니다.

오히려 일부 Data만 이용하기 때문에 Gradient Estimate에 Noise가 있다.

그 결과 Update가 지그재그로 움직일 수 있다.

---

# 92. 자주 헷갈리는 점 ⑦ — 그렇다면 Noise는 무조건 나쁜가?

아니다.

Non-convex Optimization에서는 Randomness가 Local Minimum이나 Saddle Point 주변에서 벗어나는 데 도움이 될 수도 있다.

---

# 93. 자주 헷갈리는 점 ⑧ — SGD면 Global Minimum을 보장하는가?

아니다.

강의에서도 그러한 보장은 없다고 설명한다.

Noise가 일부 상황에서 도움이 될 수 있다는 것과 Global Minimum 보장은 별개의 문제다.

---

# 94. 자주 헷갈리는 점 ⑨ — Backpropagation이 Parameter를 Update하는가?

엄밀히 구조를 나누면

```text
Backpropagation
→ Gradient 계산

Gradient Descent / SGD
→ Parameter Update
```

다.

---

# 95. 자주 헷갈리는 점 ⑩ — Backpropagation은 새로운 수학 공식인가?

본질은 **Chain Rule**이다.

Neural Network라는 긴 합성 함수에 Chain Rule을 반복적으로 적용하는 계산 절차다.

---

# 96. 자주 헷갈리는 점 ⑪ — Layer가 깊으면 무조건 좋은가?

아니다.

앞 차시:

```text
Depth ↑
→ 표현 효율성 ↑
```

이번 차시:

```text
Depth ↑
→ Chain Rule 길어짐
→ Optimization 어려움 ↑
```

이다.

따라서 표현력과 학습 난이도 사이의 Trade-off가 있다.

---

# 97. 자주 헷갈리는 점 ⑫ — Vanishing Gradient는 Loss가 작다는 의미인가?

아니다.

Vanishing Gradient는 **Backpropagation 과정에서 전달되는 Gradient가 너무 작아진 상태**다.

Loss 자체가 작다는 의미가 아니다.

---

# 98. Exploding Gradient도 마찬가지

Gradient가 매우 크다고 해서 Model이 좋다는 뜻이 아니다.

Parameter Update가 지나치게 커지거나 학습이 불안정해질 수 있는 Optimization 문제다.

# 102. 이번 강의에서 반드시 기억할 핵심

### 1. 학습의 목적은 Loss를 최소화하는 Parameter를 찾는 것이다.

### 2. Linear Regression, Logistic Regression, Neural Network 모두 본질적으로 Parameter Optimization 문제다.

### 3. Gradient는 현재 위치에서 Loss가 가장 빠르게 증가하는 방향이다.

### 4. Loss를 최소화하려면 Gradient의 반대 방향으로 이동한다.

`θ ← θ - α∇L`

### 5. `α`는 Learning Rate이며 Step Size를 조절한다.

### 6. Parameter가 여러 개면 각각 편미분하고 이를 모아 Gradient Vector를 만든다.

### 7. Gradient Descent는 한 번 계산하고 끝나는 것이 아니라 반복적으로 Parameter를 Update한다.

### 8. Convex Problem에서는 Local Minimum이 Global Minimum이라는 좋은 성질이 있다.

### 9. Neural Network Optimization은 Non-convex이므로 Local Minimum이나 Saddle Point 문제가 생길 수 있다.

### 10. Full Gradient Descent는 매 Step마다 전체 Training Data를 사용한다.

### 11. 대규모 Data에서는 계산 비용 때문에 Mini-batch 기반 SGD가 유용하다.

### 12. SGD의 Gradient는 Sampling 때문에 Noise를 포함한다.

### 13. 이 Noise는 Non-convex 상황에서 Local Minimum 등에 갇히는 것을 완화하는 데 도움이 될 수도 있다.

### 14. 그렇다고 SGD가 Global Minimum을 보장하지는 않는다.

### 15. Neural Network는 합성 함수이므로 Parameter Gradient 계산에 Chain Rule을 사용한다.

### 16. Backpropagation은 Chain Rule을 이용해 최종 Loss의 Gradient를 뒤에서부터 각 Layer로 전달하는 과정이다.

### 17. Backpropagation은 Gradient를 계산하고, Gradient Descent/SGD가 그 Gradient를 이용해 Parameter를 Update한다.

### 18. Layer가 깊어지면 Chain Rule에서 곱해지는 Gradient 항이 많아진다.

### 19. 작은 Derivative들이 반복 곱되면 Vanishing Gradient가 발생할 수 있다.

### 20. 큰 Derivative들이 반복 곱되면 Exploding Gradient가 발생할 수 있다.

### 21. Deep Network는 표현력이 높지만 Optimization이 더 어려워질 수 있다.

# 104. 이번 강의의 핵심을 한 문장으로

> **신경망 학습은 Prediction으로부터 계산한 Loss를 각 Parameter에 대해 미분하고, Backpropagation으로 Chain Rule을 적용해 모든 Weight와 Bias의 Gradient를 구한 뒤, Gradient Descent 또는 Mini-batch SGD를 이용해 그 Gradient의 반대 방향으로 Parameter를 반복적으로 수정하는 과정이다.**

그리고 앞 차시와 연결하면 다음과 같다.

> **Forward Pass가 현재 Parameter가 어떤 함수를 만들고 어떤 Prediction을 내는지를 계산하는 과정이라면, Backpropagation은 그 Prediction의 Error가 각 Parameter의 책임으로 얼마나 돌아가는지를 Chain Rule로 계산하고, Gradient Descent는 그 정보를 이용해 Parameter를 실제로 수정하는 과정이다.**
