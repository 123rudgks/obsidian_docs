# 0. 강의 전체 개요

이번 시간부터 본격적인 Machine Learning 방법론을 배운다.

첫 번째 방법론은 **Linear Regression(선형회귀)** 이다.

앞선 강의에서 Regression은

> **숫자 값을 Target으로 예측하는 지도학습 문제**

라고 배웠다.

선형회귀는 그 Regression 문제를 해결하는 가장 기본적인 방법이다.

전체 흐름은 다음과 같다.

```text
Regression 문제
      ↓
Linear Hypothesis Space 선택
      ↓
Simple Linear Regression
      ↓
y = β₀ + β₁x + ε
      ↓
관측값과 예측값의 차이
Residual
      ↓
Residual²의 합
RSS
      ↓
RSS를 최소화하는
β₀, β₁ 찾기
      ↓
Least Squares
      ↓
Coefficient 추정
      ↓
Standard Error
t-statistic
p-value
R²
      ↓
Multiple Linear Regression
      ↓
여러 Feature를 동시에 사용
      ↓
Matrix 표현과 Closed-form Solution
      ↓
일반화 평가
다중공선성
상관관계 ≠ 인과관계
```

---

# 1. 선형회귀가 사용되는 문제

선형회귀는 여러 실제 분석 문제에 사용할 수 있다.

강의에서는 광고비와 매출을 대표적인 예로 든다.

```text
TV 광고비
    ↓
  매출
```

여기서

- 광고비 = Input / Feature `x`
    
- 매출 = Target / Label `y`
    

이다.

우리가 알고 싶은 것은

> **광고비가 변할 때 매출이 어떻게 변하는가?**

이다.

---

# 2. 다른 선형회귀 활용 사례 — 신용점수

신용점수를 예측한다고 하자.

Feature로

- 고객 소득
    
- 소비 패턴
    
- 부채
    
- 기타 금융 정보
    

등을 사용할 수 있다.

예를 들어 소득이 증가하면 신용점수가 증가하는 관계가 있을 수 있고, 부채가 많으면 반대로 감소하는 관계가 있을 수 있다.

이러한 Feature와 숫자로 된 Target 사이의 관계를 모델링하는 것도 Regression 문제다.

---

# 3. Linear Regression이란?

선형회귀는

> **입력 변수 x와 출력 변수 y 사이의 관계를 직선 형태의 함수로 근사하여 예측하는 방법**

이다.

1개의 Feature에서는 직선이고, Feature가 여러 개가 되면 더 높은 차원의 Hyperplane으로 확장된다.

선형회귀는

- 가장 기초적인 지도학습 방법
    
- 개념적으로 매우 중요
    
- 이후 배우는 여러 방법론의 기반
    
- 실제 현업에서도 여전히 널리 사용
    

되는 모델이다.

---

# 4. 앞 강의의 Hypothesis Space와 연결

앞서 Machine Learning에서는 먼저 **Hypothesis Space**를 결정한다고 배웠다.

Linear Regression을 선택한다는 것은

> **가능한 함수 중 Linear Function만 후보로 사용하겠다.**

는 뜻이다.

```text
전체 가능한 함수
       ↓
Linear Regression 선택
       ↓
Linear Hypothesis Space
       ↓
직선 / 평면 / Hyperplane
```

즉 선형회귀의 학습은

> **선형 함수들의 집합 중 Data를 가장 잘 설명하는 하나를 찾는 문제**

다.

---

# 5. 선형회귀로 답할 수 있는 질문

광고 데이터를 예로 들면 선형회귀를 이용해 여러 질문을 할 수 있다.

### 1. 광고비와 매출 사이에 관계가 있는가?

광고비를 늘려도 매출 변화가 없다면 기울기가 0에 가까울 수 있다.

### 2. 관계의 강도는 어느 정도인가?

광고비 변화가 매출에 얼마나 영향을 주는가를 살펴볼 수 있다.

### 3. 어떤 광고 매체가 더 관련 있는가?

예:

- TV
    
- Radio
    
- Online
    
- Newspaper
    

각 광고비가 매출과 어떤 관계를 가지는지 분석할 수 있다.

### 4. 미래 매출을 예측할 수 있는가?

광고비를 특정 값으로 설정했을 때 예상 매출을 계산할 수 있다.

### 5. 여러 광고매체의 관계를 함께 분석할 수 있는가?

여러 Feature가 존재한다면 이후 배우는 Multiple Linear Regression으로 확장할 수 있다.

---

# 6. Simple Linear Regression

가장 먼저 **Simple Linear Regression(단순 선형회귀)** 을 배운다.

단순 선형회귀란

> **설명 변수, 즉 Feature x가 하나인 선형회귀**

다.

```text
x 하나
↓
Simple Linear Regression
```

예:

```text
TV 광고비 x
      ↓
    매출 y
```

Feature가 하나이므로 앞 강의 표현으로는 **1D Feature** 문제다.

---

# 7. 단순 선형회귀의 목표

Data Point들이 다음과 같이 있다고 하자.

```text
(x₁, y₁)
(x₂, y₂)
...
(xₙ, yₙ)
```

우리가 원하는 것은

> **이 Data를 가장 잘 설명하는 직선 하나를 찾는 것**

이다.

그리고 그 직선을 이용해 새로운 `x`가 들어왔을 때 `y`를 예측한다.

---

# 8. 선형회귀의 기본 Model

직선은 기울기와 절편만 알면 결정된다.

기본 관계는

`y = β₀ + β₁x + ε`

로 표현한다.

여기서

- `β₀` : Intercept, 절편
    
- `β₁` : Slope, 기울기
    
- `x` : Feature
    
- `y` : 실제 관측값
    
- `ε` : Noise / 관측 오차
    

다.

---

# 9. β₀ — Intercept

`β₀`는 절편이다.

즉

`x = 0`

일 때 선형 함수의 기본 y값이다.

그래프에서는 y축과 직선이 만나는 위치를 결정한다.

---

# 10. β₁ — Slope

`β₁`은 기울기다.

x가 1만큼 증가할 때 평균적인 y 변화량을 나타낸다.

예를 들어

`β₁ > 0`

이라면

```text
x 증가
→ y 증가
```

하는 관계다.

반대로

`β₁ < 0`

이면 x가 증가할수록 y가 감소하는 방향이다.

---

# 11. 앞 강의의 True Function과 연결

앞서

`y = f*(x) + ε`

라고 배웠다.

이번 선형회귀에서는 True Function이 Linear하다고 가정한다면

`f*(x) = β₀ + β₁x`

형태로 생각한다.

따라서

`y = β₀ + β₁x + ε`

가 된다.

---

# 12. Data Point들이 직선 위에 완전히 놓이지 않는 이유

실제 Data는 정확히 직선 위에 있지 않는다.

```text
          ● y
          │
          │ ε
──────────┼──── True Linear Function
```

그 이유가 `ε`다.

즉 평균적인 관계는 직선이라고 가정하더라도 실제 개별 Data에는

- Noise
    
- Measurement Error
    
- 관측되지 않은 요인
    

등이 존재할 수 있다.

따라서 실제 Data Point는 직선 주변에 흩어져 있다.

---

# 13. 학습된 선을 이용한 Prediction

선형 Model을 학습하고 나면 새로운 `x`를 직선에 넣어 Prediction을 얻을 수 있다.

```text
새로운 x
   ↓
학습된 직선
   ↓
ŷ
```

예를 들어 광고비가 특정 값이라면 직선 위에서 대응하는 매출값을 읽어 Prediction으로 사용한다.

중요한 점은

> **선형 Model의 모든 Prediction은 학습된 직선 위에 존재한다.**

는 것이다.

---

# 14. 그런데 직선을 어떻게 학습하는가?

가능한 직선은 무수히 많다.

```text
/
——
\
/
...
```

따라서 어떤 직선이 가장 좋은지 정하는 기준이 필요하다.

선형회귀에서는 대표적으로 **Least Squares(최소제곱법)** 를 사용한다.

---

# 15. Residual

최소제곱법을 이해하려면 먼저 **Residual(잔차)** 을 알아야 한다.

i번째 Data Point에서

- 실제값 = `yᵢ`
    
- 예측값 = `ŷᵢ`
    

라면 Residual은

`eᵢ = yᵢ - ŷᵢ`

이다.

즉

> **실제 관측값과 모델의 예측값 사이의 차이**

다.

---

# 16. Residual을 그림으로 이해하기

```text
        ● 실제값 yᵢ
        │
        │ Residual
        │
────────●──────── Regression Line
       ŷᵢ
```

현재 Model이 만든 Prediction은 직선 위에 있다.

실제 Data Point와 직선 위 Prediction 사이의 차이가 Residual이다.

---

# 17. Residual과 ε는 같은가?

구분해야 한다.

앞서 배운 `ε`는

```text
True Function
↕
Observed Data
```

사이의 관측 Noise다.

Residual은

```text
Estimated Model
↕
Observed Data
```

사이의 차이다.

우리는 True Function을 모르므로 실제 `ε`를 직접 볼 수 없다.

반면 학습된 Model과 관측 Data가 있으면 Residual은 계산할 수 있다.

---

# 18. 왜 Residual을 그냥 더하지 않는가?

Residual은 Positive일 수도 있고 Negative일 수도 있다.

```text
+10
-10
```

을 그냥 합치면

`0`

이 된다.

두 Prediction 모두 크게 틀렸는데 Error가 사라져버린다.

따라서 Residual을 제곱한다.

---

# 19. Residual Squared

각 Residual을

`eᵢ²`

으로 만든다.

그러면

- Positive Error
    
- Negative Error
    

모두 Positive가 된다.

그리고 큰 Error일수록 더 큰 Penalty가 생긴다.

---

# 20. RSS — Residual Sum of Squares

모든 Data Point의 Residual을 제곱한 뒤 합한다.

`RSS = Σ eᵢ²`

즉

`RSS = Σ(yᵢ - ŷᵢ)²`

이다.

RSS는 **Residual Sum of Squares**, 즉 **잔차제곱합**이다.

---

# 21. RSS가 작다는 의미

```text
RSS 큼
→ 관측 Data와 직선이 많이 떨어져 있음

RSS 작음
→ 관측 Data와 직선이 가까움
```

따라서 Training Data를 설명하는 관점에서는 RSS가 작을수록 좋은 직선이다.

---

# 22. Linear Regression의 학습 문제

결국 Linear Regression의 문제는 다음과 같다.

> **가능한 모든 직선 중 RSS를 가장 작게 만드는 직선을 찾아라.**

직선을 결정하는 것은

- 기울기 `β₁`
    
- 절편 `β₀`
    

두 값이다.

따라서 실질적인 학습 문제는

> **RSS를 최소화하는 β₀와 β₁을 찾는 것**

이다.

---

# 23. Prediction 식을 RSS에 넣어보기

단순 선형회귀의 예측식은

`ŷᵢ = β̂₀ + β̂₁xᵢ`

이다.

따라서 Residual은

`yᵢ - (β̂₀ + β̂₁xᵢ)`

이고 RSS는

`RSS = Σ[yᵢ - (β̂₀ + β̂₁xᵢ)]²`

가 된다.

즉 RSS는 결국

> **β₀와 β₁에 따라 값이 변하는 함수**

다.

---

# 24. Hat 기호의 의미

강의에서 추정값에 붙는 표기는 **Hat**이다.

예:

- `β₀` : 실제 True Parameter
    
- `β̂₀` : Data로부터 추정한 Parameter
    
- `β₁` : 실제 True Slope
    
- `β̂₁` : 추정한 Slope
    
- `y` : 실제값
    
- `ŷ` : Prediction
    

즉

> **Hat이 붙으면 우리가 Data를 이용해 추정한 값**

이라고 이해하면 된다.

---

# 25. True β는 알 수 없다

중요하다.

학습으로 얻은 직선이 있다고 해서

> “이 직선이 True Function이다.”

라고 말할 수는 없다.

실제

`β₀`, `β₁`

은 알 수 없다.

우리가 Data를 이용해 얻는 것은

`β̂₀`, `β̂₁`

이라는 **Estimate**다.

목표는 이를 True Parameter에 가능한 가깝게 추정하는 것이다.

---

# 26. Least Squares의 Closed-form Solution

단순 선형회귀에서는 RSS를 최소화하는 `β̂₀`, `β̂₁`을 수식으로 직접 계산할 수 있다.

강의에서는 정확한 식을 외울 필요는 없다고 설명한다.

중요한 점은

> **Data의 x와 y 값만 있으면 RSS를 최소화하는 기울기와 절편을 직접 계산할 수 있다.**

는 것이다.

기울기 계산에는

- 각 `xᵢ`
    
- 각 `yᵢ`
    
- `x̄`
    
- `ȳ`
    

등이 사용된다.

즉 모두 관측된 Data로 계산할 수 있다.

---

# 27. 왜 최소값을 직접 계산할 수 있는가?

RSS를 `β`에 대한 함수라고 생각해보자.

Residual 안에는 `β`가 1차로 들어 있고 전체가 제곱되므로 RSS는 β에 대한 **2차 함수** 형태가 된다.

개념적으로

```text
RSS
 ↑
 │       /
 │      /
 │  ___/
 │ /
 └────────→ β
```

처럼 아래로가 아니라 위로 열린 2차 함수 형태의 최소점을 생각할 수 있다.

---

# 28. 2차 함수의 최소값

2차 함수의 최소값은 꼭짓점에 존재한다.

그리고 그 점에서는

> **기울기 = 0**

이다.

따라서 RSS를 β에 대해 미분하고

`Derivative = 0`

이 되는 지점을 찾으면 RSS의 최소점이 된다.

이것이 최소제곱 해를 구하는 수학적 핵심이다.

---

# 29. 미분이 왜 Machine Learning에 등장하는가?

이 강의에서 미분의 역할을 처음 직관적으로 연결한다.

```text
우리가 원하는 것
= Loss 최소

Loss는 Parameter의 함수
       ↓
최솟값에서는
기울기 = 0
       ↓
미분을 이용하여
기울기 계산
```

즉 Machine Learning에서 미분은

> **Loss가 최소가 되는 Parameter를 찾기 위해 사용된다.**

이후 Gradient Descent에서도 이 생각이 다시 등장한다.

---

# 30. Closed-form과 Gradient Descent

이번 선형회귀에서는 수식으로 한 번에 Parameter를 계산하는 **Closed-form Solution**을 소개한다.

하지만 이후 4차시에서는 **Gradient Descent**를 이용해서 Parameter를 순차적으로 update하는 방법을 배울 예정이다.

```text
Closed-form
→ 식으로 한 번에 계산

Gradient Descent
→ 조금씩 반복해서 최솟값으로 이동
```

두 방법 모두 궁극적으로는 **Loss를 줄이는 Parameter를 찾는다**는 같은 목적을 가진다.

---

# 31. 학습된 Regression Line의 의미

최소제곱법으로 얻은 Regression Line은

> **현재 Training Data에 대해 RSS가 가장 작은 직선**

이다.

다른 직선을 가져오면 Residual이 달라지고 RSS도 달라진다.

최소제곱법으로 얻은 선은 이 후보들 중 RSS가 최소가 되도록 선택한 선이다.

---

# 32. 학습 결과로 얻는 핵심 값

Simple Linear Regression의 핵심 Parameter는 두 개다.

```text
β̂₀
→ Estimated Intercept

β̂₁
→ Estimated Slope
```

이 두 값만 알면 학습된 직선을 완전히 정의할 수 있다.

---

# 33. Linear Regression 결과표

실제 통계 또는 Machine Learning Library를 이용해 Linear Regression을 수행하면 보통 다음과 같은 정보를 볼 수 있다.

- Coefficient Estimate
    
- Standard Error
    
- t-statistic
    
- p-value
    
- R²
    

강의에서는 단순히 Library를 사용하는 것보다

> **결과표의 각 숫자가 무엇을 의미하는지 해석할 수 있어야 한다.**

고 강조한다.

---

# 34. Coefficient

Coefficient는 각 `β`의 추정치다.

Simple Linear Regression에서는

- Intercept estimate
    
- Slope estimate
    

가 나온다.

예를 들어 TV 광고비의 Slope가 Positive라면, 다른 조건에서 광고비가 증가할수록 예상 매출도 증가하는 방향의 관계라고 해석한다.

---

# 35. Standard Error

Coefficient Estimate는 Data Sample에 따라 조금씩 달라질 수 있다.

Data를 조금 다르게 관측했다면

```text
β̂₁ = 0.0475
```

가 아니라 조금 다른 값이 나올 수도 있다.

Standard Error는 이러한 **Estimate의 불확실성/변동 정도**를 나타내는 값으로 설명된다.

---

# 36. t-statistic

강의에서는 t-statistic을 기본적으로

`Coefficient / Standard Error`

의 비율로 설명한다.

즉

> **추정된 계수가 그 추정 불확실성에 비해 얼마나 크게 0에서 떨어져 있는가**

를 살펴보는 값이다.

---

# 37. 기본 Null Hypothesis

Slope의 유의성을 분석할 때 대표적인 기본 가정은

`H₀ : β₁ = 0`

이다.

`β₁ = 0`이라는 것은

```text
x가 변해도
y의 평균적인 선형 관계가 변하지 않음
```

즉 강의 맥락에서는

> **x와 y 사이에 의미 있는 선형 관계가 없다고 보는 기본 가설**

이다.

---

# 38. p-value의 직관

강의에서는 p-value를 다음 상황으로 설명한다.

먼저

`β₁ = 0`

이라고 가정한다.

즉 실제로 x와 y 사이에 선형 관계가 없다고 가정한다.

그런데 실제 Data에서 0과 꽤 떨어진 `β̂₁`을 관측했다.

이때 묻는다.

> **만약 정말 β₁=0이라면 현재처럼 0에서 크게 떨어진 결과를 관측할 가능성이 얼마나 되는가?**

그 관점에서 p-value를 해석한다.

---

# 39. p-value가 작다면?

p-value가 매우 작다면

> **β₁=0이라는 가정 아래 현재 같은 결과가 나오는 것이 매우 드물다.**

는 뜻이다.

따라서 충분히 작은 경우 Null Hypothesis를 기각하고

> `β₁`이 0과 다르다고 볼 통계적 근거가 있다.

고 판단한다.

강의에서는 이를 해당 Feature와 Target 사이의 관계가 통계적으로 유의하다는 방향으로 설명한다.

---

# 40. 일반적으로 사용하는 p-value 기준

강의에서는 통상적으로

`p < 0.05`

를 많이 사용하는 기준으로 소개한다.

Domain에 따라 더 엄격하게

`0.01`

등을 사용할 수도 있다.

핵심은 특정 Threshold 아래로 충분히 작다면 `β=0`이라는 가설에 반하는 증거로 사용한다는 것이다.

---

# 41. 매우 중요 — Coefficient가 작으면 관계가 약한가?

아니다.

강의에서 강하게 강조하는 오해다.

예를 들어

`β̂₁ = 0.0475`

라고 하자.

숫자가 작아 보인다고 해서

> “x와 y의 선형 관계가 약하다.”

라고 해석하면 안 된다.

왜냐하면 Coefficient의 숫자는 **Feature와 Target의 단위에 영향을 받기 때문**이다.

---

# 42. 단위를 바꾸면 Coefficient도 바뀐다

예를 들어 광고비를

```text
100만 원 단위
```

로 표현하는 것과

```text
원 단위
```

로 표현하는 것은 값의 Scale이 완전히 다르다.

같은 관계라도 x 단위를 바꾸면 기울기의 숫자값도 달라진다.

따라서

> **Coefficient의 절댓값 자체만 보고 관계가 강하다/약하다고 판단하면 안 된다.**

---

# 43. Coefficient 해석은 단위와 함께 해야 한다

기울기는 기본적으로

> **x가 1 unit 증가했을 때 y가 평균적으로 얼마나 변화하는가**

이기 때문에 `1 unit`이 무엇인지가 중요하다.

따라서 항상 Feature 단위를 함께 확인해야 한다.

---

# 44. p-value는 Coefficient만으로 결정되지 않는다

p-value의 유의성을 판단하려면 Coefficient뿐 아니라 **Standard Error**도 중요하다.

강의의 흐름은

```text
Coefficient
       ↓
Coefficient / Standard Error
       ↓
t-statistic
       ↓
p-value
```

이다.

Coefficient가 어느 정도 있어도 Standard Error가 매우 크면 t-statistic의 절댓값이 작아지고 p-value가 커질 수 있다.

반대로 Coefficient가 작아도 Standard Error가 매우 작으면 통계적으로 유의할 수 있다.

---

# 45. 항상 상대적으로 봐야 한다

따라서 단순히

```text
Coefficient가 0.001이니까 작다.
```

라고 해석해서는 안 된다.

중요한 것은

> **Estimate가 그 불확실성에 비해 얼마나 큰가**

이다.

강의에서는 이 상대적 해석을 반복적으로 강조한다.

---

# 46. R² 다시 보기

앞 차시에서 배운 결정계수 `R²`도 Linear Regression 결과를 평가하는 데 사용한다.

R²는 기본적으로

> **단순히 y 평균으로 예측했을 때와 비교하여 현재 Model이 y의 변동을 얼마나 설명하는가**

를 나타낸다.

---

# 47. TV 광고 단순회귀의 R² 예

강의의 광고 Dataset에서는 TV 광고비 하나만 사용한 Simple Linear Regression에서 약

`R² ≈ 0.61`

정도의 결과를 예로 든다.

강의에서는 이를

> **매출 y의 변동 중 상당 부분을 TV 광고비라는 하나의 Feature로 설명할 수 있다.**

는 방향으로 해석한다.

---

# 48. Simple → Multiple Linear Regression

지금까지는 Feature가 하나였다.

```text
x = TV 광고비
```

하지만 실제 문제에는 Feature가 여러 개 있을 수 있다.

예:

```text
x₁ = TV 광고비
x₂ = Radio 광고비
x₃ = Online 광고비
x₄ = Newspaper 광고비
...
```

여러 Input Feature를 동시에 사용하는 것을 **Multiple Linear Regression(다중 선형회귀)** 이라고 한다.

---

# 49. Simple과 Multiple의 기준

구분 기준은 **Input Feature 개수**다.

```text
Feature 1개
→ Simple Linear Regression

Feature 2개 이상
→ Multiple Linear Regression
```

Target `y`는 여전히 하나다.

---

# 50. 용어 정리

강의에서 다음 표현들은 같은 대상을 가리키는 문맥으로 사용된다.

```text
Input Variable
Independent Variable
Predictor
Feature
x
```

그리고

```text
Output Variable
Dependent Variable
Response Variable
Target
Label
y
```

로 이해할 수 있다.

---

# 51. Multiple Linear Regression Model

Feature가 `p`개라면 선형식은

`y = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ + ε`

가 된다.

각 Feature마다 하나의 Coefficient가 존재한다.

---

# 52. Multiple Regression에서 학습하는 값

우리가 학습해야 하는 Parameter는

```text
β₀
β₁
β₂
...
βₚ
```

이다.

이들을

- Regression Coefficients
    
- Parameters
    

라고 부른다.

즉 선형회귀에서 **학습 대상은 β들**이다.

---

# 53. Multiple Regression Coefficient 해석

예를 들어

`β₂`

가 Radio 광고비에 해당한다고 하자.

그 의미는 기본적으로

> **다른 모든 Feature를 고정했을 때 Radio 광고비 `x₂`를 1 unit 증가시키면 y가 평균적으로 β₂만큼 변한다.**

는 것이다.

이때 매우 중요한 표현은

> **다른 변수들을 모두 고정했을 때**

이다.

---

# 54. 왜 여러 Feature를 따로따로 분석하지 않는가?

Multiple Linear Regression은

```text
x₁과 y 따로
x₂와 y 따로
x₃와 y 따로
```

분석하는 것이 아니다.

모든 Feature를

```text
y = β₀ + β₁x₁ + β₂x₂ + β₃x₃ + ...
```

하나의 Model 안에 동시에 넣는다.

그래야 다른 Feature의 영향을 고려한 상태에서 각 Coefficient를 해석할 수 있다.

---

# 55. Multiple Regression에서도 Residual 정의는 동일하다

i번째 Data Point에서

`eᵢ = yᵢ - ŷᵢ`

이다.

다만 Prediction이

`ŷᵢ = β̂₀ + β̂₁xᵢ1 + β̂₂xᵢ2 + ... + β̂ₚxᵢp`

로 확장될 뿐이다.

Residual의 개념 자체는 변하지 않는다.

---

# 56. Multiple Regression에서도 목표는 RSS 최소화

여전히

`RSS = Σ(yᵢ - ŷᵢ)²`

를 최소화한다.

달라진 것은 Parameter가

```text
β₀, β₁
```

두 개에서

```text
β₀, β₁, β₂, ..., βₚ
```

여러 개로 늘어난 것뿐이다.

핵심 원리는 동일하다.

---

# 57. Feature가 2개면 직선이 아니라 평면

Feature가 하나일 때:

```text
x → y
```

이므로 Regression Model은 직선이었다.

Feature가 두 개라면

```text
(x₁, x₂) → y
```

가 되어 3D 공간의 **Plane**으로 표현된다.

```text
Simple Linear Regression
→ Line

Multiple Linear Regression
→ Plane / Hyperplane
```

---

# 58. 결국 다중 선형회귀도 같은 문제다

겉으로는 식이 길어져 복잡해 보이지만 본질은 동일하다.

```text
여러 Input Feature
       ↓
Linear Hyperplane
       ↓
각 Data와 Hyperplane 사이 Residual
       ↓
Residual² 합
       ↓
RSS 최소
       ↓
β₀...βₚ 학습
```

즉

> **여러 입력변수를 동시에 고려하면서 Data에 가장 가까운 Linear Hyperplane을 찾는 문제**

다.

---

# 59. Matrix 표현이 등장하는 이유

Feature와 Data가 많아지면

```text
β₀ + β₁x₁ + β₂x₂ + ...
```

를 Data마다 계속 적는 것이 불편하다.

그래서 전체 Dataset을 Matrix와 Vector로 묶는다.

---

# 60. y Vector

관측 Target이

```text
y₁
y₂
...
yₙ
```

이라면 이를 하나의 Vector로 묶을 수 있다.

```text
y =
[y₁
 y₂
 ...
 yₙ]
```

---

# 61. Design Matrix X

각 Data Point의 Feature들을 행으로 배치한다.

Intercept `β₀`까지 표현하기 위해 첫 번째 column에 `1`을 추가한다.

개념적으로

```text
X =

[1  x₁₁ x₁₂ ... x₁ₚ
 1  x₂₁ x₂₂ ... x₂ₚ
 ...
 1  xₙ₁ xₙ₂ ... xₙₚ]
```

로 표현한다.

---

# 62. Parameter Vector β

Parameter들도 Vector로 묶는다.

```text
β =

[β₀
 β₁
 β₂
 ...
 βₚ]
```

---

# 63. Multiple Linear Regression을 한 줄로 표현

이제 긴 식을

`y = Xβ + ε`

처럼 한 줄로 표현할 수 있다.

강의에서 강조하는 점은

> **Matrix 표현은 새로운 계산 원리가 아니라 기존 식을 간단하게 묶어서 표현한 것**

이라는 것이다.

---

# 64. Matrix로 표현해도 RSS 원리는 같다

Prediction은

`ŷ = Xβ̂`

로 생각할 수 있다.

Residual Vector는

`y - Xβ̂`

이다.

그리고 RSS는 이 Residual들의 제곱합이다.

즉 Matrix 표현으로 바뀌어도

> **관측 y와 예측 ŷ의 차이를 최소화한다.**

는 본질은 완전히 동일하다.

---

# 65. Matrix에서도 β에 대한 2차식

RSS를 Matrix로 표현해 전개해도 결국 `β`에 대한 2차식이다.

따라서 똑같이

```text
RSS를 β에 대해 미분
       ↓
Derivative = 0
       ↓
β의 해 계산
```

을 할 수 있다.

겉보기 식은 복잡해졌지만 원리는 Simple Linear Regression과 같다.

---

# 66. Multiple Linear Regression의 Closed-form Solution

강의에서는 Matrix 계산을 이용하면 β의 Estimate를 한 번에 계산할 수 있는 **Closed-form Solution**이 존재한다고 설명한다.

이 부분은 수학적으로 어려울 수 있으므로 식 자체를 암기하기보다

> **Linear Regression은 RSS가 β에 대한 2차식이기 때문에 미분하여 0이 되는 점을 풀면 β를 직접 계산할 수 있다.**

는 구조를 이해하는 것이 핵심이다.

---

# 67. Closed-form의 의미

Closed-form Solution은 반복해서 조금씩 Parameter를 바꾸는 것이 아니라

```text
Data X, y
     ↓
공식에 대입
     ↓
β̂ 계산
```

처럼 한 번의 수학적 계산으로 해를 얻는 방식이다.

이후 Gradient Descent와 비교하면 더 명확해진다.

---

# 68. Multiple Regression 결과 시각화

Feature가 두 개라면 모델은 Plane으로 표현할 수 있다.

Feature가 세 개 이상이라면 사람이 그대로 시각화할 수는 없지만 수학적으로는 더 높은 차원의 **Hyperplane**이다.

결국 각각의 `β`가 그 Hyperplane의 방향과 형태를 결정한다.

---

# 69. TV + Radio + Newspaper 예

강의에서는

- TV
    
- Radio
    
- Newspaper
    

세 광고비를 동시에 넣은 Multiple Linear Regression 예제를 설명한다.

각 Feature마다

- Coefficient
    
- Standard Error
    
- t-statistic
    
- p-value
    

가 계산된다.

---

# 70. Multiple Regression의 p-value 해석

예를 들어 TV와 Radio는 p-value가 매우 작고 Newspaper는 상대적으로 크다고 하자.

강의에서는 이를

```text
TV
→ 유의한 관계

Radio
→ 유의한 관계

Newspaper
→ 현재 Model과 Data에서는
   유의하다고 보기 어려울 수 있음
```

이라는 방식으로 해석한다.

중요한 것은 Coefficient 숫자의 크기나 Positive/Negative 여부만 보는 것이 아니다.

---

# 71. Negative Coefficient = 나쁜 Feature인가?

아니다.

Coefficient가 Negative라고 해서

> “이 Feature는 나쁘다.”

라는 뜻이 아니다.

Negative는 단지

> **다른 조건이 동일할 때 x가 증가할수록 y가 감소하는 방향의 관계**

를 나타낸다.

“좋다/나쁘다”라는 가치판단과는 다른 문제다.

---

# 72. 작은 Coefficient = 중요하지 않음도 아니다

마찬가지로 Coefficient가 `0.001`처럼 작다고 해서 무조건 중요하지 않은 Feature라고 판단할 수 없다.

Coefficient와 Standard Error의 관계를 보고 t-statistic 및 p-value를 해석해야 한다.

강의에서는 이 **상대적 해석**을 다시 강조한다.

---

# 73. Multiple Regression의 R²

TV 하나만 사용했을 때보다

```text
TV
Radio
Newspaper
```

를 함께 사용했을 때 강의 예제에서는 R²가 약 `0.897` 수준으로 증가한다.

강의에서는 약 0.9에 가까운 매우 높은 설명력으로 해석한다.

즉 여러 Feature를 함께 사용함으로써 y의 Variability를 훨씬 더 많이 설명할 수 있게 된 예다.

---

# 74. 하지만 Training R²만 보고 끝내면 안 된다

매우 중요한 주의점이다.

지금까지 계산한

- RSS
    
- Coefficient
    
- R²
    

등은 현재 Training Data에서 나온 결과다.

Training Data에서 설명력이 높다고 해서 새로운 Data에서도 반드시 잘한다는 보장은 없다.

따라서 앞 강의에서 배운 Generalization 평가가 다시 필요하다.

---

# 75. 새로운 Data에서도 검증해야 한다

가능하다면

```text
Test Data
```

에서 성능을 평가한다.

충분한 Test Data가 없다면 앞 차시에서 배운

```text
Cross Validation
```

을 이용한다.

즉 선형회귀라고 해서 Generalization 원칙이 달라지는 것은 아니다.

```text
Training에서 잘함
        ≠
좋은 Model 확정

새로운 Data에서도 잘함
        ↓
Good Model
```

---

# 76. Multiple Linear Regression의 중요한 문제 — Feature 간 Correlation

여러 Feature가 있을 때 Feature끼리 서로 강하게 관련되어 있을 수 있다.

예:

```text
x₁ 증가할 때
x₂도 거의 항상 함께 증가
```

하는 경우다.

이런 상황에서는 각 Coefficient를 독립적으로 해석하기 어려워질 수 있다.

---

# 77. 왜 Coefficient 해석이 어려워지는가?

Multiple Regression에서 `β₂`는

> **다른 모든 Feature를 고정한 채 x₂만 1 증가했을 때의 y 변화**

라고 해석했다.

그런데 실제 Data에서 x₁과 x₂가 항상 함께 움직인다면

```text
x₁ 고정
+
x₂만 변화
```

라는 상황 자체를 Data에서 분리하기 어려워진다.

따라서 β의 개별 해석이 불안정하거나 어려워질 수 있다.

---

# 78. 분석 전에 Feature 간 Correlation 확인

강의에서는 여러 변수들이 서로 함께 움직이는지 확인하기 위해 Feature 간 **Correlation**을 계산해보는 것이 중요하다고 설명한다.

즉 Multiple Linear Regression에서는

```text
Feature ↔ Target
```

뿐 아니라

```text
Feature ↔ Feature
```

관계도 확인할 필요가 있다.

이 문제는 이후 **Multicollinearity(다중공선성)** 와 연결된다.

---

# 79. 매우 중요 — Correlation은 Causation이 아니다

선형회귀에서 매우 중요한 주의점이다.

Regression을 수행해서 x와 y 사이에 강한 관계가 발견됐다고 하더라도

> **x가 y의 원인이다.**

라고 바로 결론 내리면 안 된다.

선형회귀에서 관찰한 것은 기본적으로 **데이터상 관계/상관 구조**다.

---

# 80. 아이스크림과 상어 공격 예

강의에서는 대표적인 예를 든다.

### x

아이스크림 소비량

### y

상어에게 물리는 사건 수

두 값으로 Regression을 수행하면 Positive한 관계가 나타날 수 있다.

그러면

> “아이스크림을 많이 먹으면 상어에게 물린다.”

라고 결론 내려도 될까?

아니다.

---

# 81. 숨겨진 변수 — 여름

두 값이 동시에 증가하는 다른 요인이 존재할 수 있다.

```text
여름
├─ 아이스크림 소비 ↑
└─ 해변 방문 ↑
       ↓
   상어 사고 가능성 ↑
```

즉 실제 관계를 설명하는 제3의 요인이 존재한다.

따라서

```text
아이스크림 소비 ↑
↔
상어 사고 ↑
```

라는 Correlation이 있다고 해서

```text
아이스크림 소비
→ 상어 사고
```

라는 Causation을 의미하는 것은 아니다.

---

# 82. 선형회귀의 전체 학습 구조

```text
Training Data
(xᵢ, yᵢ)
       ↓
Linear Hypothesis Space 설정
       ↓
ŷᵢ = β̂₀ + β̂₁xᵢ
       ↓
Residual
eᵢ = yᵢ - ŷᵢ
       ↓
Residual 제곱
       ↓
모든 Data 합산
       ↓
RSS
       ↓
RSS를 최소화하는
β̂₀, β̂₁ 탐색
       ↓
Least Squares Solution
       ↓
학습된 Regression Line
       ↓
Coefficient / p-value / R² 해석
       ↓
Test / Cross Validation으로
Generalization 확인
```

---

# 83. Simple Linear Regression 핵심 구조

```text
Model

y = β₀ + β₁x + ε

Prediction

ŷ = β̂₀ + β̂₁x

Residual

e = y - ŷ

Objective

RSS = Σe²

Learning

RSS를 최소화하는
β̂₀, β̂₁ 찾기
```

---

# 84. Multiple Linear Regression 핵심 구조

```text
y
=
β₀
+ β₁x₁
+ β₂x₂
+ ...
+ βₚxₚ
+ ε
```

Prediction:

```text
ŷ
=
β̂₀
+ β̂₁x₁
+ β̂₂x₂
+ ...
+ β̂ₚxₚ
```

목표:

```text
Σ(yᵢ - ŷᵢ)²
```

를 최소화하는 모든 `β̂`를 찾는 것.

---

# 85. Simple vs Multiple Linear Regression

|항목|Simple|Multiple|
|---|---|---|
|Feature 수|1개|2개 이상|
|2D 시각화|직선|Feature 2개라면 평면|
|학습 Parameter|β₀, β₁|β₀, β₁ … βₚ|
|학습 목표|RSS 최소화|RSS 최소화|
|기본 원리|동일|동일|

---

# 86. ε와 Residual 다시 구분

|구분|ε|Residual e|
|---|---|---|
|관계|True Function ↔ 관측 y|Estimated Model ↔ 관측 y|
|True Function 필요|필요|필요 없음|
|직접 계산|불가능|가능|
|학습 대상|아님|Loss 계산에 사용|
|이상적인 경우|Model이 완벽해도 존재|Model이 f*에 가까워질수록 감소 가능|

# 87. RSS와 MSE 관계

앞 강의에서 MSE를 배웠다.

```text
RSS
= Residual²을 모두 더한 값

MSE
= Residual²을 모두 더한 뒤 평균
```

즉 두 값 모두 **Squared Error**를 이용한다.

Model Parameter를 어떤 방향으로 선택할지 판단하는 핵심 아이디어는 동일하다.

---

# 88. 자주 헷갈리는 점 ① — 선형회귀는 x와 y가 직선 위에 있어야 하는가?

아니다.

선형회귀에서는 평균적인 관계를 Linear Function으로 모델링한다.

실제 Data Point는 Noise `ε` 때문에 직선 주변에 흩어질 수 있다.

---

# 89. 자주 헷갈리는 점 ② — 학습된 직선이 True Function인가?

모른다.

우리가 가지고 있는 것은 Sample Data뿐이다.

따라서 학습된 직선은

> **현재 Data를 기반으로 True Function을 추정한 Model**

이다.

True Function 자체를 직접 확인할 수는 없다.

---

# 90. 자주 헷갈리는 점 ③ — Residual = ε인가?

아니다.

```text
ε
True Function과 Data 차이

Residual
Estimated Function과 Data 차이
```

다.

둘을 반드시 구분해야 한다.

---

# 91. 자주 헷갈리는 점 ④ — Coefficient가 작으면 관계가 약한가?

아니다.

Coefficient의 크기는 단위에 영향을 받는다.

따라서 숫자 자체만 가지고 관계 강도를 판단하면 안 된다.

---

# 92. 자주 헷갈리는 점 ⑤ — p-value가 작으면 Coefficient가 큰가?

반드시 그렇지 않다.

p-value는 Coefficient를 Standard Error와 함께 고려한 결과다.

```text
Coefficient
상대적으로 큼

Standard Error
상대적으로 작음

→ |t| 큼
→ p-value 작아질 가능성
```

처럼 상대적인 구조로 이해해야 한다.

---

# 93. 자주 헷갈리는 점 ⑥ — p-value가 작으면 Model 예측력이 무조건 좋은가?

강의에서 p-value는 주로

> 해당 Coefficient가 0과 다른 관계를 가진다고 볼 통계적 근거

를 해석하는 데 사용한다.

Model의 전체 Prediction 성능은 별도로

- R²
    
- Test Error
    
- Cross Validation
    

등을 확인해야 한다.

---

# 94. 자주 헷갈리는 점 ⑦ — R²가 높으면 실제 서비스에서도 무조건 좋나?

아니다.

Training Data에서 계산한 R²일 수 있기 때문이다.

새로운 Data에서의 Generalization 성능은 Test Set이나 Cross Validation으로 확인해야 한다.

---

# 95. 자주 헷갈리는 점 ⑧ — Feature가 여러 개면 각각 따로 Linear Regression을 하면 같은가?

아니다.

Multiple Linear Regression은 여러 Feature를 하나의 Model에 **동시에** 넣는다.

각 Coefficient는 다른 Feature를 함께 고려한 상태에서 해석된다.

---

# 96. 자주 헷갈리는 점 ⑨ — Negative Coefficient는 나쁜 변수인가?

아니다.

단지 x 증가와 y 변화 방향이 Negative라는 뜻이다.

그 Feature가 Business적으로 좋은지 나쁜지는 별개의 해석이다.

---

# 97. 자주 헷갈리는 점 ⑩ — Correlation이 있으면 Causation인가?

아니다.

숨겨진 제3 변수나 기타 구조 때문에 두 변수가 함께 움직일 수 있다.

Regression 결과를 그대로 인과관계라고 해석해서는 안 된다.

---

# 98. 앞선 AI & 기계학습 기초 강의와 연결

## 기초 1차시

```text
y = f*(x) + ε
```

라는 Machine Learning의 기본 구조를 배웠다.

이번에는 `f*`를 Linear하다고 가정한다.

```text
f*(x)
=
β₀ + β₁x
```

---

## 기초 2차시

Regression에서는 숫자를 Prediction하고 대표적으로 Squared Error를 사용한다고 배웠다.

이번에는 실제로

```text
Residual
→ Residual²
→ RSS
→ 최소화
```

를 이용해 Linear Model을 학습한다.

---

## 기초 3차시

Training Data에서 잘하는 것만으로는 부족하다고 배웠다.

따라서 Linear Regression도 최종적으로 Test Set이나 Cross Validation을 이용해 Generalization을 확인해야 한다.

# 100. 이번 강의에서 반드시 기억할 핵심

### 1. Linear Regression은 숫자를 예측하는 지도학습 Regression이다.

### 2. Linear Regression을 선택한다는 것은 Linear Hypothesis Space를 선택하는 것이다.

### 3. Simple Linear Regression은 Feature가 하나다.

### 4. 기본 Model은

`y = β₀ + β₁x + ε`

이다.

### 5. `β₀`는 절편, `β₁`은 기울기다.

### 6. 실제 Data와 Prediction의 차이를 Residual이라고 한다.

`eᵢ = yᵢ - ŷᵢ`

### 7. Residual과 ε는 다른 개념이다.

### 8. 모든 Residual²의 합이 RSS다.

### 9. Linear Regression 학습은 RSS를 최소화하는 β를 찾는 문제다.

### 10. RSS가 β에 대한 2차식이므로 미분값이 0인 최소점을 이용해 해를 구할 수 있다.

### 11. Hat이 붙은 β는 True Parameter가 아니라 Estimate다.

### 12. p-value는 Coefficient 숫자 자체가 아니라 Standard Error와의 상대적 관계까지 고려한다.

### 13. Coefficient의 크기는 단위 영향을 받으므로 숫자만 보고 관계의 강도를 판단하면 안 된다.

### 14. Multiple Linear Regression은 Feature가 여러 개다.

### 15. Multiple Regression에서 βⱼ는 다른 Feature들을 고정했을 때 xⱼ가 1 증가할 때의 평균적인 y 변화량으로 해석한다.

### 16. Matrix 표현은 기존 Multiple Regression 식을 간결하게 나타낸 것이다.

### 17. Training R²가 높다고 끝이 아니다. Test / Cross Validation으로 Generalization을 확인해야 한다.

### 18. Feature끼리 높은 Correlation이 있으면 개별 Coefficient 해석이 어려워질 수 있다.

### 19. Regression은 관계를 보여주지만 자동으로 인과관계를 증명하지 않는다.

# 102. 이번 강의의 핵심 한 문장

> **선형회귀는 Feature와 숫자 Target 사이의 관계가 선형이라고 가정하고, 관측값과 예측값 사이의 잔차제곱합 RSS를 최소화하는 회귀계수 β를 찾아 직선 또는 Hyperplane을 학습하는 방법이다.**

그리고 앞선 강의까지 연결하면 다음과 같다.

> **우리가 직접 볼 수 없는 참함수 `f*`를 선형 함수라고 가정한 뒤, 관측 Data만을 이용해 그 함수의 기울기와 절편을 최소제곱법으로 추정하는 것이 선형회귀의 본질이다.**
