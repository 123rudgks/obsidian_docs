# 0. 강의 전체 개요

이번 강의에서는 **Neural Network(신경망)** 의 가장 기본적인 원리를 다룬다.

앞에서

```text
Linear Regression
        ↓
Logistic Regression
```

으로 모델을 확장했다면, 이번에는 이를 더 일반적인 함수 표현으로 확장한다.

전체 흐름은 다음과 같다.

```text
Linear Model
      ↓
Parameter와 Loss
      ↓
Shallow Neural Network
      ↓
여러 Linear Function
      ↓
Activation Function
      ↓
ReLU
      ↓
Hidden Unit
      ↓
Weighted Sum
      ↓
Piecewise Linear Function
      ↓
Hidden Unit 증가
      ↓
표현력 증가
      ↓
Universal Approximation
      ↓
다차원 Input / Output
      ↓
Deep Neural Network
      ↓
Shallow Network들의 합성
      ↓
같은 Parameter 수로
더 높은 표현 효율성
      ↓
Layer 단위
Matrix / Vector 표현
```

이번 강의의 가장 중요한 메시지는 다음과 같다.

> **신경망은 정체를 알 수 없는 특별한 함수가 아니라, Linear Mapping → Activation → Linear Combination을 반복적으로 합성한 함수다.**

---

# 1. 앞선 선형 모델에서 출발한다

앞서 Linear Regression에서는

```text
Input x
   ↓
Linear Function
   ↓
Prediction ŷ
```

이라는 모델을 사용했다.

Function은 기울기와 절편 같은 **Parameter**로 결정됐다.

예를 들어

`f(x) = wx + b`

처럼 생각할 수 있다.

여기서

- `w` = Weight / 기울기
    
- `b` = Bias / 절편
    

이다.

강의에서는 이전의 `β` 표기를 신경망에서는 다른 Parameter 기호로 바꾸어 표현하지만 본질적으로는 동일한 개념이라고 설명한다.

---

# 2. Parameter를 학습한다는 것

Linear Regression에서도 결국 우리가 학습한 것은

```text
기울기
절편
```

이었다.

즉 Parameter를 조정하여 Loss를 줄였다.

개념적으로

```text
초기 Parameter
      ↓
좋지 않은 Linear Function
      ↓
Loss 큼
      ↓
Parameter 수정
      ↓
더 나은 Function
      ↓
Loss 감소
```

의 과정이다.

---

# 3. Closed-form뿐 아니라 반복적인 학습도 가능하다

앞 강의에서는 Linear Regression의 Parameter를 **Closed-form Solution**으로 한 번에 계산할 수 있다고 배웠다.

하지만 Parameter를 처음부터 적절하게 정하지 않고

```text
Initial Parameter
      ↓
조금 수정
      ↓
Loss 감소
      ↓
다시 수정
      ↓
...
```

처럼 반복해서 최적점으로 이동할 수도 있다.

이 방식은 이후 Gradient Descent에서 본격적으로 다룬다.

---

# 4. Loss Surface의 직관

Linear Regression의 Squared Loss는 Parameter에 대한 2차 함수 형태로 생각할 수 있다.

따라서 개념적으로 그릇과 같은 Loss Surface가 만들어진다.

```text
Loss
 ↑
 │      \       /
 │       \     /
 │        \___/
 │          ↑
 │       최소점
 └──────────────→ Parameter
```

학습은 이 최소점에 해당하는 Parameter를 찾는 과정이다.

---

# 5. Neural Network로 확장

이번에는 Linear Function 하나에서 더 복잡한 구조로 확장한다.

가장 먼저 **Shallow Neural Network**를 살펴본다.

강의에서는

> **Hidden Layer가 하나인 Neural Network**

를 Shallow Network라고 정의한다.

---

# 6. Shallow Neural Network의 기본 구조

가장 기본적인 구조는

```text
Input
  ↓
Hidden Layer
  ↓
Output Layer
```

이다.

Hidden Layer 안에는 여러 개의 **Hidden Unit**이 존재할 수 있다.

즉

```text
Hidden Layer 수 = 1

Hidden Unit 수 = 여러 개 가능
```

이다.

이 두 개를 혼동하면 안 된다.

---

# 7. Shallow와 Deep의 구분

강의 기준:

```text
Hidden Layer = 1
→ Shallow Neural Network

Hidden Layer ≥ 2
→ Deep Neural Network
```

즉 Unit 개수가 많다고 Deep인 것은 아니다.

```text
Hidden Layer 1개
Hidden Unit 100개
```

여도 여전히 **Shallow Network**다.

---

# 8. Shallow Network도 복잡한 함수를 표현할 수 있다

Shallow Network라고 해서 단순한 Linear Function만 표현하는 것은 아니다.

Activation Function을 사용하면 **Non-linear Pattern**을 학습할 수 있다.

따라서 비교적 간단한

- Regression
    
- Classification
    

문제에서도 사용할 수 있다.

---

# 9. Shallow Network의 내부를 뜯어보자

겉으로 보면 Neural Network의 식이 복잡해 보인다.

하지만 하나씩 분해하면 각 Hidden Unit 내부에는 기본적으로

`wx + b`

와 같은 Linear Function이 들어 있다.

예를 들어 Hidden Unit이 3개라면

```text
z₁ = w₁x + b₁
z₂ = w₂x + b₂
z₃ = w₃x + b₃
```

처럼 각각 다른 Weight와 Bias를 가진 Linear Function을 만든다.

---

# 10. 각 Linear Function은 서로 다른 Parameter를 가진다

각 Unit에서 사용하는

```text
w₁, b₁
w₂, b₂
w₃, b₃
```

는 서로 다른 값이다.

따라서 같은 Input `x`가 들어가도 서로 다른 Linear Function이 만들어진다.

```text
Input x
 ├─ Linear Function 1
 ├─ Linear Function 2
 └─ Linear Function 3
```

---

# 11. 그런데 Linear Function만 여러 개 쌓으면 충분한가?

아니다.

여기서 매우 중요한 것이 등장한다.

> **Activation Function**

이다.

강의에서는 이를 `A`라는 함수로 먼저 표현한 뒤 대표적으로 **ReLU**를 설명한다.

---

# 12. Activation Function

Activation Function은 Linear Function의 결과를 받아 새로운 값으로 변환한다.

```text
x
 ↓
wx + b
 ↓
Activation
 ↓
Hidden Unit Output
```

즉 Hidden Unit 하나는 크게

```text
Linear Mapping
+
Activation
```

으로 구성된다.

---

# 13. ReLU

이번 강의에서 대표적으로 사용하는 Activation Function은 **ReLU(Rectified Linear Unit)** 다.

개념적으로

```text
z ≥ 0
→ z 그대로 출력

z < 0
→ 0 출력
```

한다.

즉

`ReLU(z) = max(0, z)`

로 이해할 수 있다.

---

# 14. ReLU의 그래프

```text
Output
  ↑
  │        /
  │       /
  │      /
──┼─────/────────→ z
  │
  └────── 0
```

Negative 영역은 모두 0으로 만들고 Positive 영역은 그대로 통과시킨다.

---

# 15. Neural Network라는 이름

강의에서는 ReLU가

```text
활성화된 경우
→ 값을 전달

활성화되지 않은 경우
→ 0
```

처럼 작동하는 구조를 인간 뇌의 Neuron에서 영감을 받은 부분과 연결한다.

따라서 이러한 함수를 **Activation Function**이라고 부른다.

---

# 16. Activation Function은 학습 Parameter인가?

강의에서 구분한다.

```text
Weight / Bias
→ Parameter
→ 학습 대상

ReLU 같은 Activation Function 자체
→ Parameter가 아님
```

즉 Parameter 값은 Training을 통해 바뀌지만 ReLU의 기본 규칙 자체는 고정되어 있다.

---

# 17. Neural Network에서 학습하는 것은 Parameter

Neural Network에서도 본질은 기존 Model과 동일하다.

```text
Training Data
      ↓
Prediction
      ↓
Loss 계산
      ↓
Parameter 수정
      ↓
Loss 감소
```

따라서 Weight와 Bias들이 모두 **학습 대상**이다.

강의 예제에서는 Shallow Network 안에 여러 Parameter가 존재하며, 이 Parameter 조합에 따라 전체 Function의 모양이 달라진다.

---

# 18. Parameter가 달라지면 Function도 달라진다

같은 Network Architecture라도 Parameter 값이 다르면

```text
Function A
Function B
Function C
```

처럼 서로 다른 함수를 표현한다.

즉 Architecture는 함수의 **형식/가설 공간**을 정의하고 Parameter는 그 안에서 **구체적인 함수 하나**를 결정한다.

---

# 19. Shallow Network는 비선형 함수를 만들 수 있다

실제로 여러 Linear Function에 ReLU를 적용하고 합치면 결과는 더 이상 하나의 직선이 아니다.

```text
     /
 ___/
     \___
         \
```

처럼 여러 번 꺾인 형태가 만들어질 수 있다.

즉 전체 Network는 **Non-linear Function**이다.

---

# 20. Piecewise Linear Function

ReLU 기반 Neural Network의 Output은 강의에서 **Piecewise Linear Function**으로 설명된다.

Piecewise Linear란

> 전체적으로는 하나의 직선이 아니지만 각각의 구간을 따로 보면 Linear한 함수

다.

```text
   /        ← Linear Piece
__/
  \__       ← Linear Piece
     \      ← Linear Piece
```

즉 여러 Linear Piece가 이어진 함수다.

---

# 21. 왜 꺾이는가?

중요하다.

Linear Function 자체가 꺾임을 만드는 것이 아니다.

ReLU가 Negative 영역을 0으로 잘라내면서 꺾이는 지점이 만들어진다.

```text
Linear Function
       ↓
ReLU
       ↓
Negative 영역 제거
       ↓
Kink 생성
       ↓
Piecewise Linear
```

따라서 강의는

> **Neural Network에서 Non-linearity를 만드는 핵심이 Activation Function이다.**

라고 설명한다.

---

# 22. Hidden Unit

각각의

```text
Linear Mapping
↓
Activation
```

결과를 하나의 **Hidden Unit**으로 묶어 생각한다.

예:

```text
h₁ = ReLU(w₁x + b₁)
h₂ = ReLU(w₂x + b₂)
h₃ = ReLU(w₃x + b₃)
```

여기서

`h₁, h₂, h₃`

가 Hidden Unit이다.

---

# 23. Hidden Unit 하나의 계산은 매우 단순하다

Hidden Unit 하나를 보면

```text
① Linear Function 계산
② Activation 적용
```

뿐이다.

즉 복잡한 고차식 하나를 직접 계산하는 것이 아니다.

매우 단순한 Operation들을 여러 개 조합한다.

---

# 24. 같은 Input이 여러 Hidden Unit으로 전달된다

Input `x`가 들어오면 동일한 `x`가 여러 Hidden Unit으로 전달된다.

```text
             ┌→ w₁x+b₁ → ReLU → h₁
x ───────────┼→ w₂x+b₂ → ReLU → h₂
             └→ w₃x+b₃ → ReLU → h₃
```

각 Unit은 서로 다른 Parameter를 가지므로 서로 다른 Linear Mapping을 만든다.

---

# 25. ReLU가 각 Linear Function을 꺾는다

각 Linear Function에 ReLU를 적용하면 Negative 부분이 사라진다.

```text
Linear
     /
────/

ReLU 후
____/
```

각 Hidden Unit마다 Weight와 Bias가 다르므로 꺾이는 위치와 기울기도 서로 달라질 수 있다.

---

# 26. Hidden Unit에 다시 Weight를 곱한다

각 Hidden Unit의 결과에는 Output으로 가기 전에 또 다른 Weight가 적용될 수 있다.

예:

```text
v₁h₁
v₂h₂
v₃h₃
```

`v`가 Positive이면 방향을 유지하고 Negative이면 뒤집힐 수 있다.

절댓값이 크면 증폭되고 작으면 축소된다.

---

# 27. 마지막으로 모두 더한다

최종 Output은 이러한 Hidden Unit들을 Weighted Sum하여 만든다.

개념적으로

`y = v₀ + v₁h₁ + v₂h₂ + v₃h₃`

처럼 생각할 수 있다.

전체 과정은

```text
x
↓
여러 Linear Mapping
↓
ReLU
↓
각 Hidden Unit에 Weight
↓
모두 합산
↓
Output
```

이다.

---

# 28. 이것이 Shallow Neural Network의 본질

강의가 반복적으로 강조하는 구조는 다음이다.

> **Linear → Activation → Weighted Sum**

즉 굉장히 복잡해 보이는 Network도 실제로는

```text
1차 계산
Activation
상수배
합산
```

을 수행하고 있다.

---

# 29. Neural Network Diagram

이를 일반적인 Network Diagram으로 표현하면

```text
Input
   │
   ├────→ Hidden Unit 1 ──┐
   ├────→ Hidden Unit 2 ──┼──→ Output
   └────→ Hidden Unit 3 ──┘
```

가 된다.

그림에서는 Bias를 생략하는 경우가 많지만 실제 Model에는 Bias가 존재한다고 이해해야 한다.

---

# 30. Hidden Unit 수와 표현력

Hidden Unit 하나는 ReLU를 통해 하나의 꺾임을 만들어낼 수 있다.

따라서 1차원 강의 예제에서는 Hidden Unit이 증가할수록 표현할 수 있는 Piecewise Linear Region 역시 증가한다.

예:

```text
Hidden Unit 1개
→ 꺾임 1개

Hidden Unit 3개
→ 여러 꺾임

Hidden Unit 증가
→ 더 세밀한 Piecewise Function
```

---

# 31. Hidden Unit을 늘리는 이유

더 많은 Hidden Unit을 사용하면 더 많은 Linear Piece를 조합할 수 있다.

따라서 복잡한 Target Function을 더 정밀하게 근사할 수 있다.

```text
Units 적음
→ 표현력 낮음

Units 많음
→ Piece 증가
→ 표현력 증가
```

---

# 32. Universal Approximation Theorem

이와 연결되는 중요한 개념이 **Universal Approximation Theorem(보편 근사 정리)** 이다.

강의에서는

> Hidden Unit을 충분히 많이 사용하면 Shallow Neural Network도 임의의 연속 함수를 원하는 수준으로 근사할 수 있다.

는 핵심 직관으로 설명한다.

---

# 33. 매우 중요 — Shallow Network가 Linear Model이라는 뜻은 아니다

각 Piece가 Linear하다고 해서 전체 Function이 하나의 Linear Function인 것은 아니다.

```text
각 구간
→ Linear

전체
→ Non-linear Piecewise Function
```

이다.

따라서

> “1차 함수 여러 개를 사용했으니 Neural Network도 Linear다.”

라고 이해하면 안 된다.

---

# 34. Deep해야만 복잡한 함수를 표현할 수 있는가?

강의에서는 이것도 오해라고 설명한다.

Shallow Network도 충분히 많은 Hidden Unit이 있다면 복잡한 Function을 근사할 수 있다.

따라서

```text
Deep Network만 복잡한 함수 표현 가능
```

이라는 말은 강의의 설명과 다르다.

Deep Network의 핵심 장점은 뒤에서 **표현 효율성**으로 연결된다.

---

# 35. Output Dimension 확장

지금까지 Output이 하나라고 가정했다.

하지만 Output이 여러 개일 수도 있다.

예:

```text
Hidden Units
   ├→ y₁
   └→ y₂
```

이때 Hidden Layer 자체를 다시 만들 필요는 없다.

Hidden Representation을 공유하면서 Output마다 다른 Weight를 적용하면 된다.

---

# 36. 여러 Output에서 Hidden Unit은 공유된다

같은 Hidden Unit을 사용하기 때문에 ReLU에 의해 만들어진 구조적 꺾임은 공유된다.

하지만 마지막 Output Weight가 다르므로 최종적으로

```text
Output 1의 Function
Output 2의 Function
```

은 서로 다른 값을 가진다.

---

# 37. Input Dimension도 늘릴 수 있다

Input이 하나일 필요도 없다.

기존에는

`wx + b`

였다면 Input이 여러 개일 경우

`w₁x₁ + w₂x₂ + ... + b`

가 된다.

즉 Activation 전의 Linear Mapping이 **Multiple Linear Regression과 같은 Linear Function**으로 확장되는 것이다.

---

# 38. Pre-activation

Activation Function을 통과하기 전의 값을 **Pre-activation**이라고 한다.

예를 들어

`z = w₁x₁ + w₂x₂ + b`

라면

```text
z
→ Pre-activation

h = ReLU(z)
→ Activation 후 Hidden Unit
```

이다.

---

# 39. Input이 2D라면 Linear Function은 Plane

Feature가

```text
x₁
x₂
```

두 개라면 Pre-activation의 Linear Function은 직선이 아니라 Plane이다.

```text
1D Feature
→ Line

2D Feature
→ Plane
```

이다.

---

# 40. 2D에서 ReLU를 적용하면

Plane의 값이 Negative인 영역은 모두 0이 된다.

따라서

```text
원래 Plane
       ↓
ReLU
       ↓
Negative 영역 → 평평한 0
Positive 영역 → 기존 Plane
```

이 된다.

즉 2D Input에서는 ReLU가 **Piecewise Planar Surface**를 만든다.

---

# 41. 여러 2D Hidden Unit을 합치면

각 Hidden Unit마다 서로 다른 Plane을 만들고 ReLU를 적용한다.

그 결과를 Weighting해서 합치면 매우 복잡한 Surface를 만들 수 있다.

하지만 각 Region 내부를 보면 여전히 Linear Plane이다.

즉

> **고차원에서도 ReLU Neural Network는 Piecewise Linear Structure를 만든다.**

---

# 42. Shallow Network의 일반화된 구조

Input Dimension과 Output Dimension이 몇 개이든 기본 구조는 같다.

```text
Input Vector
      ↓
Linear Mapping
      ↓
Activation
      ↓
Hidden Representation
      ↓
Linear Mapping
      ↓
Output Vector
```

즉 Dimension이 늘어나도 개념 자체는 달라지지 않는다.

---

# 43. 이제 Deep Neural Network로 확장한다

Shallow Network를 이해했으므로 Deep Network는 이를 여러 번 연결하면 된다.

강의에서는 먼저 두 개의 Shallow Network를 생각한다.

```text
Network 1
x → y

Network 2
y → y'
```

그리고 이 둘을 합성한다.

---

# 44. 두 Shallow Network의 합성

두 Function을

```text
y = f(x)

y' = g(y)
```

라고 한다면 전체 Network는

`y' = g(f(x))`

이다.

즉 **Composition Function(합성 함수)** 이다.

---

# 45. Deep Neural Network의 핵심은 합성

첫 번째 Network가 만든 Output이 두 번째 Network의 Input이 된다.

```text
x
↓
Network 1
↓
Hidden Representation
↓
Network 2
↓
Output
```

이것을 계속 연결하면

```text
f₃(f₂(f₁(x)))
```

처럼 여러 Function을 중첩할 수 있다.

---

# 46. 합성하면 Function이 더 복잡해진다

각 Shallow Network 자체가 Piecewise Linear Function이다.

그런데 이 Piecewise Function을 다시 다른 Piecewise Function의 Input으로 넣으면 Region이 더욱 세분화될 수 있다.

강의에서는 이를 종이를 접었다 다시 펼치는 것과 비슷한 구조적 직관으로 설명한다.

```text
Piecewise Function
      ↓
다시 Piecewise Function 적용
      ↓
Region이 더 세분화
      ↓
복잡한 Function
```

---

# 47. Depth가 증가하면 표현 영역이 빠르게 증가할 수 있다

강의의 예제에서는 비슷한 수의 Hidden Unit과 Parameter를 가지고도

```text
Shallow하게 배치
```

하는 경우보다

```text
여러 Layer로 나누어 합성
```

하는 경우가 더 많은 Piecewise Linear Region을 표현하는 사례를 보여준다.

강의 예제에서는 두 Shallow Network를 합성한 구조가 약 20개 Parameter로 16개의 Linear Region을 표현하는 반면, 비슷한 규모의 단일 Shallow Network는 더 적은 Region을 표현하는 비교를 제시한다.

---

# 48. Deep Network의 핵심 장점 — 표현 효율성

이것이 강의에서 강조하는 Deep Network의 핵심이다.

> **Shallow Network가 복잡한 함수를 표현할 수 없어서 Deep Network를 사용하는 것이 아니다.**

Shallow Network도 충분히 넓으면 복잡한 함수를 근사할 수 있다.

그러나 Deep Network는

> **비슷한 Parameter 수로 더 복잡한 함수를 효율적으로 표현할 수 있다.**

는 장점이 있다.

---

# 49. Width와 Depth

이 관점에서 Neural Network의 크기를 두 방향으로 생각할 수 있다.

### Width

한 Layer 안의 Hidden Unit 개수.

```text
Hidden Units ↑
→ Width ↑
```

### Depth

Hidden Layer의 개수.

```text
Hidden Layers ↑
→ Depth ↑
```

둘 모두 Network의 표현력과 관련 있지만 서로 다른 방식으로 표현력을 증가시킨다.

---

# 50. Shallow Network도 Width를 크게 하면 표현력이 증가한다

```text
Hidden Layer = 1
Hidden Units ↑↑↑
```

으로 만들면 매우 복잡한 Function을 표현할 수 있다.

이는 Universal Approximation과 연결된다.

---

# 51. Deep Network는 Composition을 이용한다

반면 Deep Network는

```text
Layer 1
↓
Layer 2
↓
Layer 3
↓
...
```

처럼 Function을 계속 합성한다.

그 결과 이전 Layer에서 만든 Representation을 다음 Layer가 다시 조합한다.

이것이 Depth가 가지는 중요한 의미다.

---

# 52. 고차원 Input에서도 같은 원리

Input이 하나일 때는 Piecewise Line으로 볼 수 있었다.

Input이 2개이면 Piecewise Plane이고, 더 높은 Dimension이면 고차원 Piecewise Linear Region으로 확장된다.

Deep Network에서도 이러한 Region이 합성을 거치면서 더 복잡하게 나뉜다.

---

# 53. Deep Network의 식이 복잡해 보이는 이유

Layer가 많아지고 Unit이 많아지면 모든 Scalar Weight를 하나씩 적는 것은 매우 복잡해진다.

하지만 Operation 자체가 복잡해진 것은 아니다.

각 Layer에서 반복되는 것은 기본적으로

```text
Linear Mapping
↓
Activation
```

뿐이다.

강의에서는 수식이 길어 보이는 것은 Parameter를 하나하나 적었기 때문이라고 설명한다.

---

# 54. Deep Network를 더 간단하게 표현하자

개별 Parameter를 전부

```text
w₁
w₂
w₃
...
```

처럼 적지 않고 Vector와 Matrix로 묶는다.

이렇게 하면 Network 구조를 훨씬 간단하게 표현할 수 있다.

---

# 55. Weight Matrix

한 Layer의 여러 Unit이 이전 Layer의 여러 Output을 동시에 입력받기 때문에 Weight들을 하나의 **Matrix**로 묶을 수 있다.

개념적으로

`Wx`

로 표현한다.

---

# 56. Bias Vector

각 Unit의 Bias 역시 하나씩 적지 않고 Vector로 묶을 수 있다.

`b`

라고 표현한다.

강의에서는 교재나 자료에 따라

- Weight를 `W`, `ω` 등
    
- Bias를 `b`, `β` 등
    

다른 기호로 표시할 수 있다고 설명한다.

중요한 것은 기호가 아니라 역할이다.

---

# 57. Layer 하나의 핵심 계산

한 Layer는 크게

`z = Wx + b`

를 계산한 뒤

`h = A(z)`

를 적용한다.

즉

```text
이전 Layer Output
      ↓
Weight Matrix 곱
      ↓
Bias Vector 더하기
      ↓
Pre-activation
      ↓
Activation
      ↓
현재 Layer Output
```

이다.

---

# 58. Deep Network에서는 이 연산을 반복한다

예를 들면

```text
Input x
 ↓
W₁x + b₁
 ↓
ReLU
 ↓
h₁
 ↓
W₂h₁ + b₂
 ↓
ReLU
 ↓
h₂
 ↓
W₃h₂ + b₃
 ↓
...
 ↓
Output
```

처럼 진행된다.

---

# 59. 첫 번째 Hidden Layer

개념적으로

`z¹ = W¹x + b¹`

`h¹ = A(z¹)`

이다.

여기서 `h¹`은 첫 번째 Hidden Layer의 Representation이다.

---

# 60. 두 번째 Hidden Layer

두 번째 Layer에서는 원래 Input `x`가 아니라 첫 번째 Layer가 만든 `h¹`을 사용한다.

`z² = W²h¹ + b²`

`h² = A(z²)`

이다.

---

# 61. 그 이후 Layer도 동일하다

세 번째 Layer라면

`z³ = W³h² + b³`

`h³ = A(z³)`

이다.

즉 Layer가 늘어나도 새로운 종류의 Operation이 계속 추가되는 것이 아니다.

같은 형태를 반복한다.

---

# 62. Deep Network의 핵심 반복식

```text
이전 Representation
        ↓
Linear Mapping
Wx + b
        ↓
Activation
        ↓
새로운 Representation
```

이 과정이 반복된다.

---

# 63. Hidden Representation

각 Hidden Layer의 Output은 원래 Input을 새로운 형태로 변환한 **Representation**으로 생각할 수 있다.

```text
Raw Input
   ↓
Hidden Representation 1
   ↓
Hidden Representation 2
   ↓
Hidden Representation 3
   ↓
Output
```

Deep Network는 이렇게 여러 단계의 Representation Transformation을 수행한다.

---

# 64. Pre-activation과 Activation 다시 구분

각 Layer에서

### Pre-activation

`z = Wx + b`

### Activation 이후

`h = A(z)`

다.

즉

```text
Linear Mapping 결과
→ Pre-activation

Non-linear Function 통과 결과
→ Hidden Unit / Activation
```

이다.

---

# 65. 두 번째 Hidden Layer에서도 원리는 완전히 같다

첫 번째 Layer에서 복잡한 Piecewise Representation이 만들어졌더라도 두 번째 Layer에서 하는 일도 동일하다.

```text
첫 Layer의 Hidden Units
        ↓
Weighted Sum
        ↓
Pre-activation
        ↓
ReLU
        ↓
두 번째 Hidden Units
```

이다.

---

# 66. 두 번째 Layer를 통과하면서 더 복잡해진다

두 번째 Layer의 Pre-activation 자체가 이전 Layer의 Piecewise Function들을 Linear Combination한 결과다.

여기에 다시 ReLU를 적용한다.

```text
Piecewise Function
        ↓
Linear Combination
        ↓
ReLU
        ↓
새로운 Kink / Region
```

따라서 Region이 더욱 세분화될 수 있다.

---

# 67. Layer가 더 늘어나도 동일하다

Hidden Layer가

```text
2개
3개
4개
...
```

가 되어도 동일한 Operation을 계속 반복한다.

따라서 Deep Neural Network를 처음 보면 복잡해 보이지만, 내부 Operation은 반복적인 구조다.

---

# 68. Shallow와 Deep 최종 비교

|항목|Shallow NN|Deep NN|
|---|---|---|
|Hidden Layer|1개|2개 이상|
|Hidden Unit|여러 개 가능|각 Layer마다 여러 개 가능|
|Non-linearity|가능|가능|
|복잡한 함수 근사|가능|가능|
|Universal Approximation|충분한 Unit이면 가능|가능|
|주요 장점|구조 단순|표현 효율성 높음|
|핵심|Width 확대|Depth를 통한 Composition|

---

# 69. Linear Regression과 Neural Network 비교

|Linear Regression|Neural Network|
|---|---|
|하나의 Linear Mapping|여러 Linear Mapping|
|Activation 없음|Activation 사용|
|전체 Function이 Linear|전체 Function이 Non-linear 가능|
|Weight/Bias 학습|많은 Weight/Bias 학습|
|직선/평면|복잡한 Piecewise Function|

---

# 70. Neural Network는 Linear Function을 버린 것이 아니다

중요한 관점이다.

Neural Network 안을 보면 오히려 Linear Function이 계속 등장한다.

```text
Linear
→ Activation
→ Linear
→ Activation
→ Linear
...
```

즉 기존 Linear Model을 버린 것이 아니라

> **Linear Model을 작은 계산 단위로 반복 사용하면서 Non-linearity를 사이에 삽입한 것**

이다.

---

# 71. Activation이 없다면?

이번 강의에서 Activation이 핵심이라고 강조한 이유를 구조적으로 이해해야 한다.

각 Layer가 단지 Linear Mapping만 수행한다면

```text
Linear
○ Linear
○ Linear
```

의 합성 역시 결국 하나의 Linear Mapping처럼 표현될 수 있다.

이번 강의에서는 ReLU를 이용함으로써 꺾인 Piecewise Region이 생기고 전체 Function이 Non-linear해지는 구조를 중점적으로 설명한다.

---

# 72. Neural Network Parameter

주요 학습 Parameter는

```text
Weights
Biases
```

다.

반면

```text
ReLU라는 Function Rule 자체
```

는 이번 강의 설명에서는 Parameter가 아니다.

---

# 73. 학습 전과 학습 후

이번 차시는 Neural Network의 **함수 구조와 표현력**을 중심으로 다룬다.

Parameter가 주어졌을 때

> Network가 어떤 Function을 만드는가?

를 먼저 이해한다.

실제로 이 Parameter들을 어떻게 Update하는지는 이후 Gradient Descent와 관련된 강의에서 본격적으로 다룬다.

---

# 74. Neural Network 학습도 결국 Loss 최소화

구조가 복잡해져도 학습의 큰 원리는 바뀌지 않는다.

```text
Input
 ↓
Neural Network
 ↓
Prediction
 ↓
Actual Label과 비교
 ↓
Loss
 ↓
Parameter 수정
 ↓
Loss 감소
```

이다.

Linear Regression에서 기울기와 절편을 찾던 문제가 수많은 Weight와 Bias를 찾는 문제로 확장된 것이다.

---

# 75. Regression에서도 Neural Network를 사용할 수 있다

Output이 숫자라면 Neural Network를 Regression Model로 사용할 수 있다.

예를 들어

```text
Input
 ↓
Neural Network
 ↓
숫자 Output
```

으로 만들고 Squared Error 계열의 Loss를 사용할 수 있다.

강의 초반에서도 Shallow Network를 간단한 Regression 및 Classification 문제에 적용할 수 있다고 설명한다.

---

# 76. Classification에도 Neural Network를 사용할 수 있다

마찬가지로 Output Layer 구조와 Loss를 적절히 설정하면 Classification에도 사용할 수 있다.

즉 Neural Network 자체는

```text
Regression 전용
Classification 전용
```

으로 고정된 모델이 아니라 매우 일반적인 함수 모델이다.

---

# 77. Hidden Layer는 왜 “Hidden”인가?

Input과 Output은 직접 관측할 수 있다.

하지만 중간 Hidden Unit의 값은 Data에서 정답으로 직접 제공되는 값이 아니다.

Network 내부에서 Parameter에 의해 계산되는 **중간 표현**이다.

그래서 Hidden Layer라고 부른다.

---

# 78. Network Diagram에서 Bias가 생략될 수 있다

강의 후반에서는 일반적인 Neural Network Diagram을 보면 Bias Node가 명시되지 않는 경우가 많다고 설명한다.

그러나 그림에서 생략됐다고 해서

```text
Bias가 존재하지 않는다
```

고 생각해서는 안 된다.

대부분의 표현에서는 단순화를 위해 생략한 것이다.

---

# 79. Weight Matrix Dimension

Layer마다 Hidden Unit 개수가 다르면 Weight Matrix의 크기도 달라진다.

예를 들어

```text
이전 Layer Unit = 3
현재 Layer Unit = 5
```

라면 두 Layer를 연결하기 위한 Weight Matrix는 이 두 Dimension을 연결할 수 있는 형태가 되어야 한다.

따라서 Network 수식을 이해할 때는

> **각 Layer의 Unit 개수를 추적하는 bookkeeping**

이 중요하다.

---

# 80. Neural Network를 이해할 때 가장 중요한 관점

복잡한 전체 수식을 한꺼번에 외우려고 하면 어렵다.

대신 Layer 하나를 보면 된다.

```text
Input Vector
      ↓
Linear Mapping
      ↓
Activation
      ↓
Output Vector
```

그리고

> **이것을 반복한 것이 Deep Neural Network다.**

라고 이해하면 된다.

---

# 81. 자주 헷갈리는 점 ① — Hidden Unit이 많으면 Deep인가?

아니다.

```text
Hidden Layer 개수
→ Depth

한 Layer의 Hidden Unit 개수
→ Width
```

이다.

Hidden Unit이 아무리 많아도 Hidden Layer가 하나면 Shallow Network다.

---

# 82. 자주 헷갈리는 점 ② — Neural Network에는 Linear Function이 없는가?

오히려 Linear Function이 기본 계산이다.

각 Unit에서

`Wx + b`

를 계산한다.

차이는 그 뒤에 Activation Function을 추가한다는 것이다.

---

# 83. 자주 헷갈리는 점 ③ — ReLU가 Parameter인가?

강의 설명에서는 아니다.

학습하는 것은 Weight와 Bias이고 ReLU라는 함수 규칙 자체는 고정되어 있다.

---

# 84. 자주 헷갈리는 점 ④ — ReLU 기반 NN은 Linear Model인가?

아니다.

각 Region 안에서는 Linear할 수 있지만 전체 Function은 여러 Linear Piece가 연결된 Non-linear Function이다.

---

# 85. 자주 헷갈리는 점 ⑤ — Non-linearity는 Weight가 만드는가?

강의의 핵심 설명에서는 **Activation Function이 Non-linearity를 만든다.**

Weight와 Bias는 각 Linear Piece의

- 위치
    
- 기울기
    
- Scale
    

등을 결정하고 Activation이 꺾임을 만든다.

---

# 86. 자주 헷갈리는 점 ⑥ — Shallow Network는 복잡한 함수를 표현하지 못하는가?

아니다.

충분한 Hidden Unit을 사용하면 강의에서 소개한 Universal Approximation의 관점에서 매우 복잡한 연속 함수도 근사할 수 있다.

---

# 87. 자주 헷갈리는 점 ⑦ — 그렇다면 Deep Network는 왜 필요한가?

강의의 핵심 답은

> **표현 효율성**

이다.

Shallow Network도 표현할 수 있지만 동일하거나 비슷한 Parameter 규모에서 Deep Network가 더 많은 Region과 더 복잡한 구조를 효율적으로 표현할 수 있다.

---

# 88. 자주 헷갈리는 점 ⑧ — Network가 깊어질수록 새로운 종류의 계산을 배우는가?

아니다.

기본적으로 계속

```text
Weight Matrix 곱
Bias 더하기
Activation
```

을 반복한다.

Depth는 같은 Operation을 여러 단계로 합성하는 것이다.

---

# 92. 이번 강의에서 반드시 기억할 핵심

### 1. Shallow Neural Network는 Hidden Layer가 하나다.

### 2. Deep Neural Network는 강의 기준 Hidden Layer가 두 개 이상이다.

### 3. Hidden Unit의 기본 구조는 Linear Mapping + Activation이다.

### 4. 대표 Activation으로 ReLU를 사용한다.

`ReLU(z)=max(0,z)`

### 5. ReLU는 Negative 영역을 0으로 만든다.

### 6. Activation이 Neural Network에 Non-linearity를 만든다.

### 7. ReLU Network는 Piecewise Linear Function으로 이해할 수 있다.

### 8. Weight와 Bias가 주요 학습 Parameter다.

### 9. Activation Function 자체는 이번 강의에서 학습 Parameter가 아니다.

### 10. Hidden Unit이 많아지면 표현 가능한 Piece가 증가한다.

### 11. 충분히 많은 Hidden Unit을 가진 Shallow Network도 복잡한 연속 함수를 근사할 수 있다.

### 12. 따라서 Deep Network를 사용하는 이유는 단순히 Shallow가 복잡한 Function을 못 표현해서가 아니다.

### 13. Deep Network는 Function Composition을 통해 표현 효율성을 높인다.

### 14. Input이 여러 개이면 Pre-activation이 Multiple Linear Function으로 확장된다.

### 15. 2D Input에서는 ReLU Network가 Piecewise Plane을 만든다.

### 16. Output Dimension 역시 쉽게 여러 개로 확장할 수 있다.

### 17. Deep Network도 기본 Operation은 반복적으로 `Wx+b → Activation`이다.

### 18. Weight들은 Matrix로, Bias들은 Vector로 묶어 표현할 수 있다.

### 19. Network Diagram에서 Bias가 생략되어도 실제 계산에서는 Bias가 존재할 수 있다.

### 20. Neural Network 학습 역시 궁극적으로 Loss를 줄이는 Parameter를 찾는 문제다.

# 93. 이번 강의의 핵심 한 문장

> **신경망은 여러 선형 함수를 Activation Function으로 비선형 변환한 뒤 다시 가중합하고, 이러한 변환을 반복적으로 합성함으로써 복잡한 함수를 표현하는 Parameterized Function Model이다.**

그리고 Deep Neural Network까지 포함하면 다음과 같다.

> **Shallow Network도 충분한 Hidden Unit으로 복잡한 함수를 근사할 수 있지만, Deep Network는 여러 Layer의 함수 합성을 통해 비슷한 Parameter 수로 훨씬 복잡한 Piecewise Region을 효율적으로 표현할 수 있다는 점이 핵심이다.**
