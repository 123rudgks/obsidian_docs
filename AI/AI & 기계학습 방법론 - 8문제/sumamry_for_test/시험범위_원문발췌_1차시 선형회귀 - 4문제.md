# 1. 선형회귀가 사용되는 문제

선형회귀는 여러 실제 분석 문제에 사용할 수 있다.

강의에서는 광고비와 매출을 대표적인 예로 든다.

```text
TV 광고비
    ↓
  매출
```

여기서

- 광고비 = Input / Feature `x`
    
- 매출 = Target / Label `y`
    

이다.

우리가 알고 싶은 것은

> **광고비가 변할 때 매출이 어떻게 변하는가?**

이다.

---

# 2. 다른 선형회귀 활용 사례 — 신용점수

신용점수를 예측한다고 하자.

Feature로

- 고객 소득
    
- 소비 패턴
    
- 부채
    
- 기타 금융 정보
    

등을 사용할 수 있다.

예를 들어 소득이 증가하면 신용점수가 증가하는 관계가 있을 수 있고, 부채가 많으면 반대로 감소하는 관계가 있을 수 있다.

이러한 Feature와 숫자로 된 Target 사이의 관계를 모델링하는 것도 Regression 문제다.

---

# 3. Linear Regression이란?

선형회귀는

> **입력 변수 x와 출력 변수 y 사이의 관계를 직선 형태의 함수로 근사하여 예측하는 방법**

이다.

1개의 Feature에서는 직선이고, Feature가 여러 개가 되면 더 높은 차원의 Hyperplane으로 확장된다.

선형회귀는

- 가장 기초적인 지도학습 방법
    
- 개념적으로 매우 중요
    
- 이후 배우는 여러 방법론의 기반
    
- 실제 현업에서도 여전히 널리 사용
    

되는 모델이다.

---

# 8. 선형회귀의 기본 Model

직선은 기울기와 절편만 알면 결정된다.

기본 관계는

`y = β₀ + β₁x + ε`

로 표현한다.

여기서

- `β₀` : Intercept, 절편
    
- `β₁` : Slope, 기울기
    
- `x` : Feature
    
- `y` : 실제 관측값
    
- `ε` : Noise / 관측 오차
    

다.

---

# 9. β₀ — Intercept

`β₀`는 절편이다.

즉

`x = 0`

일 때 선형 함수의 기본 y값이다.

그래프에서는 y축과 직선이 만나는 위치를 결정한다.

---

# 10. β₁ — Slope

`β₁`은 기울기다.

x가 1만큼 증가할 때 평균적인 y 변화량을 나타낸다.

예를 들어

`β₁ > 0`

이라면

```text
x 증가
→ y 증가
```

하는 관계다.

반대로

`β₁ < 0`

이면 x가 증가할수록 y가 감소하는 방향이다.

---

# 11. 앞 강의의 True Function과 연결

앞서

`y = f*(x) + ε`

라고 배웠다.

이번 선형회귀에서는 True Function이 Linear하다고 가정한다면

`f*(x) = β₀ + β₁x`

형태로 생각한다.

따라서

`y = β₀ + β₁x + ε`

가 된다.

---

# 12. Data Point들이 직선 위에 완전히 놓이지 않는 이유

실제 Data는 정확히 직선 위에 있지 않는다.

```text
          ● y
          │
          │ ε
──────────┼──── True Linear Function
```

그 이유가 `ε`다.

즉 평균적인 관계는 직선이라고 가정하더라도 실제 개별 Data에는

- Noise
    
- Measurement Error
    
- 관측되지 않은 요인
    

등이 존재할 수 있다.

따라서 실제 Data Point는 직선 주변에 흩어져 있다.

---

# 13. 학습된 선을 이용한 Prediction

선형 Model을 학습하고 나면 새로운 `x`를 직선에 넣어 Prediction을 얻을 수 있다.

```text
새로운 x
   ↓
학습된 직선
   ↓
ŷ
```

예를 들어 광고비가 특정 값이라면 직선 위에서 대응하는 매출값을 읽어 Prediction으로 사용한다.

중요한 점은

> **선형 Model의 모든 Prediction은 학습된 직선 위에 존재한다.**

는 것이다.

---

# 51. Multiple Linear Regression Model

Feature가 `p`개라면 선형식은

`y = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ + ε`

가 된다.

각 Feature마다 하나의 Coefficient가 존재한다.

---

# 52. Multiple Regression에서 학습하는 값

우리가 학습해야 하는 Parameter는

```text
β₀
β₁
β₂
...
βₚ
```

이다.

이들을

- Regression Coefficients
    
- Parameters
    

라고 부른다.

즉 선형회귀에서 **학습 대상은 β들**이다.

---

# 53. Multiple Regression Coefficient 해석

예를 들어

`β₂`

가 Radio 광고비에 해당한다고 하자.

그 의미는 기본적으로

> **다른 모든 Feature를 고정했을 때 Radio 광고비 `x₂`를 1 unit 증가시키면 y가 평균적으로 β₂만큼 변한다.**

는 것이다.

이때 매우 중요한 표현은

> **다른 변수들을 모두 고정했을 때**

이다.

---

# 76. Multiple Linear Regression의 중요한 문제 — Feature 간 Correlation

여러 Feature가 있을 때 Feature끼리 서로 강하게 관련되어 있을 수 있다.

예:

```text
x₁ 증가할 때
x₂도 거의 항상 함께 증가
```

하는 경우다.

이런 상황에서는 각 Coefficient를 독립적으로 해석하기 어려워질 수 있다.

---

# 77. 왜 Coefficient 해석이 어려워지는가?

Multiple Regression에서 `β₂`는

> **다른 모든 Feature를 고정한 채 x₂만 1 증가했을 때의 y 변화**

라고 해석했다.

그런데 실제 Data에서 x₁과 x₂가 항상 함께 움직인다면

```text
x₁ 고정
+
x₂만 변화
```

라는 상황 자체를 Data에서 분리하기 어려워진다.

따라서 β의 개별 해석이 불안정하거나 어려워질 수 있다.

---

# 78. 분석 전에 Feature 간 Correlation 확인

강의에서는 여러 변수들이 서로 함께 움직이는지 확인하기 위해 Feature 간 **Correlation**을 계산해보는 것이 중요하다고 설명한다.

즉 Multiple Linear Regression에서는

```text
Feature ↔ Target
```

뿐 아니라

```text
Feature ↔ Feature
```

관계도 확인할 필요가 있다.

이 문제는 이후 **Multicollinearity(다중공선성)** 와 연결된다.
